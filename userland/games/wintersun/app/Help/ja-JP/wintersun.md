## NAME

wintersun — 手続き的に生成された世界を歩く

## SYNOPSIS

`wintersun [--seed SEED | --reference-scene]`

## DESCRIPTION

生成された世界を映すデスクトップウィンドウを開きます。同梱するのではなく機械が合
成した地面を見下ろす視点で、低い太陽に照らされ、どの斜面にも長い影が伸びます。

世界は北の果ての氷床から赤道の向こうの熱帯雨林まで広がります。気候は緯度と卓越風、そ
してその行く手を遮る山々に従うので、雨の届かないところには砂漠が、水の抜けないところ
には湿原が広がります。どの世界もただ一つの数、シードから生まれます。同じシードはどの
機械でも同じ世界を開きます。

この世界のどこにも絵素材として保存されたものはありません。地面を成す素材——氷、砂丘の
砂、枯れ草、林床、花崗岩——はそれぞれ数個の数値にすぎず、クライアントが描画しながらテ
クスチャに変えます。そのため世界はどの機械でも同じに見え、ディスクをほとんど占めませ
ん。道は横切る地面の上に載るのではなく、その中へ擦り込まれます。

まだ生成されていない地面は、空白そのものとして描かれ、届くにつれて埋まっていきま
す。クライアントは立ち止まって待つのではなく手元にあるものを描くので、世界が追い
つく間もウィンドウは応答し続けます。

矢印キーまたは `W`、`A`、`S`、`D` で歩きます。二つ同時に押すと、その間の対角線を同
じ速さで歩き、反対向きのキーは打ち消し合います。視点はあなたを追い、世界の外へ滑
り出さずに縁で止まります。登るには急すぎる斜面と、渡るには深すぎる水は、あなたを
脇へそらします。

`+` と `-` は視点を近づけたり遠ざけたりします。世界のセル一つが八ピクセルの幅から
百二十八ピクセルの幅まで、五段階です。

`F11` はウィンドウを全画面にし、その後は元の状態へ戻します。最大化されていたウィン
ドウは最大化されたまま戻ります。`Esc` は元に戻し、`Q` は終了します。

別の設定を選ぶまで、すべての細部は最も細かい品質で描かれます。アイコンバーにある
ゲームのメニューの *Settings…* 行を選ぶと設定ウィンドウが開き、品質を選べます。
*Ultra* はすべての細部を最も細かく、*Basic* はすべての細部を最も簡素にしてウィン
ドウの大きさのまま描き、*Custom* は照明・影・地面の質感・描画の縮尺をそれぞれの
スライダーで自分で選び、*Auto* は機械に任せます。スライダーを動かすと選択は
*Custom* になります。選択は次に遊ぶときまで保たれます。

*Auto* では、フレームがしばらく遅れ続けるとクライアントは細部を少しずつ下げ——ま
ず照明、次に影、次に描画の縮尺——回復するにつれて一段ずつ戻します。判断は一つのフ
レームではなく数秒単位で行うので、機械が一瞬ほかの仕事をしても何も失われず、ウィ
ンドウを大きくしても最も簡素な状態に落ちることはなく、人物が読み取れないほど小さ
く描かれることもありません。

ソフトウェア描画が埋められる大きさを超えるウィンドウは、最大 2560×1440 で描かれ、
ウィンドウの大きさへ拡大されます。

## OPTIONS

- `-h, -?, --help` — このコマンド自身の短いヘルプを表示します。
- `--seed SEED, --seed=SEED` — SEED が指す世界を開きます。SEED は 0 から
  18446744073709551615 までの整数です。指定しなければ新しいシードを引き、同じ世
  界をもう一度開けるよう標準情報ストリーム（記述子 3）に報告しま
  す。`--reference-scene` とは併用できません。そちらは固定された一つの世界です。
- `--reference-scene` — 固定の参照シーンを描き、静止させたまま保ちます。同じ世界、同じ人物、
  同じ瞬間で、どのマシンでも同一なので、ウィンドウの画像を別の場所で描いた
  ものと照合できます。`F11` と `Esc` は引き続きウィンドウの大きさを変え、
  それ以外は何も動きません。

## EXIT STATUS

終了したときは `0`。ゼロ以外の状態は、その理由を標準エラー出力に示します。世界を生
成できなかった、ウィンドウを開けなかった、またはセッションのイベントチャネルが失
われた、のいずれかです。

- `2` — コマンドラインを理解できなかった。
- `87` — 参照シーンを描画できなかった。
