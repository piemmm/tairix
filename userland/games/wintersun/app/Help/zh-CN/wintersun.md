## NAME

wintersun — 在程序化生成的世界中行走

## SYNOPSIS

`wintersun [--seed SEED | --reference-scene]`

## DESCRIPTION

打开一个桌面窗口，望向一个生成出来的世界：俯视地面，那片地面由机器自行合成而非随
程序附带，由一轮低垂的太阳照亮，在每道斜坡上投下长长的影子。

这个世界从遥远北方的冰盖一直延伸到赤道另一侧的热带雨林。它的气候随纬度、盛行风以及挡
住风路的山脉而定，所以雨水到不了的地方是沙漠，水排不出去的地方是沼泽。每个世界都出自
一个数字，即它的种子：同一个种子在每台机器上打开同一个世界。

这个世界没有任何部分以美术素材的形式存储。地面所用的每种材质——冰、沙丘沙、枯草、林地、
花岗岩——都只是少数几个数字，客户端在绘制时把它们变成纹理，因此世界在每台机器上看起
来都一样，而且几乎不占磁盘空间。道路会磨进它所穿过的地面，而不是浮在上面。

尚未生成的地面会按其本来的样子画成空缺，并随着数据到达而逐步填满。客户端绘制它已
经拥有的内容，而不是停下来等待，因此在世界追赶进度时窗口仍然有响应。

方向键或 `W`、`A`、`S`、`D` 用于行走。同时按住两个键会以相同速度沿它们之间的对角
线行走，方向相反的键相互抵消。视角跟随你，并在世界边缘停住，而不会滑出世界之外。
太陡而无法攀登的山坡和太深而无法涉过的水会让你绕开。

`+` 和 `-` 拉近和拉远视角，共五档，从一个世界单元格占八像素到占一百二十八像素。

`F11` 让窗口进入全屏，再返回它先前的状态：最大化的窗口会以最大化返回。`Esc` 还原
窗口。`Q` 退出。

在你另作选择之前，所有细节都以最精细的品质绘制。图标栏中游戏菜单的 *Settings…*
一行会打开它的设置窗口，品质可选：*Ultra*，所有细节最精细；*Basic*，所有细节最简
朴，按窗口的完整尺寸绘制；*Custom*，由你用各自的滑块选择光照、阴影、地面纹理和渲
染比例；或 *Auto*。移动任一滑块，选择即成为 *Custom*。你的选择会保留到下次游玩。

在 *Auto* 下，当帧持续一段时间迟到时，客户端会降低细节——先是光照，再是阴影，然后
是渲染比例——并在恢复时逐级还回。它以数秒而非单帧来判断，因此机器片刻忙于其他工作
不会带来任何损失，窗口变大也不会让它降到最简朴，而且它绝不会把人物画得小到无法辨
认。

对于超出软件渲染器所能填满的窗口，最多按 2560×1440 绘制，再放大到窗口大小。

## OPTIONS

- `-h, -?, --help` — 显示本命令自身的简短帮助。
- `--seed SEED` — 打开 SEED 所指的世界，SEED 是 0 到 18446744073709551615 之间的整数
  。不指定时，游戏会抽取一个新种子，并在标准信息流（描述符 3）上报告，以便再次打开同
  一个世界。不能与 `--reference-scene` 同时使用，后者是一个固定的世界。
- `--reference-scene` — 绘制固定的参考场景并保持静止：同一个世界、同样的角色、同一时刻，
  在每台机器上都完全相同，以便把窗口的画面与在别处绘制的画面进行比对。
  `F11` 与 `Esc` 仍可改变窗口大小；其余一切都不会移动。

## EXIT STATUS

退出时为 `0`。非零状态会在标准错误上说明原因：世界无法生成、窗口无法打开，或会话
的事件通道已丢失。

- `2` — 无法理解命令行。
- `87` — 无法绘制参考场景。
