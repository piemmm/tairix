## NAME

recorder — 为桌面录制屏幕

## SYNOPSIS

`recorder SESSION`

## DESCRIPTION

在桌面要求时把屏幕录制成影片。它不由人手动运行：录制开始时由桌面启动，
录制结束时随之结束。

启动它的程序以 `SESSION` 指明它为之录制的桌面会话。

要录制，请按 `Meta+Shift+5` 打开截屏栏，选择整个屏幕、一个窗口或一个
区域，然后按 **Record**（录制）。截屏快捷键、通知区域中的录制指示器，
或在 **Options**（选项）中选择的时长到期，都会停止录制。

录制按 **Options** 的选择保存在 Desktop 文件夹或 `Home/Videos` 中，名为
`Screen Recording YYYY-MM-DD at HH.MM.SS.webm`。它是 WebM 影片：画面是
每秒最多三十帧的 VP8 视频，只在屏幕上有变化时才拍摄；声音是 Opus。

**Options** 中的 **Sound**（声音）选择录制听到的内容：无、麦克风、桌面
自身的声音，或两者混合。管理员带声音的录制会立即开始。其他任何账户会先
要求输入管理员的密码，随后录制程序仅为这一次录制以该管理员的身份运行；
取消则什么也不录制，并有通知说明。

磁盘写满时，录制就此结束并被保留。录制程序出错时，已录制的内容会被
保留，并有通知说明发生了什么。

## EXIT STATUS

录制完成时（包括因磁盘写满而结束的录制）为零。无法开始或以其他任何方式
结束时为非零；原因写入标准错误。
