## NAME

elsh — TAIRiX의 명령 셸

## SYNOPSIS

`elsh [-h | -?]`

## DESCRIPTION

대화형 명령 셸 — 상속받은 표준 스트림 위의 읽기-평가-인쇄 루프 — 를
실행합니다. 입력된 명령어는 먼저 셸의 내장 명령에, 그다음 시스템 명령
스토어(`/System/Commands`)에, 시스템 앱 스토어(`/System/Applications`)에,
사용자 자신의 명령 스토어(`<home>/Commands`)와 앱
스토어(`<home>/Applications`)에, 그다음 `PATH` 변수의 디렉터리들에 대해
해석됩니다. 이 네 스토어는 사용자가 재정렬하거나 재정의할 수 없는 고정된
접두부이므로 `PATH`는 시스템 명령을 결코 가릴 수 없습니다. 해석되지 않는
단어는 `127`로 종료하고, 해석되었으나 실행할 수 없는 번들은 `126`으로
종료합니다.

내장 명령:

- `cd [-L | -P [-e]] [directory]`, `cd -` — 작업 디렉터리를 바꿉니다.
  `directory`로, 그것이 없으면 `HOME`으로 가고, `-`이면 `OLDPWD`로
  되돌아가 그것을 인쇄합니다. 기본값인 `-L`은 `PWD`가 아직 작업
  디렉터리를 가리키는 동안 `directory`를 쓰인 그대로 `PWD`에 적용하므로,
  `cd link` 다음에 `cd ..`를 하면 링크가 있는 곳으로 돌아옵니다. `-P`는
  먼저 링크를 따라가며, `PWD`는 디렉터리 자신의 경로가 됩니다(이때
  `-e`는 그 경로를 읽을 수 없으면 실패합니다). `/..`는 `/`와 같으며,
  별칭 루트(`Home:/`) 아래에서는 `..`가 결코 그 위로 올라가지 않습니다.
- `pwd [-L | -P]` — 작업 디렉터리를 인쇄합니다: 아직 그것을 가리키는
  동안의 `PWD`(`-L`, 기본값), 또는 디렉터리 자신의 경로(`-P`).
- `echo ...` — 피연산자를 인쇄합니다.
- `export NAME=value`, `unset NAME` — 내보낸 환경을 편집합니다.
- `jobs`, `fg`, `bg` — 작업 제어.
- `ulimit [-a] [-H | -S] [resource [value]]` — 자원 제한을 읽고 부과합니다.
  `ulimit -n [value]`는 열린 파일에 대한 제한을 읽거나 설정합니다.
- `umask [-S] [mode]` — 파일 모드 생성 마스크(`0022`)를 보이거나, `-S`가
  있으면 그 마스크가 남기는 권한(`u=rwx,g=rx,o=rx`)을 보이거나, 마스크를
  설정합니다. 8진수 `mode`는 마스크 자체이고, 기호 모드(`g-w`,
  `u=rwx,g=rx,o=`)는 마스크가 남기는 권한을 편집합니다. 이후에 시작되는
  모든 명령은 그 마스크를 적용해 파일을 만들며, 리다이렉션은 `0666`에서
  마스크를 뺀 모드로 파일을 만듭니다.
- `elevate <user> <program> [argument ...]` — 콘솔의 로그인 감독자를
  통해 재인증한 뒤, 주어진 인수로 명령 하나를 실행합니다.
- `shopt [-pqsu] [-o] [name ...]` — 파일 이름 패턴 옵션을 보이거나 설정합니다.
- `help` — 내장 명령을 나열합니다.
- `exit [code]` — 세션을 끝냅니다.

따옴표로 감싸지 않은 `*`, `?`, `[...]`가 있는 단어는 파일 이름 패턴이며, bash처럼 일치하는 이름들을 정렬한 목록으로 바뀝니다: `cp *.tmp /tmp`.
맨 앞의 `.`은 `.`로만 일치하며, 아무것에도 일치하지 않는 패턴은 쓴 그대로 남습니다.
중괄호가 먼저 확장됩니다: `a{b,c}`는 `ab ac`가 되고 `{1..5}`는 수를 셉니다.
따옴표로 감싸면 이 문자들은 모두 글자 그대로가 되며, 변수의 값은 결코 패턴으로 읽히지 않습니다.
`shopt -s`는 bash의 옵션을 켭니다: `nullglob`(일치가 없으면 단어도 없음), `failglob`(일치가 없으면 오류), `dotglob`, `nocaseglob`, `globstar`(`**`는 어떤 깊이에도 일치), `extglob`(`?(…)`, `*(…)`, `+(…)`, `@(…)`, `!(…)`); `shopt -o -s noglob`은 파일 이름 패턴을 끕니다.

터미널에서 셸은 익숙한 bash/zsh 키를 쓰는 대화형 줄 편집기를 실행합니다.
위/아래 화살표(또는 `Ctrl-P`/`Ctrl-N`)로 세션의 명령 기록을 이동하고,
`Ctrl-R`로 기록을 증분 검색하며, 왼쪽/오른쪽/Home/End와
`Ctrl-A`/`Ctrl-E`로 커서를 옮기고, `Ctrl-K`/`Ctrl-U`/`Ctrl-W`/`Ctrl-Y`로
잘라내기와 붙여넣기를 하며, `Ctrl-T`로 두 문자를 맞바꾸고, `Ctrl-L`로
화면을 지우고 다시 그리며, `Ctrl-C`로 편집 중인 줄을 버리고, 빈 줄에서
`Ctrl-D`로 세션을 끝냅니다. Tab은 커서 아래의 단어를 완성합니다. 명령
이름(내장 명령과 설치된 명령 앱), 파일 경로, 그리고 리다이렉션 대상이나
참조 형태의 단어에서는 `sys:random` 같은 리소스 참조를 완성합니다.
네임스페이스는 등록된 선택자를 한 세그먼트씩
완성합니다(`state:` → `net/` → `wan/` → `link`). 레지스트리가 형태만
아는 부분(인터페이스 이름, 인터럽트 회선)에서는 Tab이 실제 시스템의
이름을 제시하며, 이 세션에 목록 권한이 없으면 아무것도 제시하지
않습니다. `info:`/`state:`/`stats:`는 인수로도, 값을 읽는 `<` 뒤에도
나오지만(`cat < info:mem/physical`), `>` 뒤에는 결코 나오지 않습니다.
이런 리소스는 리다이렉션으로 쓰이지 않기 때문입니다. 파이프나 스크립트로
들어온 입력은 편집기를 거치지 않으며, 터미널이 있든 없든 똑같이
동작합니다.

셸은 피연산자를 받지 않습니다. 스크립트 실행은 아직 문법에 없습니다.

## OPTIONS

- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시하고 종료합니다.

## EXIT STATUS

- 내장 `exit`의 코드, 또는 입력 스트림이 끝났을 때(또는 짧은 도움말이
  표시되었을 때) `0`.
- `2` — 호출을 이해하지 못했습니다.

## ENVIRONMENT

- `HOME` — 피연산자 없는 `cd`가 가는 곳.
- `PWD`, `OLDPWD` — `cd`가 도달한 그대로의 작업 디렉터리와 그 이전
  디렉터리. `cd`가 둘 다 설정합니다. 셸이 시작할 때 받은 `PWD`는 작업
  디렉터리를 가리키는 동안 그대로 유지되고, 그렇지 않으면 그 디렉터리
  자신의 경로가 됩니다.
- `PATH` — 고정된 스토어 접두부 다음에 검색되는 디렉터리들.
- `GLOBIGNORE` — `:`로 구분한 패턴들로, 파일 이름 패턴은 이것과 일치하는 결과를 버립니다.
  이 변수가 비어 있지 않으면 파일 이름 패턴이 `.`로 시작하는 이름에도 일치하므로 `rm *`는 `.profile`도 지웁니다.
- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그). 시작되는
  모든 명령에 내보내집니다.
