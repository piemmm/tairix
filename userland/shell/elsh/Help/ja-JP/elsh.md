## NAME

elsh — TAIRiX のコマンドシェル

## SYNOPSIS

`elsh [-h | -?]`

## DESCRIPTION

対話的なコマンドシェル — 継承した標準ストリーム上の読取・評価・印字ルー
プ — を実行します。打鍵されたコマンド語はまずシェルの組み込みコマンドに
対して、次にシステムコマンドストア（`/System/Commands`）、システムアプ
リストア（`/System/Applications`）、ユーザー自身のコマンドストア
（`<home>/Commands`）とアプリストア（`<home>/Applications`）、次に `PATH`
変数のディレクトリに対して解決されます。これら4つのストアは固定された接
頭部であり、ユーザーが並べ替えたり上書きしたりすることはできないので、
`PATH` がシステムコマンドを覆い隠すことはできません。解決できない語は
`127` で終了し、解決できたが実行できないバンドルは `126` で終了します。

組み込みコマンド：

- `cd [-L | -P [-e]] [directory]`、`cd -` — 作業ディレクトリを変更す
  る。`directory` へ、それがなければ `HOME` へ移り、`-` なら `OLDPWD` へ
  戻ってそれを印字する。既定の `-L` は、`PWD` がまだ作業ディレクトリを指
  している間、`directory` を書かれたとおりに `PWD` へ適用する。そのため
  `cd link` の後に `cd ..` とするとリンクのある場所に戻る。`-P` は先にリ
  ンクをたどり、`PWD` はディレクトリ自身のパスになる（このとき `-e` は、
  そのパスを読み取れなければ失敗する）。`/..` は `/` であり、エイリアス
  ルート（`Home:/`）の下では `..` がそれより上へ上がることはない。
- `pwd [-L | -P]` — 作業ディレクトリを印字する。既定の `-L` では、まだそれ
  を指している限り `PWD` を、`-P` ではディレクトリ自身のパスを印字する。
- `echo ...` — オペランドの印字。
- `export NAME=value`、`unset NAME` — エクスポートされた環境の編集。
- `jobs`、`fg`、`bg` — ジョブ制御。
- `ulimit [-a] [-H | -S] [resource [value]]` — 資源制限の読み取りと設
  定。`ulimit -n [value]` は開いているファイルの制限を読み取るか設定する。
- `umask [-S] [mode]` — ファイルモード作成マスク（`0022`）を表示する
  か、`-S` があればマスクが残す許可（`u=rwx,g=rx,o=rx`）を表示するか、マス
  クを設定する。8 進の `mode` はマスクそのもので、シンボリックなもの
  （`g-w`、`u=rwx,g=rx,o=`）はマスクが残す許可を編集する。以後に起動される
  すべてのコマンドはこのマスクを適用してファイルを作成し、リダイレクトは
  `0666` からマスクを除いたモードでファイルを作成する。
- `elevate <user> <program> [argument ...]` — コンソールのログイン監督者
  を通して再認証したうえで、指定した引数でコマンドを一つ実行する。
- `shopt [-pqsu] [-o] [name ...]` — ファイル名パターンのオプションを表示または設定する。
- `help` — 組み込みコマンドの一覧。
- `exit [code]` — セッションを終える。

引用符で囲まれていない `*`、`?`、`[...]` を含む語はファイル名パターンであり、bash と同様に、一致する名前を整列したものに置き換えられる: `cp *.tmp /tmp`。
先頭の `.` には `.` でしか一致せず、何にも一致しないパターンは書かれたまま残る。
中括弧が最初に展開される: `a{b,c}` は `ab ac` になり、`{1..5}` は数を数える。
引用するとこれらの文字はどれも文字どおりになり、変数の値がパターンとして読まれることはない。
`shopt -s` は bash のオプションを有効にする: `nullglob`(一致がなければ語も残らない)、`failglob`(一致がなければエラー)、`dotglob`、`nocaseglob`、`globstar`(`**` が任意の深さに一致)、`extglob`(`?(…)`、`*(…)`、`+(…)`、`@(…)`、`!(…)`)。
`shopt -o -s noglob` はファイル名パターンを無効にする。

端末ではシェルは、bash/zsh でおなじみのキーを使える対話的な行エディタを
実行します。上下キー（または `Ctrl-P`/`Ctrl-N`）でセッションのコマンド履
歴をたどり、`Ctrl-R` で履歴をインクリメンタルに検索し、左右
キー・Home・End と `Ctrl-A`/`Ctrl-E` でカーソルを動か
し、`Ctrl-K`/`Ctrl-U`/`Ctrl-W`/`Ctrl-Y` で切り取りと貼り付けを行
い、`Ctrl-T` で文字を入れ替え、`Ctrl-L` で画面を消去して描き直
し、`Ctrl-C` で編集中の行を破棄し、空行での `Ctrl-D` でセッションを終了
します。Tab はカーソル位置の語を補完します。補完されるのは、コマンド名
（組み込みコマンドとインストール済みのコマンドアプリ）、ファイルパス、そ
してリダイレクト先や参照の形をした語では `sys:random` のようなリソース参
照です。名前空間は登録済みのセレクタを 1 セグメントずつ補完します
（`state:` → `net/` → `wan/` → `link`）。レジストリが形しか知らない部分
（インタフェース名、割り込み線）では、Tab は実際のマシンの名前を提示し、
このセッションに一覧の権限がなければ何も提示しま
せん。`info:`/`state:`/`stats:` は引数として、また値を読み取る `<` の後
に現れます（`cat < info:mem/physical`）が、`>` の後には決して現れま
せん。この種のリソースがリダイレクトで書き込まれることはないためです。パ
イプやスクリプトからの入力はエディタを通らず、端末の有無にかかわらず同じ
ように動作します。

シェルはオペランドを取りません。スクリプトの実行はまだ文法に含まれてい
ません。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示して終了する。

## EXIT STATUS

- 組み込み `exit` のコード。入力ストリームが終わったとき（または短いヘ
  ルプを表示したとき）は `0`。
- `2` — 呼び出しを解釈できなかった。

## ENVIRONMENT

- `HOME` — オペランドなしの `cd` が移る先。
- `PWD`、`OLDPWD` — `cd` がたどり着いたとおりの作業ディレクトリと、その
  一つ前のもの。`cd` が両方を設定する。シェル起動時の `PWD` は、作業ディ
  レクトリを指している間はそのまま保たれ、そうでなければそのディレクトリ
  自身のパスになる。
- `PATH` — 固定ストア接頭部の後に探すディレクトリ。
- `GLOBIGNORE` — `:` で区切ったパターン。これに一致したものはファイル名パターンの結果から除かれる。
  この変数が空でない間は、ファイル名パターンが `.` で始まる名前にも一致するため、`rm *` は `.profile` も削除する。
- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。起
  動されるすべてのコマンドにエクスポートされる。
