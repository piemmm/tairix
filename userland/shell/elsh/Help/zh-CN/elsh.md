## NAME

elsh — TAIRiX 的命令 shell

## SYNOPSIS

`elsh [-h | -?]`

## DESCRIPTION

运行一个交互式命令 shell — 在继承的标准流上的读取-求值-打印循环。键入的命
令词先在 shell 的内建命令中解析，然后是系统命令商店（`/System/Commands`）、
系统应用商店（`/System/Applications`）、用户自己的命令商店
（`<home>/Commands`）和应用商店（`<home>/Applications`），再是 `PATH` 变量
的目录；这四个商店构成一个固定前缀，用户无法重新排序或覆盖，因此 `PATH`
永远不能遮蔽系统命令。无法解析的词以 `127` 退出；解析成功但不可执行的程序
包以 `126` 退出。

内建命令：

- `cd [-L | -P [-e]] [directory]`、`cd -` — 更改工作目录：改到
  `directory`，没有它时改到 `HOME`，或用 `-` 回到 `OLDPWD` 并将其打印。
  默认的 `-L` 在 `PWD` 仍指向工作目录时，把 `directory` 按原样应用于
  `PWD`，因此 `cd link` 之后再 `cd ..` 会回到链接所在之处；`-P` 先跟随链
  接，`PWD` 变为该目录自身的路径（此时若该路径无法读取，`-e` 会使其失
  败）。`/..` 即 `/`，而在别名根（`Home:/`）之下，`..` 绝不会越过该根。
- `pwd [-L | -P]` — 打印工作目录：仍指向它的 `PWD`（`-L`，默认），或该目录
  自身的路径（`-P`）。
- `echo ...` — 打印其操作数。
- `export NAME=value`、`unset NAME` — 编辑导出的环境。
- `jobs`、`fg`、`bg` — 作业控制。
- `ulimit [-a] [-H | -S] [resource [value]]` — 读取和施加资源限
  制；`ulimit -n [value]` 读取或设置对打开文件的限制。
- `umask [-S] [mode]` — 显示文件模式创建掩码（`0022`），或用 `-S` 显示它留
  下的权限（`u=rwx,g=rx,o=rx`），或设置它：八进制的 `mode` 就是掩码本身，
  符号形式的（`g-w`、`u=rwx,g=rx,o=`）则编辑它留下的权限。此后启动的每个命
  令创建文件时都会应用它，重定向则以 `0666` 减去掩码的模式创建其文件。
- `elevate <user> <program> [argument ...]` — 经控制台的登录监督者重新认
  证后，以给定的参数运行一条命令。
- `shopt [-pqsu] [-o] [name ...]` — 显示或设置文件名模式选项。
- `help` — 列出内建命令。
- `exit [code]` — 结束会话。

含有未加引号的 `*`、`?` 或 `[...]` 的词是文件名模式，会像 bash 一样替换为它所匹配的、已排序的名称：`cp *.tmp /tmp`。
开头的 `.` 只能由 `.` 匹配，什么也不匹配的模式保持原样。
花括号最先展开：`a{b,c}` 得到 `ab ac`，`{1..5}` 用于计数。
加引号会使这些字符都按字面理解，变量的值永远不会被当作模式。
`shopt -s` 打开 bash 的选项：`nullglob`（无匹配则不留词）、`failglob`（无匹配即出错）、`dotglob`、`nocaseglob`、`globstar`（`**` 匹配任意深度）和 `extglob`（`?(…)`、`*(…)`、`+(…)`、`@(…)`、`!(…)`）；`shopt -o -s noglob` 关闭文件名模式。

在终端上，shell 运行一个交互式行编辑器，使用熟悉的 bash/zsh 按键：
上/下方向键（或 `Ctrl-P`/`Ctrl-N`）浏览本会话的命令历史，`Ctrl-R` 对其
进行增量搜索，左/右方向键、Home、End 以及 `Ctrl-A`/`Ctrl-E` 移动光
标，`Ctrl-K`/`Ctrl-U`/`Ctrl-W`/`Ctrl-Y` 剪切与粘贴，`Ctrl-T` 交换字
符，`Ctrl-L` 清屏后重绘，`Ctrl-C` 放弃正在编辑的行，空行上的 `Ctrl-D`
结束会话。Tab 补全光标下的词：命令名（内建命令和已安装的命令应用）、文
件路径，以及在重定向目标或形如引用的词中补全 `sys:random` 这样的资源引
用。命名空间按段逐层补全其已注册的选择符
（`state:` → `net/` → `wan/` → `link`）；注册表只知道形状的部分（接口
名、中断线）由 Tab 补全为机器上的真实名称，若本会话无权列举，则不提供
任何候选。`info:`/`state:`/`stats:` 作为参数出现，也出现在 `<` 之后
（读取其值，如 `cat < info:mem/physical`），但绝不出现在 `>` 之后：此
类资源从不通过重定向写入。来自管道或脚本的输入绕过编辑器，无论有无终
端，行为都相同。

shell 不接受操作数：脚本执行尚不在其语法之内。

## OPTIONS

- `-h, -?` — 显示本命令自身的简短帮助并退出。

## EXIT STATUS

- `exit` 内建命令的代码，或输入流结束时为 `0`（或简短帮助已显示）。
- `2` — 无法理解此次调用。

## ENVIRONMENT

- `HOME` — 不带操作数的 `cd` 所去的目录。
- `PWD`、`OLDPWD` — 按 `cd` 到达时的样子记下的工作目录，以及之前的那一
  个；两者都由 `cd` 设置。shell 启动时带有的 `PWD` 只要仍指向工作目录就
  会保留，否则变为该目录自身的路径。
- `PATH` — 在固定商店前缀之后搜索的目录。
- `GLOBIGNORE` — 以 `:` 分隔的模式，文件名模式会丢弃与之匹配的结果。
  只要该变量非空，文件名模式也会匹配以 `.` 开头的名字，因此 `rm *` 也会删除 `.profile`。
- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`），导出给每
  个被启动的命令。
