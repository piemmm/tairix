## NAME

mkdir — створення каталогів

## SYNOPSIS

`mkdir [-pv] [-m MODE] [--] каталог...`

## DESCRIPTION

Створює кожен каталог-операнд по черзі. Без `-p` батьківський каталог
кожного операнда має вже існувати, а сам операнд — ні; операнд, який не
вдається створити, повідомляється, і наступний однаково створюється.

З `-p` спочатку створюється кожен відсутній предок, від найзовнішнього
до найглибшого, і операнд (або предок), що вже існує як каталог, не є
помилкою. Предок, що існує як файл, усе одно спричиняє помилку: ніщо
ніколи не замінюється мовчки.

Новий каталог отримує режим `a=rwx` за вирахуванням umask. З `-m` кожен
створений каталог-операнд натомість отримує рівно `MODE`, хай яким є
umask: вісімкове значення або символьні вирази, як їх читає `chmod`,
починаючи з `a=rwx`. Відсутній предок, якого створює `-p`, зберігає
права запису й пошуку для власника, хоч би що вказував umask, тож
каталог під ним завжди можна створити. Каталог, створений усередині
каталогу з бітом set-group-ID, зберігає успадкований біт, якщо `MODE`
його не називає. Операнд, що вже існує, зберігає свій режим. `--`
завершує розбір параметрів: кожен наступний аргумент — це шлях.

## OPTIONS

- `-m, --mode=MODE` — надавати кожному створеному каталогу-операнду
  режим `MODE`, вісімковий або символьний, як у `chmod`, замість `a=rwx`
  за вирахуванням umask.
- `-p, --parents` — створювати відсутні батьківські каталоги; операнд,
  що вже є каталогом, не є помилкою.
- `-v, --verbose` — повідомляти про кожен створений каталог як
  `mkdir: created directory 'кат'`.
- `-h, -?` — показати коротку довідку цієї команди (також `--help`).

## EXAMPLES

- `mkdir Notes` — створити один каталог у поточному каталозі.
- `mkdir -p Projects/os/build` — створити весь ланцюжок, пропускаючи
  частини, що вже існують.
- `mkdir -pv Home:/tools/bin` — створити під коренем псевдоніма,
  повідомляючи про кожен новий каталог.
- `mkdir -m 700 Private` — створити каталог, яким може користуватися
  лише його власник.

## EXIT STATUS

- `0` — кожен каталог створено (або, з `-p`, він уже існував).
- `1` — помилка файлової системи чи виводу або режим, який не вдалося
  надати; причину надруковано в стандартний потік помилок. Нерозпізнаний
  командний рядок або `MODE`, що не є режимом, теж завершується з `1`.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, наприклад
  `uk-UA`).
