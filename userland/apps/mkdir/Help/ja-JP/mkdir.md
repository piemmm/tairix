## NAME

mkdir — ディレクトリを作る

## SYNOPSIS

`mkdir [-pv] [-m MODE] [--] directory...`

## DESCRIPTION

各ディレクトリオペランドを順に作成します。`-p` がなければ、各オペランドの
親はすでに存在していなければならず、オペランド自体は存在していてはなりま
せん。作成できないオペランドは報告され、それでも次のオペランドは
作成されます。

`-p` があれば、欠けている祖先が外側から順に先に作成され、すでにディレクト
リとして存在するオペランド（や祖先）はエラーになりません。ファイルとして
存在する祖先は依然として失敗します。何かが黙って置き換えられることは決し
てありません。

新しいディレクトリは、`a=rwx` から umask を除いたモードになります。`-m` が
あれば、作成される各ディレクトリオペランドには、umask にかかわらず、代わり
に正確に `MODE` が与えられます。これは 8 進値またはシンボリック節
で、`chmod` と同じように `a=rwx` を起点として読まれます。`-p` が作成する欠
けている祖先は、umask がどうであれ所有者の書き込みと検索の許可を保つので、
その下のディレクトリは必ず作成できます。set-group-ID ビットを持つディレク
トリの中に作成されたディレクトリは、`MODE` がそのビットを指定しない限り、
継承したビットを保ちます。すでに存在するオペランドはそのモードを保ちま
す。`--` はオプション解析を終え、以降のすべての引数はパスです。

## OPTIONS

- `-m, --mode=MODE` — 作成する各ディレクトリオペランドに、`a=rwx` から
  umask を除いたモードではなく、`chmod` と同じく 8 進またはシンボリックで
  書いたモード `MODE` を与える。
- `-p, --parents` — 欠けている親ディレクトリを作る。すでにディレクトリで
  あるオペランドはエラーではない。
- `-v, --verbose` — 作成した各ディレクトリを
  `mkdir: created directory 'dir'` の形で報告する。
- `-h, -?` — このコマンド自身の短いヘルプを表示する（`--help` も可）。

## EXAMPLES

- `mkdir Notes` — 現在のディレクトリにディレクトリを一つ作る。
- `mkdir -p Projects/os/build` — 既存の部分を飛ばして連鎖全体を作る。
- `mkdir -pv Home:/tools/bin` — エイリアスルートの下に作り、新しいディレ
  クトリを逐一報告する。
- `mkdir -m 700 Private` — 所有者だけが使えるディレクトリを作る。

## EXIT STATUS

- `0` — すべてのディレクトリを作成した（または `-p` の下ですでに存在し
  た）。
- `1` — ファイルシステムまたは出力の失敗、あるいは付与できなかったモード。
  理由は標準エラーに印字される。解釈できなかったコマンド行も、モードとして
  読めない `MODE` も `1` で終了する。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
