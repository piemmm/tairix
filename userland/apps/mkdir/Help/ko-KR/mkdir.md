## NAME

mkdir — 디렉터리 만들기

## SYNOPSIS

`mkdir [-pv] [-m MODE] [--] directory...`

## DESCRIPTION

각 디렉터리 피연산자를 순서대로 만듭니다. `-p`가 없으면 각 피연산자의
부모는 이미 존재해야 하고 피연산자 자체는 존재하면 안 됩니다. 만들 수
없는 피연산자는 보고되고, 다음 피연산자는 그래도 만들어집니다.

`-p`가 있으면 빠져 있는 조상들이 가장 바깥쪽부터 먼저 만들어지고, 이미
디렉터리로 존재하는 피연산자(또는 조상)는 오류가 아닙니다. 파일로 존재하는
조상은 여전히 실패합니다. 어떤 것도 조용히 대체되지 않습니다.

새 디렉터리는 `a=rwx`에서 umask를 뺀 모드를 받습니다. `-m`이 있으면
만들어지는 각 디렉터리 피연산자는 umask와 상관없이 대신 정확히 `MODE`를
받습니다. 이는 8진수 값 또는 기호 절이며, `chmod`가 읽는 방식대로
`a=rwx`에서 출발해 읽힙니다. `-p`가 만드는 빠져 있는 조상은 umask가 어떻든
소유자의 쓰기 및 검색 권한을 유지하므로, 그 아래의 디렉터리를 언제나 만들
수 있습니다. set-group-ID 디렉터리 안에 만들어진 디렉터리는 `MODE`가 그
비트를 지정하지 않는 한 물려받은 비트를 유지합니다. 이미 존재하는
피연산자는 자신의 모드를 유지합니다. `--`는 옵션 해석을 끝내며, 이후의
모든 인수는 경로입니다.

## OPTIONS

- `-m, --mode=MODE` — 만들어지는 각 디렉터리 피연산자에 `a=rwx`에서
  umask를 뺀 모드 대신 `chmod`에서처럼 8진수 또는 기호로 쓴 모드 `MODE`를
  부여합니다.
- `-p, --parents` — 빠진 부모 디렉터리를 만듭니다. 이미 디렉터리인
  피연산자는 오류가 아닙니다.
- `-v, --verbose` — 만들어진 각 디렉터리를
  `mkdir: created directory 'dir'` 형식으로 보고합니다.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다(`--help`도 가능).

## EXAMPLES

- `mkdir Notes` — 현재 디렉터리에 디렉터리 하나를 만듭니다.
- `mkdir -p Projects/os/build` — 이미 있는 부분은 건너뛰며 사슬 전체를
  만듭니다.
- `mkdir -pv Home:/tools/bin` — 별칭 루트 아래에 만들고 새 디렉터리를
  하나씩 보고합니다.
- `mkdir -m 700 Private` — 소유자만 사용할 수 있는 디렉터리를 만듭니다.

## EXIT STATUS

- `0` — 모든 디렉터리가 만들어졌습니다(또는 `-p`에서 이미 존재했습니다).
- `1` — 파일 시스템 또는 출력 실패, 또는 부여할 수 없었던 모드. 이유가
  표준 오류에 인쇄됩니다. 이해하지 못한 명령줄이나 모드가 아닌 `MODE`도
  `1`로 끝납니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
