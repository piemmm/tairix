## NAME

mkdir — 创建目录

## SYNOPSIS

`mkdir [-pv] [-m MODE] [--] directory...`

## DESCRIPTION

按顺序创建每个目录操作数。没有 `-p` 时，每个操作数的父目录必须已经存在，
而操作数本身必须不存在；无法创建的操作数会被报告，下一个仍会被创建。

有 `-p` 时，先创建每个缺失的祖先，自最外层开始；已经作为目录存在的操作数
（或祖先）不是错误。以文件形式存在的祖先仍然失败：任何东西都不会被悄悄替
换。

新目录的模式为 `a=rwx` 减去 umask。有 `-m` 时，每个被创建的目录操作数改为
恰好获得 `MODE`，无论 umask 如何：即八进制值或符号子句，按 `chmod` 的读法
从 `a=rwx` 开始解读。`-p` 所创建的缺失祖先，无论 umask 怎样设置，都保留其
所有者的写和搜索权限，因此其下的目录总能被创建。在带有 set-group-ID 位的目
录中创建的目录会保留它继承的该位，除非 `MODE` 指明了该位。已经存在的操作数
保持其模式。`--` 结束选项解析：之后的每个参数都是路径。

## OPTIONS

- `-m, --mode=MODE` — 给每个被创建的目录操作数赋予模式 `MODE`（八进制或符
  号形式，同 `chmod`），而不是 `a=rwx` 减去 umask。
- `-p, --parents` — 创建缺失的父目录；已是目录的操作数不是错误。
- `-v, --verbose` — 以 `mkdir: created directory 'dir'` 报告每个创建的目
  录。
- `-h, -?` — 显示本命令自身的简短帮助（也可用 `--help`）。

## EXAMPLES

- `mkdir Notes` — 在当前目录中创建一个目录。
- `mkdir -p Projects/os/build` — 创建整条链，跳过已经存在的部分。
- `mkdir -pv Home:/tools/bin` — 在别名根之下创建，并报告每个新目录。
- `mkdir -m 700 Private` — 创建一个只有其所有者可以使用的目录。

## EXIT STATUS

- `0` — 每个目录都已创建（或在 `-p` 下本已存在）。
- `1` — 文件系统或输出失败，或无法赋予的模式；原因打印在标准错误上。无法理
  解的命令行，或不是模式的 `MODE`，同样以 `1` 退出。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
