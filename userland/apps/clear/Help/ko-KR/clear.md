## NAME

clear — 터미널 화면 지우기

## SYNOPSIS

`clear [-x]`

## DESCRIPTION

커서를 왼쪽 위 모서리로 옮기고 전체 표시를 지우는 시퀀스를 써서 빈 화면을
남깁니다. 어떤 시퀀스를 쓸지는 `TERM`에 지정된 터미널이 결정합니다. 지울
수 없는 터미널(알 수 없는 `TERM`은 「dumb」 기준선으로 격하됩니다)에서는
터미널이 쓰레기로 표시할 바이트를 출력하는 대신 명령이 실패합니다.

터미널이 지원하는 경우 화면 위쪽에 보관하는 줄(스크롤백)도 함께 지우므로,
화면에 있던 내용으로는 스크롤해서 되돌아갈 수 없습니다.

## OPTIONS

- `-x` — 스크롤백을 남기고 화면만 지웁니다.
- `-h, -?` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `clear` — 화면을 지웁니다.

## EXIT STATUS

- `0` — 지우기 시퀀스를 썼습니다.
- `1` — 터미널이 지울 수 없거나 출력을 전달할 수 없었습니다. 이해하지 못한
  명령줄도 `1`로 끝납니다.

## ENVIRONMENT

- `TERM` — 그 지우기 시퀀스를 쓰는 터미널.
- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
