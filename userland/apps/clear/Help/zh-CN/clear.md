## NAME

clear — 清除终端屏幕

## SYNOPSIS

`clear [-x]`

## DESCRIPTION

写出把光标移到左上角并擦除整个显示的序列，留下一个空屏幕。写出哪个序列由
`TERM` 命名的终端决定；无法清屏的终端（未知的 `TERM` 会退化为「dumb」基
线）会使命令失败，而不是打印终端会显示为乱码的字节。

在终端支持的情况下，也会擦除它保留在屏幕上方的行（即回滚缓冲区），因此
无法再回滚查看屏幕上曾有的任何内容。

## OPTIONS

- `-x` — 保留回滚缓冲区：只擦除屏幕。
- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `clear` — 清屏。

## EXIT STATUS

- `0` — 清屏序列已写出。
- `1` — 终端无法清屏，或输出无法送达。无法理解的命令行同样以 `1` 退出。

## ENVIRONMENT

- `TERM` — 写出其清屏序列的终端。
- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
