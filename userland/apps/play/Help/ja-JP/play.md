## NAME

play — サウンドファイルを再生する

## SYNOPSIS

`play [option...] file...`

## DESCRIPTION

各ファイルを順に出力先で再生します。各ファイルは一切の権限を持たない隔離された
プロセスでデコードされるため、悪意あるファイルにできるのはせいぜい自身のデコードを
終わらせることだけです。そのファイルは理由を示して除外され、リストの残りは再生され
ます。AU、WAV、FLAC のファイルを読み込みます。FLAC は単体でも Ogg の中でも
読み込みます。

サンプリングレート、サンプル形式、チャンネル配置が同じ連続したファイルは、一つの
ストリームで途切れなく再生されます。形の異なるファイルは、キューにあるものが再生し
終わるのを待ってから、自分のストリームを開きます。

標準入力が端末のとき、`play` は全画面のインターフェースを描きます。再生中のファイル、
位置、レベルとチャンネルごとのメーター、そしてリストです。再生はこれに依存しません。
バックグラウンドに送られると `play` は再生を続けて端末を返し、フォアグラウンドに戻る
と再び描画します。インターフェースがないときは、端末の標準エラーに一行で進行状況を
表示します。

インターフェースは次のキーを受け付けます。スペースまたは `p` で一時停止と再開、左右
の矢印で十秒移動、`n` または `>` で次のファイル、`b` または `<` でこのファイルの先頭
へ（最初の三秒以内なら前のファイルへ）戻ります。`+`、`=` または上矢印で三デシベル
大きく、`-`、`_` または下矢印で三デシベル小さくします。`q` または Ctrl-C で停止し、
Ctrl-Z でストリームを一時停止してから中断します。

ストリームのレベルは減衰です。ストリームはフルスケールを超えて上げられないため、
`--gain` とレベルキーは 0 dB より上には行きません。より大きく鳴らすには出力先の
音量を上げてください。

時間は `[[HH:]MM:]SS[.fraction]` と書きます——`90`、`1:30`、`1:02:03`、`12.5`。

標準情報ストリーム（fd 3）に、`play` は再生する各ファイルについて `schema` レコード
を、除外または途中で終わった各ファイルについて `omission` レコードを、終了時に
`summary` レコードを書きます。

## OPTIONS

- `-q, --quiet` — インターフェースも進行状況の行も表示しない。
- `-v, --verbose` — 各ファイルの形式と長さを標準エラーに表示する。
- `--ui, --no-ui` — インターフェースを描く、または決して描かない。端末がない
  ときの `--ui` は拒否される。
- `-d, --device <sink>` — 出力先：`audio:sink/default`、今回の起動での
  `audio:sink/<id>`、またはデバイスの位置を示す `audio:sink/<location>`。
  いずれも `--list-devices` が示すもの。
- `-g, --gain <dB>` — ストリームのレベル。0 以下、百分の一単位。
- `-s, --start <time>` — 各ファイルをこの時間から始める。
- `-t, --duration <time>` — 各ファイルをこの長さだけ再生する。
- `-l, --loop[=N]` — リストを全部で N 回、N がなければ無限に再生する。
- `--list-devices` — このセッションの出力先を ID と位置つきで一覧して終了
  する。
- `-h, -?, --help` — このコマンドの短いヘルプを表示する。
- `--version` — バージョンを表示して終了する。

## EXAMPLES

- `play song.wav` — ファイルを一つ再生し、端末にインターフェースを表示する。
- `play -q intro.au song.wav &` — リストをバックグラウンドで再生する。
- `play -s 1:30 -t 20 song.wav` — 一分三十秒から二十秒間再生する。
- `play -l3 -g -6 loop.wav` — ファイルを三回、六デシベル下げて再生する。
- `play --list-devices` — 出力先を見る。

## EXIT STATUS

- `0` — すべてのファイルを再生した、または除外なしに再生を停止した。
- `1` — 再生できないファイルがあった、または再生を続けられなかった。
- `2` — コマンドラインを理解できなかった。

## ENVIRONMENT

- `TERM` — インターフェースが描画する端末。
- `LANG` — 短いヘルプの優先ロケール（`fr-FR` のような BCP-47 タグ）。
