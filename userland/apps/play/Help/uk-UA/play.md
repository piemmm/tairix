## NAME

play — відтворення звукових файлів

## SYNOPSIS

`play [option...] file...`

## DESCRIPTION

Відтворює кожен файл по черзі на виході. Кожен файл декодується в ізольованому
процесі, що не має жодних повноважень, тож ворожий файл може щонайбільше
завершити власне декодування: його пропускають із зазначенням причини, а решту
списку відтворюють. Читаються файли AU, WAV і FLAC,
FLAC — окремо або в Ogg.

Послідовні файли з однаковою частотою, форматом відліку й розкладкою каналів
звучать без пауз, в одному потоці. Файл іншої форми чекає, доки прозвучить усе,
що стоїть у черзі, і тоді відкриває власний потік.

Коли стандартний ввід є терміналом, `play` малює повноекранний інтерфейс: файл,
що звучить, позицію, рівень і індикатор для кожного каналу, а також список.
Відтворення від нього не залежить. Відправлений у фон, `play` грає далі й
повертає термінал; повернений на передній план, малює себе знову. Без
інтерфейсу він показує поступ одним рядком у потоці помилок термінала.

Інтерфейс приймає такі клавіші: Пробіл або `p` — пауза й продовження; стрілки
ліворуч і праворуч — перехід на десять секунд; `n` або `>` — наступний файл;
`b` або `<` — на початок цього файлу або, протягом його перших трьох секунд, до
попереднього; `+`, `=` або стрілка вгору — на три децибели гучніше, `-`, `_` або
стрілка вниз — на три тихіше; `q` або Ctrl-C — зупинка; Ctrl-Z — призупинення
після паузи потоку.

Рівень потоку — це ослаблення: потік не можна підняти вище повної шкали, тому
`--gain` і клавіші рівня не йдуть вище 0 дБ. Щоб грати гучніше, підніміть
гучність виходу.

Час записують як `[[HH:]MM:]SS[.fraction]` — `90`, `1:30`, `1:02:03` або `12.5`.

У стандартну інформацію (fd 3) `play` пише запис `schema` для кожного файлу,
який відтворює, запис `omission` для кожного пропущеного чи обірваного файлу і
запис `summary` наприкінці.

## OPTIONS

- `-q, --quiet` — без інтерфейсу й рядка поступу.
- `-v, --verbose` — формат і тривалість кожного файлу в потоці помилок.
- `--ui, --no-ui` — малювати інтерфейс або ніколи; `--ui` без термінала
  відхиляється.
- `-d, --device <sink>` — вихід: `audio:sink/default`, `audio:sink/<id>`
  для цього запуску або `audio:sink/<location>`, хоч би де був пристрій,
  як їх називає `--list-devices`.
- `-g, --gain <dB>` — рівень потоку, 0 або нижче, до сотої.
- `-s, --start <time>` — починати кожен файл із цього часу.
- `-t, --duration <time>` — відтворювати стільки кожного файлу.
- `-l, --loop[=N]` — відтворити список N разів загалом, а без N — безкінечно.
- `--list-devices` — назвати виходи цього сеансу, кожен за
  ідентифікатором і розташуванням, і завершити роботу.
- `-h, -?, --help` — показати коротку довідку цієї команди.
- `--version` — показати версію й завершити роботу.

## EXAMPLES

- `play song.wav` — відтворити файл з інтерфейсом у терміналі.
- `play -q intro.au song.wav &` — відтворити список у фоні.
- `play -s 1:30 -t 20 song.wav` — двадцять секунд, починаючи з півтори хвилини.
- `play -l3 -g -6 loop.wav` — відтворити файл тричі, на шість децибелів тихіше.
- `play --list-devices` — переглянути виходи.

## EXIT STATUS

- `0` — кожен файл відтворено, або відтворення зупинено без пропущених файлів.
- `1` — файл не вдалося відтворити, або відтворення не змогло тривати.
- `2` — командний рядок не зрозуміло.

## ENVIRONMENT

- `TERM` — термінал, для якого малює інтерфейс.
- `LANG` — бажана мова короткої довідки (тег BCP-47, наприклад `fr-FR`).
