## NAME

play — 소리 파일 재생

## SYNOPSIS

`play [option...] file...`

## DESCRIPTION

각 파일을 차례로 출력 장치에서 재생합니다. 모든 파일은 아무 권한도 갖지 않은 격리된
프로세스에서 디코딩되므로, 악의적인 파일이 할 수 있는 일은 기껏해야 자신의 디코딩을
끝내는 것뿐입니다. 그 파일은 이유와 함께 제외되고 목록의 나머지는 재생됩니다. AU, WAV,
FLAC 파일을 읽으며, FLAC는 단독 파일이든 Ogg 안에 든 것이든 읽습니다.

샘플링 속도, 샘플 형식, 채널 배치가 같은 연속된 파일은 하나의 스트림에서 끊김 없이
재생됩니다. 형태가 다른 파일은 대기열에 있는 것이 다 재생되기를 기다린 뒤 자신의
스트림을 엽니다.

표준 입력이 터미널이면 `play`는 전체 화면 인터페이스를 그립니다. 재생 중인 파일,
위치, 레벨과 채널별 미터, 그리고 목록입니다. 재생은 이 인터페이스에 의존하지 않습니다.
백그라운드로 보내면 `play`는 계속 재생하며 터미널을 돌려주고, 포그라운드로 가져오면
다시 그립니다. 인터페이스가 없으면 터미널의 표준 오류에 한 줄로 진행 상황을 알립니다.

인터페이스는 다음 키를 받습니다. 스페이스나 `p`는 일시 정지와 재개, 왼쪽과 오른쪽
화살표는 10초 이동, `n`이나 `>`는 다음 파일, `b`나 `<`는 이 파일의 처음으로(처음 3초
안이면 이전 파일로) 돌아갑니다. `+`, `=` 또는 위쪽 화살표는 3데시벨 크게, `-`, `_`
또는 아래쪽 화살표는 3데시벨 작게 합니다. `q`나 Ctrl-C는 멈추고, Ctrl-Z는 스트림을
먼저 일시 정지한 뒤 중단합니다.

스트림의 레벨은 감쇠입니다. 스트림은 최대 레벨 위로 올릴 수 없으므로 `--gain`과 레벨
키는 0 dB를 넘지 않습니다. 더 크게 들으려면 출력 장치의 음량을 올리십시오.

시간은 `[[HH:]MM:]SS[.fraction]`로 씁니다 — `90`, `1:30`, `1:02:03`, `12.5`.

표준 정보 스트림(fd 3)에 `play`는 재생하는 파일마다 `schema` 레코드를, 제외되거나
일찍 끝난 파일마다 `omission` 레코드를, 끝날 때 `summary` 레코드를 씁니다.

## OPTIONS

- `-q, --quiet` — 인터페이스도 진행 줄도 표시하지 않는다.
- `-v, --verbose` — 각 파일의 형식과 길이를 표준 오류에 표시한다.
- `--ui, --no-ui` — 인터페이스를 그리거나 절대 그리지 않는다. 터미널 없이 `--ui`를
  쓰면 거부된다.
- `-d, --device <sink>` — 출력 장치: `audio:sink/default`, 이번 부팅에서의
  `audio:sink/<id>`, 또는 장치의 위치를 가리키는 `audio:sink/<location>`.
  모두 `--list-devices`가 알려 주는 것.
- `-g, --gain <dB>` — 스트림의 레벨, 0 이하, 100분의 1 단위.
- `-s, --start <time>` — 각 파일을 이 시간부터 시작한다.
- `-t, --duration <time>` — 각 파일을 이만큼 재생한다.
- `-l, --loop[=N]` — 목록을 모두 N번, N이 없으면 끝없이 재생한다.
- `--list-devices` — 이 세션의 출력 장치를 ID와 위치와 함께 나열하고
  끝낸다.
- `-h, -?, --help` — 이 명령의 짧은 도움말을 보인다.
- `--version` — 버전을 보이고 끝낸다.

## EXAMPLES

- `play song.wav` — 파일 하나를 재생하고 터미널에 인터페이스를 표시한다.
- `play -q intro.au song.wav &` — 목록을 백그라운드에서 재생한다.
- `play -s 1:30 -t 20 song.wav` — 1분 30초 지점부터 20초를 재생한다.
- `play -l3 -g -6 loop.wav` — 파일을 세 번, 6데시벨 낮춰 재생한다.
- `play --list-devices` — 출력 장치를 본다.

## EXIT STATUS

- `0` — 모든 파일을 재생했거나, 제외된 파일 없이 재생을 멈췄다.
- `1` — 재생할 수 없는 파일이 있었거나, 재생을 계속할 수 없었다.
- `2` — 명령줄을 이해하지 못했다.

## ENVIRONMENT

- `TERM` — 인터페이스가 그리는 터미널.
- `LANG` — 짧은 도움말의 선호 로캘(`fr-FR` 같은 BCP-47 태그).
