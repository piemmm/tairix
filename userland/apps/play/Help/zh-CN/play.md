## NAME

play — 播放声音文件

## SYNOPSIS

`play [option...] file...`

## DESCRIPTION

依次在一个输出上播放每个文件。每个文件都在一个不持有任何权限的隔离进程中解码，
因此恶意文件至多只能终止它自己的解码：它会被跳过并说明原因，列表其余部分照常播放。
可读取 AU、WAV 和 FLAC 文件，FLAC 可为原生格式或封装于 Ogg 中。

采样率、采样格式和声道布局相同的相邻文件在同一个流中无缝连续播放。形状不同的文件
会等待队列中的内容播放完毕，然后打开自己的流。

当标准输入是终端时，`play` 绘制一个全屏界面：正在播放的文件、播放位置、电平与每个
声道的电平表，以及文件列表。播放并不依赖该界面。转入后台时，`play` 继续播放并交还
终端；回到前台时，它会重新绘制自己。没有界面时，它在终端的标准错误上以一行显示进度。

界面接受以下按键：空格或 `p` 暂停与继续；左右方向键前后跳转十秒；`n` 或 `>` 转到下
一个文件；`b` 或 `<` 回到本文件开头，若在开头三秒内则回到上一个文件；`+`、`=` 或上
方向键增大三分贝，`-`、`_` 或下方向键减小三分贝；`q` 或 Ctrl-C 停止；Ctrl-Z 在暂停
流之后挂起。

流的电平是衰减：流不能被提升到满刻度以上，因此 `--gain` 和电平键最高只到 0 dB。若要
更响，请调高输出的音量。

时间写作 `[[HH:]MM:]SS[.fraction]`——`90`、`1:30`、`1:02:03` 或 `12.5`。

在标准信息流（fd 3）上，`play` 为播放的每个文件写一条 `schema` 记录，为每个被跳过
或提前结束的文件写一条 `omission` 记录，并在结束时写一条 `summary` 记录。

## OPTIONS

- `-q, --quiet` — 不显示界面，也不显示进度行。
- `-v, --verbose` — 在标准错误上显示每个文件的格式与时长。
- `--ui, --no-ui` — 绘制界面，或永不绘制；没有终端时 `--ui` 会被拒绝。
- `-d, --device <sink>` — 播放输出：`audio:sink/default`、本次启动有效的
  `audio:sink/<id>`，或无论设备在何处都有效的 `audio:sink/<location>`，
  均以 `--list-devices` 所列为准。
- `-g, --gain <dB>` — 流的电平，0 或以下，精确到百分之一。
- `-s, --start <time>` — 每个文件从此时间开始。
- `-t, --duration <time>` — 每个文件播放这么长时间。
- `-l, --loop[=N]` — 列表共播放 N 次，不带 N 则无限循环。
- `--list-devices` — 列出本会话可用的输出及其编号和位置，然后退出。
- `-h, -?, --help` — 显示本命令的简短帮助。
- `--version` — 显示版本，然后退出。

## EXAMPLES

- `play song.wav` — 播放一个文件，在终端上显示界面。
- `play -q intro.au song.wav &` — 在后台播放一个列表。
- `play -s 1:30 -t 20 song.wav` — 从一分半处开始播放二十秒。
- `play -l3 -g -6 loop.wav` — 将一个文件播放三次，降低六分贝。
- `play --list-devices` — 查看输出。

## EXIT STATUS

- `0` — 每个文件都已播放，或在未跳过任何文件的情况下停止了播放。
- `1` — 某个文件无法播放，或播放无法继续。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `TERM` — 界面所绘制的终端类型。
- `LANG` — 简短帮助的首选语言（BCP-47 标签，如 `fr-FR`）。
