## NAME

mv — 移动（重命名）文件和目录

## SYNOPSIS

`mv [-finvT] [-t dir] [--] source... dest`

## DESCRIPTION

把每个来源操作数移动到目的地。只有一个来源、且目的地不指目录时，来源被重
命名为那个确切路径。当目的地指向已存在的目录 — 以及来源多于一个的任何时
候 — 每个来源都以其自身的基本名被移动*进*该目录。

同一卷内的移动是保留节点标识的原子重命名。跨卷移动信守同样的承诺：先在目
标旁边构建副本，在其完整之前只有其属主可以读取，写入磁盘，再一步重命名到
位，之后才删除已复制的内容——因此在移动完整之前，目标始终保持原有内容，失
败或崩溃都不会丢失任何东西。复制期间加入源中的文件或被更改的文件，会连同
包含它的目录一起留在原处，并被报告；在不记录更改计数、或时间记录粗略
（FAT 的两秒）的卷上，在该粒度内进行的同等长度的重写可能不会被察觉。无论
哪种情况，目录只能替换空目录，除目录外没有任何东西能替换目录，目录也绝不
会移入其自身的子树。

已存在的目的地默认被覆盖，带 `-n` 时被保留（与 GNU 相同，会提示
`not replacing` 并使运行失败），带 `-i` 时在标准错误流上询问（被拒绝的询
问跳过该次移动并使运行失败；无法读取的回答绝不被当作同意）。无法移动的操
作数会被报告，下一个仍会被移动。`--` 结束选项解析：之后的每个参数都是路
径。

只要目标能够保存，副本会带上每个文件的空洞、扩展属性（RISC OS 文件类
型、Mac 类型和创建者）、权限位和属主，并把符号链接作为保存相同目标的链接
移动，而不是其所指的内容。交还给其他属主的文件到达时不带 set-ID 位，因为
属主变更时系统会清除它们；移动者无权交还的文件会归移动者所有，在移动者可
以保留时仍属于原来的组，并去掉其未能保留的属主或组的 set-ID 位。时间戳不
会带上：本系统没有设置时间戳的调用。目标无法保存的属性会在源被彻底删除之
前，于运行结束时以一条警告，并在标准信息流上以一条 `omission` 记录报告。

## OPTIONS

- `-f, --force` — 覆盖前从不询问。`-f`、`-i` 和 `-n` 中以最后给出的为
  准。
- `-i, --interactive` — 覆盖已存在的目的地前询问；只有以 `y`/`Y` 开头的
  回答才算同意。
- `-n, --no-clobber` — 从不覆盖已存在的目的地；每个被保留的目的地都报告
  为 `not replacing 'dest'`。
- `-v, --verbose` — 以 `renamed 'source' -> 'dest'` 报告每次移动；跨卷移
  动则与 GNU 相同，逐项报告：每个目录报告 `created directory 'dest'`，其
  余每项在复制时报告 `copied 'source' -> 'dest'`，然后在各来源消失时逐一
  报告 `removed 'source'` 或 `removed directory 'source'`。
- `-t dir, --target-directory=dir` — 把每个来源移动进 `dir`，它必须是已
  存在的目录。值可紧跟（`-tdir`、`--target-directory=dir`）或作为下一个
  参数。
- `-T, --no-target-directory` — 把目的地当作普通文件；恰好允许一个来源。
  不能与 `-t` 组合。
- `-h, -?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `mv draft.txt final.txt` — 重命名一个文件。
- `mv -v a.txt b.txt Archive` — 把两个文件都移动进 `Archive`，并报告每次
  移动。
- `mv -n new.cfg current.cfg` — 仅当目的地尚不存在时安装文件（若已存在则
  提示 `not replacing`）。

## EXIT STATUS

- `0` — 每次移动都成功。
- `1` — 有操作数无法移动、`-n` 保留了目的地、`-i` 询问被拒绝、源中的某些
  内容在移动时发生变化而被保留，或询问或输出失败；每个失败的原因都打印在
  标准错误上。无法理解的命令行同样以 `1` 退出。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
