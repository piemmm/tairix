## NAME

Draw — 矢量绘图编辑器

## SYNOPSIS

`Draw`

## DESCRIPTION

在桌面窗口中绘制和编辑矢量绘图：路径、矩形、椭圆、星形与多边形、直线、
手绘曲线和文字，分组、分层地放在一张页面上。带着文档启动时——从文件管理器、
从桌面，或把文件拖放到图标栏中它的图标上——它会为该文档打开一个窗口。单独
启动时，它在一张 A4 页面上打开一幅新绘图。每个文档都是同一个程序的一个窗口；
关闭最后一个窗口后它仍留在图标栏上，图标菜单中的“退出”一行将它结束。

Draw 打开并保存 SVG。一幅绘图会保留它的页面与单位、图层、组和剪切、每条路径、
每个形状和每段文字、纯色以及线性和径向渐变、每个对象的不透明度、虚线、拐角、
端点和箭头、参考线和网格，以及绘图的标题。如果文件含有绘图无法保留的内容——
其中包括滤镜效果、蒙版、图案填充、标记、嵌入图片、混合文字样式、动画或脚本——
它会以只读方式打开，状态栏会说出其中含有什么，而“保存”会要求一个新名称，
使原文件永不被覆盖。“保存副本”把绘图写成 PDF、PNG——页面按其本身大小，较长
一边最多 8192 像素——或 SVG，不改动文档本身的文件。

工具箱沿窗口左侧排列，检查器沿右侧排列，状态栏沿底部：它以页面单位显示指针
位置和所选内容的大小，并说明上一条命令做了什么。顶部的工具条说明手中工具的
用法并显示缩放比例：按下缩放比例会打开一个缩放菜单。以页面单位标注的标尺沿
画布的上边和左边，滚动条沿右边和下边。指针停在工具按钮上时会显示它的名称和
选择它的按键。

工具及选择它们的按键为：选择（`V`）、节点（`A`）、矩形（`R`）、椭圆（`E`）、
星形与多边形（`S`）、直线（`L`）、钢笔（`B`）、铅笔（`P`）、文字（`T`）、
吸管（`I`）、缩放（`Z`）和抓手（`H`）。

选择工具按一下即选中一个对象，组则整体选中；按住 Shift 可把对象加入所选或
从中移出。在空白画布上按下会拖出一个选框，选中完全位于其中的对象，按住 Alt
则选中它接触到的一切。拖动所选内容会移动它，按住 Shift 时只沿一个轴移动，
按住 Alt 时移动的是一个副本。它的八个手柄以对面的手柄为基点缩放它，按住 Shift
拖动角手柄可保持比例；在角的稍外侧拖动会使它绕中心旋转，按住 Shift 时以
15 度为步进。方向键使它移动一个像素，按住 Shift 时移动十个。

节点工具显示所选路径的节点及其曲线的手柄：拖动节点即可移动它，拖动手柄即可
弯曲它的曲线；平滑节点的另一个手柄会保持在一条线上跟随。矩形、椭圆、星形和
直线都通过拖动绘制：Shift 使各边相等——正方形、圆、角度为 15 度倍数的直线——
Alt 则从拖动开始处向外绘制。星形从其中心向外绘制；它的角数、内半径以及是否
为多边形，在检查器的“形状”选项卡中设置，新矩形的圆角也在那里设置。

钢笔逐个放置节点来绘制路径：单击得到尖角，拖动得到平滑节点及其曲线。单击
第一个节点会闭合路径，按 Enter 或选择其他工具则让它保持开放并结束；`Delete`
或 `Backspace` 撤回最后一个节点，Escape 放弃该路径。铅笔用于手绘，松开时
它的线条会拟合为平滑曲线。文字工具在单击处开始一段文字，或编辑被单击的文字：
输入文字，Enter 开始新的一行，方向键、Home 和 End 移动插入点，按 Escape 或在
别处单击会把这次输入作为一次更改结束；留空的文字会被删除。吸管把被单击对象的
样式赋予所选内容以及接下来绘制的内容。缩放工具在单击处放大，按住 Alt 缩小，
用它拖出的框会充满窗口。抓手拖动画布；无论使用哪种工具，用中键拖动或按住
空格键拖动也一样。

滚轮滚动画布，按住 Shift 时横向滚动；按住 Ctrl 时以指针为中心缩放，就像在
触控板或触摸屏上双指捏合一样。“视图 ▸ 适合页面”和“适合所选内容”使它们适合
窗口，“实际大小”以 100% 显示绘图；缩放范围为 1% 到 25600%。

检查器有四个选项卡。“样式”设置所选内容的填充和描边——未选择任何内容时，
设置接下来绘制的内容：选择“填充”或“描边”，然后选择“无”或取色器中的颜色。
取色器提供饱和度与明度的方块和旁边的色相条、色环或滑块，以及颜色的数值和
不透明度；接着是描边的宽度、拐角（尖角、圆角或斜角）、端点（平头、圆头或
方头）、虚线（实线、虚线、点线或点划线）、起点和终点的箭头——每按一次依次切换
无、三角形、箭头、圆形和菱形——、填充规则（非零或奇偶），以及每个所选对象的
不透明度。“图层”列出各图层，最上层在前：按下一个图层即在其中绘制，按它的
“显示”按钮可显示或隐藏它；列表上方，“新建”添加图层，“删除”删除手中的图层，
“锁定”使其不被更改，“上移”和“下移”移动它。“对象”按左边和上边放置所选内容，
并把它缩放到给定的宽度和高度；对齐它——按左边、中心或右边，或按顶部、中部或
底部——并把三个或更多对象横向或纵向均匀分布。对象在其所选范围内对齐；单个
对象，或在打开“对齐页面”时任意数量的对象，在页面内对齐。“形状”包含矩形的
圆角、星形的角数和内半径以及是否为多边形，还有文字的字体族——无衬线、衬线或
等宽——、字号、粗体、斜体以及相对于原点的对齐方式。比窗口高的选项卡可以滚动。
正在选取的颜色、正在输入或步进调整的宽度以及不透明度，在变化时就显示在画布上，
稳定下来后成为一次可撤销的更改；Tab 移到下一个字段，Shift+Tab 移到上一个。

从标尺拖出会在画布上放置一条横向或纵向参考线；拖动参考线可移动它，拖回标尺
上即可删除。“视图 ▸ 网格”显示页面的网格。打开“吸附”时，绘制形状、用钢笔放置
节点、移动或缩放所选内容时，指针会吸附到参考线、页面的边缘和中心，以及显示中的
网格。“视图 ▸ 轮廓”把每个对象显示为其轮廓，使拥挤的绘图易于辨认。“页面”菜单
设置页面的纸张——A4、A3、A5、A6、A2、A1、A0、B5、B4、US Letter、US Legal、
Tabloid、Executive、两种屏幕尺寸和一个图标尺寸——在纵向与横向之间旋转页面，
给它白色背景或不加背景，并设置它的单位：像素、点、派卡、毫米、厘米或英寸。

“对象 ▸ 组合”把所选内容集合成一个组，“取消组合”将其拆开；“移到最前”、“上移”、
“下移”和“移到最后”在对象所在图层内重新排序；“翻转”和“旋转”镜像所选内容或将其
旋转四分之一圈。“锁定”和“隐藏”使对象不可触及，“全部解锁”和“全部显示”找回手中
图层里的这些对象。“路径”菜单把所选形状合并为一个（并集），从最下面的形状中
减去上面的形状（差集），保留它们重叠的部分（交集）或不重叠的部分（排除），
把形状和文字转为可编辑节点的路径，并把描边转为填充的轮廓。这些运算在窗口之外
完成，期间窗口仍可自由使用；如果在结果到达之前绘图已被更改，绘图保留其更改，
运算结果则不会被应用。

每次更改都是可撤销的一步，“撤销”和“重做”会说出所处理的步骤；最多保留 1000 步，
内存紧张时会更少。“复制”把所选内容以 SVG 放到剪贴板上，“粘贴”把剪贴板中的
内容加入手中的图层，保持其在页面上的位置，并处于选中状态。

Draw 不持有任何文件系统权限。它只编辑交给它的文件：用户可以更改的文件以可写
方式交给它，“保存”会写回该文件；其他文件以只读方式打开，“保存”会询问保存到
哪里。文档以及从剪贴板粘贴的绘图，都在一个完全没有访问能力的独立工作进程中
读取，因此恶意文件无法触及 Draw 能触及的任何东西。

在窗口中任意位置按下鼠标次键（右键）会打开它的菜单：文件、页面、编辑、对象、
路径、图层、视图和工具，每一项都是一个子菜单。窗口没有菜单栏。在有未保存的
更改时关闭窗口或退出，会先询问。用次键在关闭按钮上关闭窗口，还会在文件管理器
中、在包含该文件的文件夹里显示它的文件。

* `Ctrl+N` — 新建窗口；`Ctrl+O` — 打开文件
* `Ctrl+S` — 保存；`Ctrl+Shift+S` — 另存为；`Ctrl+Shift+E` — 保存为 PDF、PNG 或 SVG 副本
* `Ctrl+W` — 关闭窗口
* `Ctrl+Z` — 撤销；`Ctrl+Shift+Z` 或 `Ctrl+Y` — 重做
* `Ctrl+X`、`Ctrl+C`、`Ctrl+V` — 剪切、复制、粘贴；`Ctrl+D` — 再制
* `Delete` 或 `Backspace` — 删除所选内容
* `Ctrl+A` — 全选；`Ctrl+Shift+A` — 取消选择；`Escape` — 取消选择，或放弃正在绘制的路径
* `Ctrl+G` — 组合；`Ctrl+Shift+G` — 取消组合
* `Page Up` / `Page Down` — 上移或下移；`Home` / `End` — 移到最前或移到最后
* `Ctrl+[` / `Ctrl+]` — 向左或向右旋转
* `Ctrl+L` — 锁定；`Ctrl+Shift+L` — 解锁图层中的全部
* `Ctrl+H` — 隐藏；`Ctrl+Shift+H` — 显示图层中的全部
* `Ctrl+Shift+C` — 对象转为路径
* `Ctrl+Shift+N` — 新建图层；`Ctrl+Shift+Page Up` / `Ctrl+Shift+Page Down` — 上移或下移图层
* `Ctrl+=` 或 `Ctrl++` / `Ctrl+-` — 放大或缩小；`Ctrl+1` — 实际大小；`Ctrl+0` — 适合页面
* `Ctrl+'` — 显示或隐藏网格；`%` — 吸附开关
* `V`、`A`、`R`、`E`、`S`、`L`、`B`、`P`、`T`、`I`、`Z`、`H` — 各工具，依次排列
* 方向键 — 将所选内容移动一个像素；按住 `Shift` 移动十个
* `Space` — 按住时，用任何工具拖动画布
* `Ctrl` + 滚轮 — 以指针为中心缩放；`Shift` + 滚轮 — 横向滚动

## OPTIONS

`-h`, `-?`, `--help`
: 将此帮助写到标准输出并退出。

## EXIT STATUS

“退出”后为零。窗口通道、事件邮箱或桌面会话被拒绝时为非零，原因写在标准错误
流上。
