## NAME

Draw — 矢量绘图编辑器

## SYNOPSIS

`Draw`

## DESCRIPTION

在桌面窗口中绘制和编辑矢量绘图：路径、矩形、椭圆、星形与多边形、直线、
手绘曲线和文字，分组、分层地放在一张页面上。带着文档启动时——从文件管理器、
从桌面，或把文件拖放到图标栏中它的图标上——它会为该文档打开一个窗口。单独
启动时，它在一张 A4 页面上打开一幅新绘图。每个文档都是同一个程序的一个窗口；
关闭最后一个窗口后它仍留在图标栏上，图标菜单中的“退出”一行将它结束。

Draw 能打开 SVG、RISC OS 的 Draw 文件和 PDF，并按文件名所示的格式，把绘图保存
为 SVG、RISC OS 的 Draw 文件或 PDF；“另存为”三种都提供。Draw 文件尽其所能保留
绘图的内容，而 PDF 再次打开时是文字已成为轮廓的单个图层；保存时会说明这一点。
PDF 的一页作为一个绘图打开，以其裁剪框为页面：多页的 PDF 会先询问打开哪一页，
并以点为单位给出每页的大小；受密码保护的 PDF 会要求输入密码，输入错误时会说明。
PDF 用其字体排出的文字目前还不会读取。一幅绘图会保留它的页面与单位、图层、组和
剪切、每条路径、每个形状、每段文字和每幅图片、纯色以及线性和径向渐变、每个对象
的不透明度、虚线、拐角、端点和箭头、参考线和网格，以及绘图的标题。如果文件含有
绘图无法保留的内容——其中包括滤镜效果、蒙版、图案填充、标记、无法读取的图片、文
本无法保存的文字样式或文字路径、动画或脚本——它会以只读方式打开，状态栏会说出其
中含有什么，而“保存”会要求一个新名称，使原文件永不被覆盖。“保存副本”把绘图写成
PDF；EPS（透明部分按 PostScript 的画法变为不透明）；按页面的副本分辨率写成 PNG、
JPEG 或 TIFF，较长一边最多 8192 像素；SVG；或 RISC OS 的 Draw 文件（会说明该格
式无法保留的内容，例如渐变）；都不改动文档本身的文件。

工具箱沿窗口左侧排列，检查器沿右侧排列，状态栏沿底部：它说明上一条命令做了什么，
否则说明手中工具的用法，并以页面单位显示指针位置和所选内容的大小以及缩放比例：
按下缩放比例会打开一个缩放菜单。以页面单位标注的标尺沿画布的上边和左边，滚动条
沿右边和下边。指针停在工具按钮上时会显示它的名称和选择它的按键。

工具及选择它们的按键为：选择（`V`）、节点（`A`）、矩形（`R`）、椭圆（`E`）、星
形与多边形（`S`）、直线（`L`）、钢笔（`B`）、铅笔（`P`）、文字（`T`）、渐变
（`G`）、吸管（`I`）、缩放（`Z`）和抓手（`H`）。

选择工具按一下即选中一个对象，组则整体选中；按住 Shift 可把对象加入所选或
从中移出。在空白画布上按下会拖出一个选框，选中完全位于其中的对象，按住 Alt
则选中它接触到的一切。拖动所选内容会移动它，按住 Shift 时只沿一个轴移动，
按住 Alt 时移动的是一个副本。它的八个手柄以对面的手柄为基点缩放它，按住 Shift
拖动角手柄可保持比例；在角的稍外侧拖动会使它绕中心旋转，按住 Shift 时以
15 度为步进。方向键使它移动一个像素，按住 Shift 时移动十个。

节点工具显示所选路径的节点及其曲线的手柄：拖动节点即可移动它，拖动手柄即可
弯曲它的曲线；平滑节点的另一个手柄会保持在一条线上跟随。矩形、椭圆、星形和
直线都通过拖动绘制：Shift 使各边相等——正方形、圆、角度为 15 度倍数的直线——
Alt 则从拖动开始处向外绘制。星形从其中心向外绘制；它的角数、内半径以及是否
为多边形，在检查器的“形状”选项卡中设置，新矩形的圆角也在那里设置。

钢笔逐个放置节点来绘制路径：单击得到尖角，拖动得到平滑节点及其曲线。单击第一个
节点会闭合路径，按 Enter 或选择其他工具则让它保持开放并结束；`Delete` 或
`Backspace` 撤回最后一个节点，Escape 放弃该路径。铅笔用于手绘，松开时它的线条
会拟合为平滑曲线。文字工具在单击处开始一段文字，或编辑被单击的文字：输入文字，
Enter 开始新的一行，方向键、Home 和 End 移动插入点，按 Escape 或在别处单击会把
这次输入作为一次更改结束；留空的文字会被删除。吸管把被单击对象的样式赋予所选内
容以及接下来绘制的内容。渐变工具沿拖动方向在所选内容上，未选择任何内容时则在被
按下的对象上，放置渐变：按住 Shift 以 15° 为步长旋转，按住 Alt 或渐变本来就是
径向时，以拖动起点为中心放置径向渐变；拿着这个工具时，所选对象的渐变显示为连接
两个手柄的线。缩放工具在单击处放大，按住 Alt 缩小，用它拖出的框会充满窗口。抓
手拖动画布；无论使用哪种工具，用中键拖动或按住空格键拖动也一样。

在文本上按下时，文字工具会把插入符放在按下的位置。按住 Shift 再按方向键、Home
和 End，或在文本上拖过，即可选择字符，`Ctrl+A` 则选择全部；之后键入的内容会以
所选第一个字符的样式取代它们。有字符被选中时，在检查器中选择的字体、字号、粗体、
斜体、字间距、提升或颜色只作用于这些字符；没有选择时，则作用于整段文本的每个字
符。“形状”标签页保存文本的字间距、字符按其字号的百分比提升多少，以及行高——对于
沿路径排列的文本，则是它从路径上多远处开始——键入时，检查器显示所选第一个字符的
设置。渐变总是绘制整段文本。

“路径 ▸ 将文本放到路径上”在选中一段文本和一个形状时，把文本沿形状的轮廓排列，
形状并入文本：每个字符按路径的方向旋转并立在路径上，沿路径的文本只有一行，落到
任一端之外的字符不会绘出。“从路径释放”把文本从其路径的起点重新排成行，并把路径
作为独立对象交还。“对象转为路径”把以多种方式绘制的文本变成一个组，每种方式一条
路径。节点工具像编辑任何路径一样编辑文本所沿的路径。

滚轮滚动画布，按住 Shift 时横向滚动；按住 Ctrl 时以指针为中心缩放，就像在
触控板或触摸屏上双指捏合一样。“视图 ▸ 适合页面”和“适合所选内容”使它们适合
窗口，“实际大小”以 100% 显示绘图；缩放范围为 1% 到 25600%。

检查器有五个选项卡。“样式”设置所选内容的填充和描边——未选择任何内容时，设置接下
来绘制的内容：选择“填充”或“描边”，然后选择“无”或取色器中的颜色。取色器提供饱和
度与明度的方块和旁边的色相条、色环或滑块，以及颜色的数值和不透明度；接着是描边
的宽度、拐角（尖角、圆角或斜角）、端点（平头、圆头或方头）、虚线（实线、虚线、
点线或点划线）、起点和终点的箭头——每按一次依次切换无、三角形、箭头、圆形和菱形
——、填充规则（非零或奇偶），以及每个所选对象的不透明度。“图层”列出各图层，最上
层在前：按下一个图层即在其中绘制，按它的“显示”按钮可显示或隐藏它；列表上方，
“新建”添加图层，“删除”删除手中的图层，“锁定”使其不被更改，“上移”和“下移”移动它。
“对象”按左边和上边放置所选内容，并把它缩放到给定的宽度和高度；对齐它——按左边、
中心或右边，或按顶部、中部或底部——并把三个或更多对象横向或纵向均匀分布。对象在
其所选范围内对齐；单个对象，或在打开“对齐页面”时任意数量的对象，在页面内对齐。
“形状”包含矩形的圆角、星形的角数和内半径以及是否为多边形，还有文字的字体族——无
衬线、衬线或等宽——、字号、粗体、斜体以及相对于原点的对齐方式。比窗口高的选项卡
可以滚动。正在选取的颜色、正在输入或步进调整的宽度以及不透明度，在变化时就显示
在画布上，稳定下来后成为一次可撤销的更改；Tab 移到下一个字段，Shift+Tab 移到上
一个。

在“样式”中，“线性”和“径向”用贴合每个对象的渐变绘制填充或描边：从它的颜色到白色，
颜色较浅时则到黑色。下方的条在棋盘格上显示渐变，每个色标有一个手柄：按下手柄即
拿起该色标，其颜色随后由取色器更改；沿条拖动手柄可移动它；按下条则在该处添加色
标。Delete 或“删除色标”删除手中的色标；左右方向键拿起旁边的色标，按住 Shift 时
把它移动百分之一。“色标位置”放置手中的色标，“角度”旋转线性渐变，“延伸”“反射”和
“重复”决定渐变在两端之外如何延续，“反转”让它反向。取色器下方的色板——灰色，然后
是十二种色相的纯色、浅色和深色，然后是绘图自己的色板——把它们的颜色赋予手中的颜
色或色标；“添加色板”把手中的颜色随绘图保存，“删除色板”放弃绘图自己的一个色板。
在“对象”中，“旋转”把所选内容逆时针旋转：单个对象转到给定角度，多个对象一起转过
该角度。

“页面”以页面的单位设置页面的宽度和高度，以及它是纵向还是横向；还设置单位（px、
pt、pc、mm、cm 或 in）、以该单位计的网格间距和网格每个方格的每条边划分成的份数、
制作 PNG、JPEG 和 TIFF 副本所用的分辨率（“副本 dpi”），以及页面的背景——“无”或
来自它自己的取色器的颜色，选取时即显示在画布上。没有背景的页面显示为白纸，它的
PNG 副本在没有绘制内容的地方是透明的。

从标尺拖出会在画布上放置一条横向或纵向参考线；拖动参考线可移动它，拖回标尺上即
可删除。“视图 ▸ 网格”显示页面的网格。打开“吸附”时，绘制形状、用钢笔放置节点、
移动或缩放所选内容时，指针会吸附到参考线、页面的边缘和中心，以及显示中的网格。
“视图 ▸ 轮廓”把每个对象显示为其轮廓，使拥挤的绘图易于辨认。“页面”菜单中的“页面
设置”显示“页面”选项卡；该菜单还设置页面的纸张——A4、A3、A5、A6、A2、A1、A0、B5、
B4、US Letter、US Legal、Tabloid、Executive、两种屏幕尺寸和一个图标尺寸——在纵
向与横向之间旋转页面，给它“页面”选项卡中的背景或不加背景，并设置它的单位：像素、
点、派卡、毫米、厘米或英寸。

“对象 ▸ 组合”把所选内容集合成一个组，“取消组合”将其拆开；“移到最前”、“上移”、
“下移”和“移到最后”在对象所在图层内重新排序；“翻转”和“旋转”镜像所选内容或将其
旋转四分之一圈。“锁定”和“隐藏”使对象不可触及，“全部解锁”和“全部显示”找回手中
图层里的这些对象。“路径”菜单把所选形状合并为一个（并集），从最下面的形状中
减去上面的形状（差集），保留它们重叠的部分（交集）或不重叠的部分（排除），
把形状和文字转为可编辑节点的路径，并把描边转为填充的轮廓。这些运算在窗口之外
完成，期间窗口仍可自由使用；如果在结果到达之前绘图已被更改，绘图保留其更改，
运算结果则不会被应用。

“对象 ▸ 用最上面的对象剪切”只在所选内容最上面的对象之内显示其余内容，“释放剪切”
让被剪切的组重新完整显示，并把剪切它的对象放回其内容的最上面。“路径 ▸ 分割”把
所选形状切成它们的重叠所形成的各个部分。“扩展”和“收缩”按“形状”选项卡中的“偏移”
把每个所选形状放大或缩小，“简化”用尽量少、仍保持在该选项卡“平滑度”之内的节点重
新描绘每一个，“反转方向”让路径反向走，使其箭头和虚线随之改变。

每次更改都是可撤销的一步，“撤销”和“重做”会说出所处理的步骤；最多保留 1000 步，
内存紧张时会更少。“复制”把所选内容以 SVG 放到剪贴板上，“粘贴”把剪贴板中的
内容加入手中的图层，保持其在页面上的位置，并处于选中状态。

“文件 ▸ 置入图片”（`Ctrl+Shift+P`）会询问一幅图片：PNG、JPEG、GIF、BMP、TIFF、
WebP、Windows 图标或 OpenRaster 文件，或 RISC OS 精灵文件；对于含有多个的文件，
取其第一页或第一个精灵。它作为一步放入手中的图层，处于选中状态并以其文件命名，
位于画布所显示范围的中央：保持原有大小，若比画布大，则缩小到画布的五分之四。文
件只会被读取，绝不会被更改。图片可以像任何对象一样移动、缩放、旋转、剪切和复制；
它没有自己的样式和节点，在合并、剪除或分割形状时，它以自己的矩形参与。图片随绘
图一起保存：SVG 将其嵌入，PDF 或 EPS 副本将其绘出，Draw 文件将其保存为精灵或
JPEG。一幅绘图中的图片合计最多 2.68 亿像素，每幅图片无论显示多少次都只计一次；
会使其超出这一上限的图片会被拒绝，状态栏会说明原因。从文件管理器或桌面拖来并在
画布上方放开的图片也以同样方式置入，以放开处为中心；放到窗口上的其他文件，会像
放到 Draw 图标上的文件一样被打开或被拒绝。

图标栏菜单中的 设置 会打开 Draw 的设置窗口：新窗口开始时使用的工具，以
及是否显示网格、是否对齐、是否只画轮廓；新绘图开始时的纸张、方向、单位和网格；
新对象所用的填充和描边——各为无或一种颜色——以及描边宽度；方向键移动的距离，
未设置时为一个像素；副本与原件相隔的距离；以及指针要靠多近才能抓住手柄、节点或
参考线。更改会立即应用并保留到下次；恢复默认值 会全部还原。

Draw 不持有任何文件系统权限。它只编辑交给它的文件：用户可以更改的文件以可写方
式交给它，“保存”会写回该文件；其他文件以只读方式打开，“保存”会询问保存到哪里。
文档、从剪贴板粘贴的绘图以及置入的图片，都在一个完全没有访问能力的独立工作进程
中读取，因此恶意文件无法触及 Draw 能触及的任何东西。

在窗口中任意位置按下鼠标次键（右键）会打开它的菜单：文件、页面、编辑、对象、
路径、图层、视图和工具，每一项都是一个子菜单。窗口没有菜单栏。在有未保存的
更改时关闭窗口或退出，会先询问。用次键在关闭按钮上关闭窗口，还会在文件管理器
中、在包含该文件的文件夹里显示它的文件。

* `Ctrl+N` — 新建窗口；`Ctrl+O` — 打开文件；`Ctrl+Shift+P` — 置入图片
* `Ctrl+S` — 保存；`Ctrl+Shift+S` — 另存为；`Ctrl+Shift+E` — 保存副本
* `Ctrl+W` — 关闭窗口
* `Ctrl+Z` — 撤销；`Ctrl+Shift+Z` 或 `Ctrl+Y` — 重做
* `Ctrl+X`、`Ctrl+C`、`Ctrl+V` — 剪切、复制、粘贴；`Ctrl+D` — 再制
* `Delete` 或 `Backspace` — 删除所选内容
* `Ctrl+A` — 全选；`Ctrl+Shift+A` — 取消选择；`Escape` — 取消选择，或放弃正在绘制的路径
* `Ctrl+G` — 组合；`Ctrl+Shift+G` — 取消组合
* `Page Up` / `Page Down` — 上移或下移；`Home` / `End` — 移到最前或移到最后
* `Ctrl+[` / `Ctrl+]` — 向左或向右旋转
* `Ctrl+L` — 锁定；`Ctrl+Shift+L` — 解锁图层中的全部
* `Ctrl+H` — 隐藏；`Ctrl+Shift+H` — 显示图层中的全部
* `Ctrl+Shift+C` — 对象转为路径
* `Ctrl+Shift+N` — 新建图层；`Ctrl+Shift+Page Up` / `Ctrl+Shift+Page Down` — 上移或下移图层
* `Ctrl+=` 或 `Ctrl++` / `Ctrl+-` — 放大或缩小；`Ctrl+1` — 实际大小；`Ctrl+0` — 适合页面
* `Ctrl+'` — 显示或隐藏网格；`%` — 吸附开关
* `V`、`A`、`R`、`E`、`S`、`L`、`B`、`P`、`T`、`G`、`I`、`Z`、`H` — 各工具，依次排列
* 方向键 — 将所选内容移动设置的距离，未设置时为一个像素；按住 `Shift` 移动其十倍
* `Space` — 按住时，用任何工具拖动画布
* `Ctrl` + 滚轮 — 以指针为中心缩放；`Shift` + 滚轮 — 横向滚动

## OPTIONS

`-h`, `-?`, `--help`
: 将此帮助写到标准输出并退出。

## EXIT STATUS

“退出”后为零。窗口通道、事件邮箱或桌面会话被拒绝时为非零，原因写在标准错误
流上。
