## NAME

files — 图形文件系统浏览器

## SYNOPSIS

`files [--desktop] [directory] [-h | -?]`

## DESCRIPTION

打开一个列出文件系统的桌面窗口，从命令行指定的 `directory` 开始；
未指定时从启动它的用户的 `UserFiles` 文件夹开始（若该文件夹无法
列出，则从其主目录开始）。窗口标题显示当前目录；窗口列出其中的条目，每个选中
的条目都以当前主题的强调色突出显示。每次读取目录都是以启动用户的身份进行的普
通的、经过权限检查的列出：无法读取的目录会被拒绝，绝不会被猜测。

桌面会替你启动浏览器并把它留在图标栏上：其位置的菜单列出你自己的位置以及所有
已挂载的内容，选择其中一项就在那里打开一个窗口。点击该位置会在你的 `UserFiles` 文
件夹打开一个窗口。请求一个已有窗口的文件夹时，会把那个窗口带到最前面，而不是
再打开一个。这个副本没有"退出"行——它是桌面的一部分，关闭它的窗口只是把它
收起来。

从 shell 按名称运行（或从桌面在某个文件夹上打开）时，它则是一个普通应
用程序：只有一个窗口，关闭窗口即退出。无论哪种方式，它都需要一个正在运行的图
形会话：没有图形会话时，窗口通道无法访问，浏览器会在标准错误流上报告拒绝并退
出。

窗口用键盘操作： `下` 和 `上` 移动选择， `回车` 打开选中的目录， `退格` 返
回上级目录。 `F5` 会重新读取列表和位置栏；新接入的卷会自动出现在位置栏
中。 `Ctrl+Shift+N` 新建文件夹。

列表打开时没有任何选中项。点击选中一个项目，按住 `Ctrl` 点击可添加或
移除一个项目，按住 `Shift` 点击则选中从上次所选项目起的一串项目；点
击空白处会清除选择。在空白处拖动会拉出一个方框，方框扩大时会选中它碰到的一切；
在列表顶部或底部按住不放时列表会滚动，按 `Escape` 则撤销方框所选的
内容。

把选中的项目拖到另一个文件管理器窗口、其中的某个文件夹或桌面上，会把它们复制
到那里；按住 `Shift` 则改为移动。放下会复制时，指针显示加号；放下会
移动时，指针显示箭头；放下的目标文件夹会突出显示。把单个文件拖到某个应用程序
在图标栏上的位置，会在那里打开它。

右键菜单的"新建"子菜单可以新建一个文件夹，或为已安装的编辑器所能写入的每种
类型新建一个空文档，并打开其名称供编辑。

`Alt+Enter` 会为选中的项目打开"属性"窗口，右键菜单中的"属性"行
也一样。它是一个独立的窗口，因此可以同时打开多个，而列表在此期间仍可使用：它
显示该项目是什么、大小、时间戳、别名指向何处、权限和所有者，以及卷为它保存的
扩展属性。权限、所有者和属性都可以在那里修改，每一项都是以你自己的身份进行的
普通的、经过权限检查的写入——被拒绝时会说明原因，并且不做任何更改。更改所有
者需要`CAP_FS_CHOWN` 权能；没有该权能的会话会看到所有者和组标
有锁形标记，并有一行说明原因。

`左 ` 和`右 ` 在窗口的各个部分之间切换。在"权限"部分中，按`下 ` 或`Tab` 进
入其控件：方向键在控件之间移动，`Space` 切换某项权限，或打开所有者或
组进行编辑，按`Tab` 或`Escape` 返回各部分。

`directory` 操作数按不可信输入对待：它必须是系统路径长度限制之内的绝
对路径，其每个组成部分都必须是真实的目录名——`.` 和 `..` 不是，因此一
种写法绝不会指向与其读法不同的地方。违反其中任一规则的目录，或启动用
户无法列出的目录，都会被拒绝并在标准错误流上说明原因，窗口转而在 `UserFiles`
文件夹打开，这样错误的参数绝不会让用户没有窗口。第二个操作数会被直接拒
绝，而不是忽略。

## OPTIONS

- `--desktop` — 作为桌面自身的文件管理器组件运行：图标栏上的一个固定位置，
  提供你的位置和已挂载的卷；在被请求之前不打开窗口，也没有退出的办法。桌面
  会话在启动时传入此选项；与它一同指定 `directory` 会被拒绝，因为组件不会打开
  可以放置它的窗口。
- `-h, -?` — 显示本命令自身的简短帮助并退出。

## EXIT STATUS

正常关闭后，或显示简短帮助后返回零；无法理解命令行时返回 `2`；当窗口
通道、共享帧区域或初始目录列表被拒绝时返回非零（原因写在标准错误流
上）。
