## NAME

files — 图形文件系统浏览器

## SYNOPSIS

`files --desktop [--mount] [path] [-h | -?]`

## DESCRIPTION

桌面自身的文件管理器，在窗口中列出文件系统。窗口从所请求的文件夹开始；若请求的
是文件，则从该文件所在的文件夹开始，并选中该文件；未指定时从设置所选的文件夹
开始：除非启动它的用户选择了自己的 `Desktop` 或已接入的存储，否则就是该用户
的 `Home` 文件夹（若该文件夹无法列出，则从其主目录开始）。窗口标题显示当前
目录；窗口列出其中的条目，每个选中的条目都以当前主题的强调色突出显示。每次读
取目录都是以启动用户的身份进行的普通的、经过权限检查的列出：无法读取的目录会
被拒绝，绝不会被猜测。

桌面随会话启动文件管理器并把它留在图标栏上，它永不退出：其位置的菜单列出你自
己的位置以及所有已挂载的内容，选择其中一项就在那里打开一个窗口；其后是"网络"，
最后是"回收站"：它打开你的回收站，没有可存放回收站的主文件夹时则显示为
灰色并说明原因。你可以推出的卷（U 盘、存储卡或其他可移动磁盘，或者你挂载的
磁盘映像或共享）会打开一个含有"推出"的子菜单；若是你可以更改其标题的卷（你自
己的磁盘映像，或其格式保存标题的磁盘），子菜单中还有"标题"：它会打开一个填有
该标题、可随即修改的输入框，按 `Return` 即可将新标题写入磁盘，空标题则清除
标题。当你无权自行更改磁盘的标题时，桌面会要求输入管理员的用户名和密码，并在
其许可下更改。点击该位置会在设置所选的位置打开一个窗口。请
求一个已有窗口的文件夹时，会把那个窗口带到最前面，而不是再打开一个。菜单中没
有"退出"行——文件管理器是桌面的一部分，关闭它的窗口只是把它收起来，万一它停止
运行，桌面会再次启动它。

位置菜单中紧挨在"回收站"上方的"网络"会打开一个窗口，显示本地网络上共享文
件的计算机。每台计算机都列出其名称、可访问的地址、所属工作组或域以及类型，列
表会随着计算机的应答而逐渐填满。只有在窗口显示网络时才会浏览网络。停止应答的
计算机会以灰色显示，直到被遗忘；以冒充其他名称所需的方式混用文字的名称，会以
警告标志代替其图片；当一台计算机提供的条目超过几项时，其余条目会单独计入一行
，而不会挤掉其他计算机。网络上的名称由各台计算机的管理者自行选定，因此名称永
远不能证明你看到的是哪台计算机。本系统不支持连接计算机的共享，打开时会给出这
样的提示。

它只能以桌面启动它的方式运行：以其他任何方式启动时——例如从 shell 按其路径
`/System/Components/files.app` 启动——它会拒绝运行，并在标准错误流上说明
原因。它需要一个正在运行的图形会话：没有图形会话时，窗口通道无法访问，它会在
标准错误流上报告拒绝并退出。

窗口用键盘操作：方向键 `Down` 和 `Up` 移动选择，`Enter` 打开选中的目录，
`Backspace` 返回上级目录。`F5` 会重新读取列表和位置栏；新接入的卷会自动出
现在位置栏中。`Ctrl+Shift+N` 新建文件夹。

列表打开时没有任何选中项。点击选中一个项目，按住 `Ctrl` 点击可添加或
移除一个项目，按住 `Shift` 点击则选中从上次所选项目起的一串项目；点击空白处
会清除选择。双击打开项目；凡在别处打开的项目——在其应用程序中打开的文档、
应用程序、作为卷打开的磁盘映像——都会在打开后变为未选中，而无法打开的项目则
保持选中。按住 `Shift` 双击则列出应用程序的内容而不启动它。按 `Enter` 会打开
所选内容并保留选择。在空白处拖动会拉出一个方框，方框扩大时会选中
它碰到的一切；在列表顶部或底部按住不放时列表会滚动，按 `Escape` 则撤销方框所
选的内容。

每个图标及其名称周围的空隙都算作空白处，因此方框可以从项目之间的任何地方开始。按 `Ctrl+A` 选中列表中的全部内容，按 `Ctrl+Shift+A` 清除选择；两者在右键菜单中也有。

项目名称会完整显示，需要时分两行；即使两行也放不下的长名称会保留开头和结尾，
中间以 `…` 代替，因此扩展名总能看到。应用程序显示时不带 `.app` 后缀，设置可
以让它显示，也可以把系统能识别的文件类型的扩展名一并隐藏。若隐藏某个后缀会使
剩下的名称看起来像另一种文件类型或应用程序，该后缀就会保持显示——
`invoice.pdf.app` 会完整显示——而窗口按显示名称为项目排序。名称以点开头的项目
只有在设置要求时才会列出。

按 `F2` 可就地重命名选中的项目；只选中一个项目时单击其名称并稍候也一样：一旦
这次单击已不可能成为双击，名称即可编辑。扩展名之前的部分会被选中，因此输入的
内容会替换名称并保留扩展名；窗口未显示的扩展名也会保留。按 `Enter` 或在名称之
外单击会保留新名称（卷拒绝的名称会连同原因保持打开），按 `Escape` 则放弃。完
成重命名的那次单击不会再做别的事，因为文件夹可能已在指针下重新排序。

把选中的项目拖到另一个文件管理器窗口、其中的某个文件夹或桌面上，会把它们复制
到那里；按住 `Shift` 则改为移动。放下会复制时，指针显示加号；放下会
移动时，指针显示箭头；放下的目标文件夹会突出显示。把单个文件拖到某个应用程序
在图标栏上的位置，会在那里打开它。从 `/Storage` 拖出的驱动器绝不会被复制或
移动：它会在放下的位置留下一个快捷方式，指针显示一个弯曲的箭头。驱动器已连接
时，快捷方式会打开它；未连接时，打开它会给出提示，并且它在桌面上显示为淡色。
复制或移动会保留每个文件的空洞和扩展属性（例如 RISC OS 文件类型）；目标
无法保留的属性会在操作结束时于警告中列出。

如果那里已有同名的项目，该操作自己的窗口会询问如何处理："替换"把新项目放到它
的位置，"跳过"保留已有的项目，"停止"结束操作并保留已完成的部分。文件夹遇到同
名文件夹时，"替换"会换成"合并"：其中的内容进入已有的文件夹，里面已存在的每个
文件会逐一询问。勾选"对每个已存在的文件执行相同操作"后，之后关于文件的所有问
题都会得到同样的回答。文件夹遇到文件夹时，复选框显示为"对每个已存在的文件夹执
行相同操作"，只回答之后的文件夹，因此合并的文件夹中已存在的每个文件仍会逐一询
问。`Escape` 即"停止"，`Enter` 给出键盘所在的选项——起初为"跳过"；
`Tab` 在复选框和各选项之间移动，`Space` 勾选复选框。在桌面上，被替换的项目会
放在放下的位置，被跳过或合并的项目则留在原处。

右键菜单以"显示方式"开头。其下的子菜单以菜单所作用的对象命名——例如"文件‘notes.txt’"，过长的名称会从中间截短，以便仍能看到扩展名；选中多个项目时则为"所选项目"。
其中有"打开""打开方式…""只读挂载""推出""显示简介…""重命名""剪切""复制"和"删除"；在当前位置无法使用的行会显示为灰色并说明原因。
其后是"新建"，然后是"全选"和"取消选择"，接着是"粘贴"。在回收站中，最后一项是"清空回收站"：经你确认后，它会彻底删除回收站中的所有内容。右键点击空白处会清除选择，因此项目的子菜单显示为灰色。

打开磁盘映像或归档文件（`.iso`、`.adf`、`.hdf`、`.zip` 等）会将其挂载到
`/Storage`，文件及其格式都允许写入时即以可写方式挂载，并打开其窗口；"只读挂
载"则改为以只读方式挂载。在桌面上打开这类文件也是如此。一旦不再有窗口显示
它，它就会再次被卸载，因此 `/Storage` 中只保留正在使用的内容；如果还有别的东
西在使用它（比如其中的某个文档正在另一个应用程序中打开），它就会保留，并在那
边可能已放开它时再次尝试卸载。设置也可以改为让你打开的内容保持挂载，直到你将
其推出或你的登录会话结束。"推出"可从卷的图标、其在位置栏中的行（该行自身的右
键菜单中有"打开"和"推出"）或图标栏位置菜单中卸下你挂载的卷，在你亲自使用这台
计算机时也可卸下可移动磁盘；你在该卷上的窗口会先转到 `/Storage`。仍有文件在
其上打开的可移动磁盘不会被推出，并会给出相应提示。当你无权推出可移动磁盘时
（坐在计算机前的人并不是你），桌面会要求输入管理员的用户名和密码，并在其许可
下将其推出。在你写入其中的内容全部保存之前就已消失的卷（其磁盘被移除，或与其
服务器失去连接）会从位置栏中移去，但其图标仍保留在 `/Storage` 中，未保存的内
容会丢失；对该图标使用"推出"时，会先询问，然后才放开它。

右键菜单的"新建"子菜单可以新建一个文件夹，或为已安装的编辑器所能写入的每种
类型新建一个空文档，并打开其名称供编辑。

右键菜单的"显示方式"子菜单可将项目显示为大图标（默认）、小图标（每个名称单行
显示在其图片旁）或列表（每项一行，附带其图片、大小、最后修改时间和类型）。其
中列出的驱动器则改为显示其可用空间、文件系统和运行状况。在这些显示方式下方，
它可按名称、类型、大小或最后修改时间为窗口排序——对于驱动器列表，则按名称、可
用空间、文件系统或运行状况——升序或降序均可。点击列标题也会按该列排序，再次点
击则反转顺序。无论选择哪种顺序，文件夹都排在最前面，除非设置让它们与文件排在
一起。

`Ctrl+,` 会在设置应用程序的"文件"下打开浏览器的
设置：新窗口在哪里打开、窗口如何显示和排列其中的项目，以及新窗口是否显示位置
栏和工具栏；文件夹是否排在最前面；隐藏哪些名称后缀和哪些项目；图片是否显示其
本身的内容，文件夹是否显示其中所含的内容；把项目移到回收站之前是否先询问；以
及你打开的磁盘映像或归档文件是否在其窗口关闭后卸载。更改会同时应用到所有窗口
并被记住；窗口会保留你自己在其中选择的显示方式或顺序。

`Alt+Enter` 会为选中的项目打开"简介"窗口，右键菜单子菜单中的"显示简介…"
也一样。它是一个独立的窗口，因此可以同时打开多个，而列表在此期间仍可使用：它
显示该项目是什么、大小、时间戳、别名指向何处、权限和所有者，以及卷为它保存的
扩展属性。权限、所有者和属性都可以在那里修改，每一项都是以你自己的身份进行的
普通的、经过权限检查的写入——被拒绝时会说明原因，并且不做任何更改。更改所有
者需要`CAP_FS_CHOWN` 权能；没有该权能的会话会看到所有者和组标
有锁形标记，并有一行说明原因。驱动器的"简介"窗口打开时显示其"驱动器"部分，其中
的"标题"输入框以同样的方式更改卷的标题：点击它或按`Tab`，输入新标题后按
`Return`；按`Escape` 则恢复原样。

方向键 `Left` 和 `Right` 在窗口的各个部分之间切换。在"权限"部分中，按
`Down` 或 `Tab` 进入其控件：方向键在控件之间移动，`Space` 切换某项权限，
或打开所有者或组进行编辑，按 `Tab` 或 `Escape` 返回各部分。

`path` 操作数按不可信输入对待：它必须是系统路径长度限制之内的绝对路
径，其每个组成部分都必须是真实的名称——`.` 和 `..` 不是，因此一种写法绝
不会指向与其读法不同的地方。违反其中任一规则的路径，或启动用户无法列出
的路径，都会被拒绝并在标准错误流上说明原因，窗口转而在 `Home` 文件夹打
开，这样错误的参数绝不会让用户没有窗口。第二个操作数会被直接拒绝，而不
是忽略。

## OPTIONS

- `--desktop` — 作为桌面自身的文件管理器运行：图标栏上的一个固定位置，提供
  你的位置和已挂载的卷，且没有退出的办法。桌面会话每次启动文件管理器时都会
  传入此选项，文件管理器只有带上它才会运行；与它一同指定 `path` 会在那里
  打开一个窗口。
- `--mount` — 像在窗口中打开它一样，将 `path` 作为磁盘映像或归档文件打开：会
  为你挂载它并打开其窗口，并按设置在其窗口关闭后再次将其卸载。此选项需要
  `path`。
- `-h, -?` — 显示本命令自身的简短帮助并退出。

## EXIT STATUS

桌面运行期间它不会退出。显示简短帮助后返回零；无法理解命令行或未指定
`--desktop` 时返回 `2`；当窗口通道或共享帧区域被拒绝时返回非零（原因写在标准
错误流上）。
