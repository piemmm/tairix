## NAME

files — 图形文件系统浏览器

## SYNOPSIS

`files [--desktop] [path] [-h | -?]`

## DESCRIPTION

打开一个列出文件系统的桌面窗口，从命令行上 `path` 所指的文件夹开始；若它指的
是文件，则从该文件所在的文件夹开始，并选中该文件；未指定时从设置所选的文件夹
开始：除非启动它的用户选择了自己的 `Desktop` 或已接入的存储，否则就是该用户
的 `Home` 文件夹（若该文件夹无法列出，则从其主目录开始）。窗口标题显示当前
目录；窗口列出其中的条目，每个选中的条目都以当前主题的强调色突出显示。每次读
取目录都是以启动用户的身份进行的普通的、经过权限检查的列出：无法读取的目录会
被拒绝，绝不会被猜测。

桌面会替你启动浏览器并把它留在图标栏上：其位置的菜单列出你自己的位置以及所有
已挂载的内容，选择其中一项就在那里打开一个窗口；最后一项是"设置…"。点击该位
置会在设置所选的位置打开一个窗口。请求一个已有窗口的文件夹时，会把那个窗口带
到最前面，而不是再打开一个。这个副本没有"退出"行——它是桌面的一部分，关闭它的
窗口只是把它收起来。

从 shell 按名称运行（或从桌面在某个文件夹上打开）时，它则是一个普通应
用程序：只有一个窗口，关闭窗口即退出。无论哪种方式，它都需要一个正在运行的图
形会话：没有图形会话时，窗口通道无法访问，浏览器会在标准错误流上报告拒绝并退
出。

窗口用键盘操作： `下` 和 `上` 移动选择， `回车` 打开选中的目录， `退格` 返
回上级目录。 `F5` 会重新读取列表和位置栏；新接入的卷会自动出现在位置栏
中。 `Ctrl+Shift+N` 新建文件夹。

列表打开时没有任何选中项。点击选中一个项目，按住 `Ctrl` 点击可添加或
移除一个项目，按住 `Shift` 点击则选中从上次所选项目起的一串项目；点击空白处
会清除选择。双击打开项目；按住 `Shift` 双击则列出应用程序的内容而不启动它，
并让在别处打开的项目保持未选中。在空白处拖动会拉出一个方框，方框扩大时会选中
它碰到的一切；在列表顶部或底部按住不放时列表会滚动，按 `Escape` 则撤销方框所
选的内容。

每个图标及其名称周围的空隙都算作空白处，因此方框可以从项目之间的任何地方开始。按 `Ctrl+A` 选中列表中的全部内容，按 `Ctrl+Shift+A` 清除选择；两者在右键菜单中也有。

项目名称会完整显示，需要时分两行；即使两行也放不下的长名称会保留开头和结尾，
中间以 `…` 代替，因此扩展名总能看到。应用程序显示时不带 `.app` 后缀，设置可
以让它显示，也可以把系统能识别的文件类型的扩展名一并隐藏。名称以点开头的项目
只有在设置要求时才会列出。

按 `F2` 可就地重命名选中的项目；只选中一个项目时单击其名称并稍候也一样：一旦
这次单击已不可能成为双击，名称即可编辑。扩展名之前的部分会被选中，因此输入的
内容会替换名称并保留扩展名；窗口未显示的扩展名也会保留。按 `回车` 或在名称之
外单击会保留新名称（卷拒绝的名称会连同原因保持打开），按 `Escape` 则放弃。完
成重命名的那次单击不会再做别的事，因为文件夹可能已在指针下重新排序。

把选中的项目拖到另一个文件管理器窗口、其中的某个文件夹或桌面上，会把它们复制
到那里；按住 `Shift` 则改为移动。放下会复制时，指针显示加号；放下会
移动时，指针显示箭头；放下的目标文件夹会突出显示。把单个文件拖到某个应用程序
在图标栏上的位置，会在那里打开它。

右键菜单以"显示方式"开头。其下的子菜单以菜单所作用的对象命名——例如"文件‘notes.txt’"，过长的名称会从中间截短，以便仍能看到扩展名；选中多个项目时则为"所选项目"。
其中有"打开""打开方式…""显示简介…""重命名""剪切""复制"和"删除"；在当前位置无法使用的行会显示为灰色并说明原因。
其后是"新建"，然后是"全选"和"取消选择"，最后是"粘贴"。右键点击空白处会清除选择，因此项目的子菜单显示为灰色。

右键菜单的"新建"子菜单可以新建一个文件夹，或为已安装的编辑器所能写入的每种
类型新建一个空文档，并打开其名称供编辑。

右键菜单的"显示方式"子菜单可将项目显示为大图标（默认）、小图标（每个名称单行
显示在其图片旁）或列表（每项一行，附带其图片、大小、最后修改时间和类型）。其
中列出的驱动器则改为显示其可用空间、文件系统和运行状况。在这些显示方式下方，
它可按名称、类型、大小或最后修改时间为窗口排序——对于驱动器列表，则按名称、可
用空间、文件系统或运行状况——升序或降序均可。点击列标题也会按该列排序，再次点
击则反转顺序。无论选择哪种顺序，文件夹都排在最前面，除非设置让它们与文件排在
一起。

图标栏位置菜单中的"设置…"或 `Ctrl+,` 会打开浏览器的设置：新窗口在哪里打开、
如何显示和排列其中的项目，以及是否显示位置栏和工具栏；文件夹是否排在最前面；
隐藏哪些名称后缀和哪些项目；图片是否显示其本身的内容，文件夹是否显示其中所含
的内容；以及把项目移到回收站之前是否先询问。"恢复默认值"会将每项设置都恢复为
默认值。更改会同时应用到所有窗口并被记住；已经打开的窗口则保留其现有的显示方
式和顺序。

`Alt+Enter` 会为选中的项目打开"简介"窗口，右键菜单子菜单中的"显示简介…"
也一样。它是一个独立的窗口，因此可以同时打开多个，而列表在此期间仍可使用：它
显示该项目是什么、大小、时间戳、别名指向何处、权限和所有者，以及卷为它保存的
扩展属性。权限、所有者和属性都可以在那里修改，每一项都是以你自己的身份进行的
普通的、经过权限检查的写入——被拒绝时会说明原因，并且不做任何更改。更改所有
者需要`CAP_FS_CHOWN` 权能；没有该权能的会话会看到所有者和组标
有锁形标记，并有一行说明原因。

`左 ` 和`右 ` 在窗口的各个部分之间切换。在"权限"部分中，按`下 ` 或`Tab` 进
入其控件：方向键在控件之间移动，`Space` 切换某项权限，或打开所有者或
组进行编辑，按`Tab` 或`Escape` 返回各部分。

`path` 操作数按不可信输入对待：它必须是系统路径长度限制之内的绝对路
径，其每个组成部分都必须是真实的名称——`.` 和 `..` 不是，因此一种写法绝
不会指向与其读法不同的地方。违反其中任一规则的路径，或启动用户无法列出
的路径，都会被拒绝并在标准错误流上说明原因，窗口转而在 `Home` 文件夹打
开，这样错误的参数绝不会让用户没有窗口。第二个操作数会被直接拒绝，而不
是忽略。

## OPTIONS

- `--desktop` — 作为桌面自身的文件管理器组件运行：图标栏上的一个固定位置，
  提供你的位置和已挂载的卷；在被请求之前不打开窗口，也没有退出的办法。桌面
  会话在启动时传入此选项；与它一同指定 `path` 会被拒绝，因为组件不会打开
  可以放置它的窗口。
- `-h, -?` — 显示本命令自身的简短帮助并退出。

## EXIT STATUS

正常关闭后，或显示简短帮助后返回零；无法理解命令行时返回 `2`；当窗口
通道、共享帧区域或初始目录列表被拒绝时返回非零（原因写在标准错误流
上）。
