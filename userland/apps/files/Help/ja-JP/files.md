## NAME

files — グラフィカルなファイルシステムブラウザ

## SYNOPSIS

`files [--desktop] [path] [-h | -?]`

## DESCRIPTION

ファイルシステムを一覧するデスクトップのウィンドウを開きます。始める場所は、コ
マンドラインで `path` が指すフォルダー、それがファイルを指す場合はそのファイル
を含むフォルダー（そのファイルを選択した状態）、指定がなければ起動したユーザー
の `Home` フォルダー（一覧できない場合はそのホームディレクトリ）です。ウィンド
ウのタイトルは現在のディレクトリを示し、ウィンドウはその項目を一覧して、選択さ
れた項目をすべて有効なテーマのアクセントカラーで強調します。ディレクトリの読み
取りはどれも、起動したユーザーの身元で行う通常のアクセス権確認付きの一覧です。
読めないディレクトリは拒否され、推測されることはありません。

デスクトップがブラウザーを起動してアイコンバーに置いたままにします。そのスロ
ットのメニューには自分の場所とマウントされているものが並び、どれかを選ぶとそ
こにウィンドウが開きます。スロットをクリックすると `Home` フ
ォルダーでウィンドウが開きます。すでにウィンドウがあるフォルダーを求めると、
別のウィンドウを開かずにそのウィンドウを前面に出します。このインスタンスには
「終了」の行がありません。デスクトップの一部であり、ウィンドウを閉じると片付
けられるだけです。

シェルから名前で実行した場合（またはデスクトップからフォルダーで開いた場合）
は、代わりに普通のアプリケーションになります。ウィンドウは一つで、閉じると終
了します。いずれの場合も実行中のグラフィカルセッションが必要です。それがない
とウィンドウチャネルに到達できず、ブラウザーは拒否を標準エラーストリームに報
告して終了します。

ウィンドウはキーボードで操作します。 `下` と `上` で選択を移動し、 `Enter` で
選択したディレクトリを開き、 `Backspace` で親ディレクトリに上が
ります。 `F5` は一覧と場所の列の両方を読み直します。新しく接続したボリ
ュームは自動で列に現れます。 `Ctrl+Shift+N` で新しいフォルダー
を作ります。

一覧は何も選択されていない状態で開きます。クリックで項目を選択し、 `Ctrl` を
押しながらのクリックで一つを追加または除外し、 `Shift` を押しながら
のクリックで最後に選んだ項目からの範囲を選択します。空いている所をクリックする
と選択が解除されます。ダブルクリックで項目を開きます。 `Shift` を押しながらダ
ブルクリックすると、アプリケーションを起動する代わりにその内容を一覧し、ほかの
場所で開いたものは選択されていない状態にしておきます。空いている所をドラッグす
ると枠が描かれ、広がるにつれて触れたものをすべて選択します。一覧の上端か下端で
止めておくとスクロールし、 `Escape` で枠が選択したものを取り消します。

各アイコンと名前のまわりの余白は空いている所として扱われるので、枠は項目の間のどこからでも始められます。 `Ctrl+A` で一覧のすべてを選択し、 `Ctrl+Shift+A` で選択を解除します。どちらも右クリックメニューにもあります。

項目の名前は省略せずに表示され、必要なら二行にわたります。それでも収まらない長い名前は先頭と末尾を残し、間を `…` にするので、拡張子は常に見えます。

`F2` で選択した項目の名前をその場で変更できます。
選択している項目が一つだけのとき、その名前をクリックして少し待っても同じです。
クリックがダブルクリックになり得なくなった時点で、名前が編集できる状態になります。
拡張子より前の部分が選択されるので、入力すると拡張子を残したまま名前が置き換わります。
`Enter` か名前の外のクリックで新しい名前に確定し（ボリュームが拒んだ名前は理由とともに開いたままになります）、 `Escape` で取り消します。

選択した項目を別のファイルマネージャーのウィンドウ、その中のフォルダー、また
はデスクトップにドラッグするとそこへコピーします。 `Shift` を押して
いると代わりに移動します。ドロップがコピーになる間はポインターにプラスが、移
動になる間は矢印が表示され、ドロップ先となるフォルダーが強調されます。ファイ
ルを一つだけアプリケーションのアイコンバーのスロットにドラッグすると、そこで
開きます。

右クリックメニューは「表示」から始まります。その下のサブメニューには、メニューが働く対象の名前が付きます。「ファイル『notes.txt』」のように示され、長い名前は拡張子が見えるよう中ほどが省略されます。複数の項目を選択しているときは「選択項目」になります。
このサブメニューには「開く」「このアプリケーションで開く…」「情報を見る…」「名前を変更」「カット」「コピー」「削除」があり、その場で使えない行は灰色になって理由を示します。続いて「新規」、さらに「すべてを選択」と「選択を解除」、最後に「ペースト」が並びます。
何もない所を右クリックすると選択が解除されるので、項目のサブメニューは灰色になります。

右クリックメニューの「新規」サブメニューは、フォルダー、またはインストールさ
れたエディターが書ける種類ごとの空の文書を作り、その名前を編集できる状態にし
ます。

右クリックメニューの「表示」サブメニューでは、項目を大きいアイコン（既定）、
小さいアイコン（名前を画像の横に1行で表示）、またはリスト（1項目1行で、サ
イズ、最終更新日時、種類を表示）で表示できます。リストに含まれるドライブは、
代わりに空き容量、ファイルシステム、動作状態を表示します。列の見出しをクリッ
クするとその列で並べ替え、もう一度クリックすると順序が逆になります。

右クリックメニューの「表示」サブメニューは、項目を大きいアイコン（既定）、小さいアイコン（各名前を絵の横に一行で）、またはリスト（項目ごとに一行で、サイズ・最終変更日時・種類を添えて）で表示します。その中に並ぶドライブは、代わりに空き容量・ファイルシステム・動作状態を示します。
列の見出しを押すとその列で並べ替え、もう一度押すと順序が逆になります。

`Alt+Enter` は選択した項目の「情報」ウィンドウを開きます。
右クリックメニューのサブメニューにある「情報を見る…」も同じです。独立したウィンドウなので一
度に複数開くことができ、その間も一覧は使えます。項目の種類、サイズ、タイムス
タンプ、エイリアスの指す先、アクセス権と所有者、そしてボリュームがその項目に
ついて保存している拡張属性を表示します。アクセス権、所有者、属性はそこで変更
でき、どれも自分の身元で行う通常のアクセス権確認付きの書き込みです。拒否され
た場合は理由を示し、何も変わりません。所有者の変更には`CAP_FS_CHOWN` の
権限が必要です。それを持たないセッションでは、所有者とグループに鍵の印が付き、
理由を示す行が表示されます。

`左 ` と`右 ` でウィンドウのセクション間を移動します。「アクセス権」
では`下 ` または`Tab` でその操作部品に入ります。矢印キーで部品間を
移動し、`Space` でアクセス権を切り替えるか所有者やグループを編集用に
開き、`Tab` または`Escape` でセクションに戻ります。

`path` オペランドは信頼できない入力として扱われます。システムのパス長
制限に収まる絶対パスでなければならず、その各構成要素は本物の名前でなけ
ればなりません。`.` と `..` はそれに当たらないため、ある綴りが読めると
おりの場所以外を指すことは決してありません。これらの規則のいずれかに反
するパス、または起動したユーザーが一覧できないパスは、理由を標準エラー
ストリームに示して拒否され、ウィンドウは代わりに `Home` フォルダーで開
きます。したがって、誤った引数によってユーザーがウィンドウを得られなく
なることはありません。二つ目のオペランドは無視されるのではなく、そのま
ま拒否されます。

## OPTIONS

- `--desktop` — デスクトップ自身のファイルマネージャー構成要素として動作
  する。アイコンバー上の恒久的なスロットが自分の場所とマウント済みボリュー
  ムを提示し、求められるまでウィンドウは開かず、終了する手段もない。デスク
  トップセッションが起動時にこれを渡す。これと併せて `path` を指定するこ
  とは拒否される。構成要素はそれを入れるウィンドウを開かないからである。
- `-h, -?` — このコマンド自身の短いヘルプを表示して終了する。

## EXIT STATUS

正常に閉じた後、または短いヘルプを表示した後はゼロ。コマンド行を解釈で
きなかった場合は `2`。ウィンドウチャネル、共有フレーム領域、または最初
のディレクトリ一覧が拒否された場合は非ゼロ（理由は標準エラーストリーム
に出力されます）。
