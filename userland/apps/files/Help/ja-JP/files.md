## NAME

files — グラフィカルなファイルシステムブラウザ

## SYNOPSIS

`files [--desktop] [directory] [-h | -?]`

## DESCRIPTION

ファイルシステムを一覧するデスクトップのウィンドウを開きます。コマンドライン
で指定した `directory` から、指定がなければ起動したユーザーの `UserFiles` フ
ォルダー（一覧できない場合はそのホームディレクトリ）から始めます。ウィンドウ
のタイトルは現在のディレクトリを示し、ウィンドウはその項目を一覧して、選択さ
れた項目をすべて有効なテーマのアクセントカラーで強調します。ディレクトリの読
み取りはどれも、起動したユーザーの身元で行う通常のアクセス権確認付きの一覧で
す。読めないディレクトリは拒否され、推測されることはありません。

デスクトップがブラウザーを起動してアイコンバーに置いたままにします。そのスロ
ットのメニューには自分の場所とマウントされているものが並び、どれかを選ぶとそ
こにウィンドウが開きます。スロットをクリックすると `UserFiles` フ
ォルダーでウィンドウが開きます。すでにウィンドウがあるフォルダーを求めると、
別のウィンドウを開かずにそのウィンドウを前面に出します。このインスタンスには
「終了」の行がありません。デスクトップの一部であり、ウィンドウを閉じると片付
けられるだけです。

シェルから名前で実行した場合（またはデスクトップからフォルダーで開いた場合）
は、代わりに普通のアプリケーションになります。ウィンドウは一つで、閉じると終
了します。いずれの場合も実行中のグラフィカルセッションが必要です。それがない
とウィンドウチャネルに到達できず、ブラウザーは拒否を標準エラーストリームに報
告して終了します。

ウィンドウはキーボードで操作します。 `下` と `上` で選択を移動し、 `Enter` で
選択したディレクトリを開き、 `Backspace` で親ディレクトリに上が
ります。 `F5` は一覧と場所の列の両方を読み直します。新しく接続したボリ
ュームは自動で列に現れます。 `Ctrl+Shift+N` で新しいフォルダー
を作ります。

一覧は何も選択されていない状態で開きます。クリックで項目を選択し、 `Ctrl` を
押しながらのクリックで一つを追加または除外し、 `Shift` を押しながら
のクリックで最後に選んだ項目からの範囲を選択します。空いている所をクリックす
ると選択が解除されます。空いている所をドラッグすると枠が描かれ、広がるにつれ
て触れたものをすべて選択します。一覧の上端か下端で止めておくとスクロールし、 `Escape` で
枠が選択したものを取り消します。

選択した項目を別のファイルマネージャーのウィンドウ、その中のフォルダー、また
はデスクトップにドラッグするとそこへコピーします。 `Shift` を押して
いると代わりに移動します。ドロップがコピーになる間はポインターにプラスが、移
動になる間は矢印が表示され、ドロップ先となるフォルダーが強調されます。ファイ
ルを一つだけアプリケーションのアイコンバーのスロットにドラッグすると、そこで
開きます。

右クリックメニューの「新規」サブメニューは、フォルダー、またはインストールさ
れたエディターが書ける種類ごとの空の文書を作り、その名前を編集できる状態にし
ます。

`Alt+Enter` は選択した項目の「プロパティ」ウィンドウを開きます。
右クリックメニューの「プロパティ」の行も同じです。独立したウィンドウなので一
度に複数開くことができ、その間も一覧は使えます。項目の種類、サイズ、タイムス
タンプ、エイリアスの指す先、アクセス権と所有者、そしてボリュームがその項目に
ついて保存している拡張属性を表示します。アクセス権、所有者、属性はそこで変更
でき、どれも自分の身元で行う通常のアクセス権確認付きの書き込みです。拒否され
た場合は理由を示し、何も変わりません。所有者の変更には`CAP_FS_CHOWN` の
権限が必要です。それを持たないセッションでは、所有者とグループに鍵の印が付き、
理由を示す行が表示されます。

`左 ` と`右 ` でウィンドウのセクション間を移動します。「アクセス権」
では`下 ` または`Tab` でその操作部品に入ります。矢印キーで部品間を
移動し、`Space` でアクセス権を切り替えるか所有者やグループを編集用に
開き、`Tab` または`Escape` でセクションに戻ります。

`directory` オペランドは信頼できない入力として扱われます。システムのパ
ス長制限に収まる絶対パスでなければならず、その各構成要素は本物のディレ
クトリ名でなければなりません。`.` と `..` はそれに当たらないため、ある
綴りが読めるとおりの場所以外を指すことは決してありません。これらの規則
のいずれかに反するディレクトリ、または起動したユーザーが一覧できない
ディレクトリは、理由を標準エラーストリームに示して拒否され、ウィンドウ
は代わりに `UserFiles` フォルダーで開きます。したがって、誤った引数によって
ユーザーがウィンドウを得られなくなることはありません。二つ目のオペラン
ドは無視されるのではなく、そのまま拒否されます。

## OPTIONS

- `--desktop` — デスクトップ自身のファイルマネージャー構成要素として動作
  する。アイコンバー上の恒久的なスロットが自分の場所とマウント済みボリュー
  ムを提示し、求められるまでウィンドウは開かず、終了する手段もない。デスク
  トップセッションが起動時にこれを渡す。これと併せて `directory` を指定するこ
  とは拒否される。構成要素はそれを入れるウィンドウを開かないからである。
- `-h, -?` — このコマンド自身の短いヘルプを表示して終了する。

## EXIT STATUS

正常に閉じた後、または短いヘルプを表示した後はゼロ。コマンド行を解釈で
きなかった場合は `2`。ウィンドウチャネル、共有フレーム領域、または最初
のディレクトリ一覧が拒否された場合は非ゼロ（理由は標準エラーストリーム
に出力されます）。
