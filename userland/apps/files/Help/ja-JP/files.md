## NAME

files — グラフィカルなファイルシステムブラウザ

## SYNOPSIS

`files --desktop [--mount] [path] [-h | -?]`

## DESCRIPTION

ファイルシステムをウィンドウで一覧する、デスクトップ自身のファイルマネージャー
です。ウィンドウが開くのは、求められたフォルダー、ファイルの場合はそのファイル
を含むフォルダー（そのファイルを選択した状態）、指定がなければ設定で選んだフォ
ルダーです。起動したユーザーが自分の `Desktop` か接続されたストレージを選んで
いなければ、そのユーザーの `Home` フォルダー（一覧できない場合はそのホームディ
レクトリ）です。ウィンドウのタイトルは現在のディレクトリを示し、ウィンドウはそ
の項目を一覧して、選択された項目をすべて有効なテーマのアクセントカラーで強調し
ます。ディレクトリの読み取りはどれも、起動したユーザーの身元で行う通常のアクセ
ス権確認付きの一覧です。読めないディレクトリは拒否され、推測されることはありま
せん。

デスクトップはセッションとともにファイルマネージャーを起動してアイコンバーに置
いたままにし、ファイルマネージャーが終了することはありません。そのスロットのメ
ニューには自分の場所とマウントされているものが並び、どれかを選ぶとそこにウィン
ドウが開きます。続いて「ネットワーク」があり、最後の「ゴミ箱」は
自分のゴミ箱を開きます。ゴミ箱を置くホームフォルダーがないときは、灰色になって
理由を示します。取り出せるボリュー
ム（USB メモリー、メモリーカードなどのリムーバブルディスクや、自分でマウントし
たディスクイメージや共有）はサブメニューを開き、そこには「取り出す」があります。
タイトルを変更できるボリューム（自分のディスクイメージや、形式がタイトルを保持
するディスク）には「タイトル」もあり、これを選ぶとタイトルが入った欄がすぐに変
更できる状態で開き、`Return` を押すと新しいタイトルがディスクに書き込まれ、空
のタイトルはタイトルを消去します。自分でディスクのタイトルを変更できないとき
は、デスクトップが管理者の名前とパスワードを尋ね、その管理者の承認を得て変更し
ます。スロットをクリックすると、設定で選んだ場所に
ウィンドウが開きます。すでにウィンドウがあるフォルダーを求めると、別のウィンド
ウを開かずにそのウィンドウを前面に出します。メニューには「終了」の行がありませ
ん。ファイルマネージャーはデスクトップの一部であり、ウィンドウを閉じると片付け
られるだけで、万一停止してもデスクトップが再び起動します。

スロットのメニューで「ゴミ箱」のすぐ上にある「ネットワーク」は、ローカルネッ
トワーク上でファイルを共有しているコンピューターのウィンドウを開きます。それ
ぞれが名前、接続先のアドレス、ワークグループまたはドメイン、種類とともに並び
、コンピューターが応答するにつれて一覧が埋まっていきます。ネットワークを探す
のは、ウィンドウがそれを表示している間だけです。応答しなくなったコンピュータ
ーは、忘れられるまで灰色で表示されます。ほかの名前をまねるのに必要な形で文字
体系を混ぜた名前には、絵の代わりに警告マークが付きます。また、1 台のコンピ
ューターがいくつもの項目を示すときは、ほかを押しのけないよう、残りを専用の行
で数えます。ネットワーク上の名前は各コンピューターの運用者が選ぶものなので、
名前だけではどのコンピューターを見ているかの証明にはなりません。このシステム
ではコンピューターの共有への接続は利用できず、開こうとするとその旨が表示され
ます。

デスクトップが起動する形でのみ動作します。それ以外の方法、たとえばシェルから
そのパス `/System/Components/files.app` で起動すると、理由を標準エラースト
リームに示して起動を拒否します。実行中のグラフィカルセッションが必要です。そ
れがないとウィンドウチャネルに到達できず、拒否を標準エラーストリームに報告して
終了します。

ウィンドウはキーボードで操作します。矢印キーの `Down` と `Up` で選択を移動
し、 `Enter` で選択したディレクトリを開き、 `Backspace` で親ディレクトリに上が
ります。 `F5` は一覧と場所の列の両方を読み直します。新しく接続したボリ
ュームは自動で列に現れます。 `Ctrl+Shift+N` で新しいフォルダー
を作ります。

一覧は何も選択されていない状態で開きます。クリックで項目を選択し、 `Ctrl` を
押しながらのクリックで一つを追加または除外し、 `Shift` を押しながら
のクリックで最後に選んだ項目からの範囲を選択します。空いている所をクリックする
と選択が解除されます。ダブルクリックで項目を開きます。ほかの場所で開くもの
（対応するアプリケーションで開く文書、アプリケーション、ボリュームとして開く
ディスクイメージ）は、開き終えると選択されていない状態になり、開けなかったもの
は選択されたまま残ります。 `Shift` を押しながらダブルクリックすると、
アプリケーションを起動する代わりにその内容を一覧します。 `Enter` は選択したも
のを開き、選択をそのまま保ちます。空いている所をドラッグす
ると枠が描かれ、広がるにつれて触れたものをすべて選択します。一覧の上端か下端で
止めておくとスクロールし、 `Escape` で枠が選択したものを取り消します。

各アイコンと名前のまわりの余白は空いている所として扱われるので、枠は項目の間のどこからでも始められます。 `Ctrl+A` で一覧のすべてを選択し、 `Ctrl+Shift+A` で選択を解除します。どちらも右クリックメニューにもあります。

項目の名前は省略せずに表示され、必要なら二行にわたります。それでも収まらない長
い名前は先頭と末尾を残し、間を `…` にするので、拡張子は常に見えます。アプリ
ケーションは末尾の `.app` を付けずに表示されます。設定でこれを表示することも、
システムが認識しているファイル形式の拡張子まで隠すこともできます。ただし、隠す
と別のファイル形式やアプリケーションに見える名前が残る場合は、その拡張子は表示
されたままになります（`invoice.pdf.app` は省略せずに表示されます）。また、ウィ
ンドウは項目を表示されているとおりの名前で並べます。名前がドット
で始まる項目は、設定で求めた場合にだけ一覧されます。

`F2` で選択した項目の名前をその場で変更できます。
選択している項目が一つだけのとき、その名前をクリックして少し待っても同じです。
クリックがダブルクリックになり得なくなった時点で、名前が編集できる状態になります。
拡張子より前の部分が選択されるので、入力すると拡張子を残したまま名前が置き換わります。
ウィンドウに表示されていない拡張子もそのまま残ります。
`Enter` か名前の外のクリックで新しい名前に確定し（ボリュームが拒んだ名前は理由とともに開いたままになります）、 `Escape` で取り消します。
フォルダーがポインターの下で並べ替わっているかもしれないため、名前を変更したクリックはほかに何もしません。

選択した項目を別のファイルマネージャーのウィンドウ、その中のフォルダー、また
はデスクトップにドラッグするとそこへコピーします。 `Shift` を押して
いると代わりに移動します。ドロップがコピーになる間はポインターにプラスが、移
動になる間は矢印が表示され、ドロップ先となるフォルダーが強調されます。ファイ
ルを一つだけアプリケーションのアイコンバーのスロットにドラッグすると、そこで
開きます。`/Storage` からドラッグしたドライブはコピーも移動もされず、ドロップした
場所にショートカットが残ります。このときポインターには曲がった矢印が表示され
ます。ショートカットは、ドライブが接続されている間はそのドライブを開きます。
接続されていないときは、開こうとするとそのことが示され、デスクトップでは薄く
表示されます。
コピーや移動では、各ファイルの穴と拡張属性（RISC OS のファイルタイプな
ど）が保たれます。コピー先が保てない属性は、操作の終わりに警告で示されます。

同じ名前の項目がすでにある場合は、その操作自身のウィンドウがどうするかを尋ね
ます。「置き換える」は新しい項目をその場所に置き、「スキップ」はすでにある項
目を残し、「中止」はそれまでに済んだ処理を残したまま操作を終えます。フォルダー
が同じ名前のフォルダーに出会うと、「置き換える」の代わりに「結合」が示されま
す。中身はすでにあるフォルダーに入り、その中ですでにあるファイルについては一
つずつ尋ねます。「すでにあるすべてのファイルに同じ操作を行う」にチェックを入
れると、それ以降のファイルについての質問すべてに同じ答えが使われます。フォル
ダーがフォルダーに出会うと、チェックボックスは「すでにあるすべてのフォルダー
に同じ操作を行う」となり、それ以降のフォルダーにだけ答えるので、結合したフォ
ルダーの中のファイルについては引き続き尋ねます。`Escape` は「中止」で、`Enter`
はキーボードが置かれている選択肢を選びます（最初は「スキップ」）。`Tab` で
チェックボックスと選択肢の間を移り、`Space` でチェックを入れます。デスクトップ
では、置き換えた項目はドロップした場所に置かれ、スキップした項目や結合した項目
は元の場所のままです。

右クリックメニューは「表示」から始まります。その下のサブメニューには、メニューが働く対象の名前が付きます。「ファイル『notes.txt』」のように示され、長い名前は拡張子が見えるよう中ほどが省略されます。複数の項目を選択しているときは「選択項目」になります。
このサブメニューには「開く」「このアプリケーションで開く…」「読み出し専用でマウント」「取り出す」「情報を見る…」「名前を変更」「カット」「コピー」「削除」があり、その場で使えない行は灰色になって理由を示します。続いて「新規」、さらに「すべてを選択」と「選択を解除」、そして「ペースト」が並びます。
ゴミ箱の中では、最後に「ゴミ箱を空にする」があります。確認すると、ゴミ箱の中のものがすべて完全に削除されます。
何もない所を右クリックすると選択が解除されるので、項目のサブメニューは灰色になります。

ディスクイメージまたはアーカイブ（`.iso`、`.adf`、`.hdf`、`.zip` など）を開
くと `/Storage` にマウントされ、ファイルとその形式の両方が書き込みを許すなら
書き込み可能になり、そのウィンドウが開きます。「読み出し専用でマウント」は代
わりに読み出し専用でマウントします。デスクトップ上で開いた場合も同じです。そ
れを表示するウィンドウがなくなると再びアンマウントされるので、`/Storage` に
は使用中のものだけが残ります。ただし、ほかのもの（たとえば、別のアプリケー
ションで開いているその中の文書）がまだ使っているときはそのまま残り、それが手
放したかもしれない時点で改めてアンマウントが試みられます。設定で、開いたもの
を代わりに、取り出すかログインセッションが終わるまでマウントしたままにするこ
ともできます。「取り出す」は、自分でマウントしたボリュームを、またこのコンピュー
ターそのものを使っているときはリムーバブルディスクも、そのアイコンからでも、場
所の一覧の行からでも、アイコンバーのスロットのメニューからでも取り外します。場
所の一覧の行の右クリックメニューには「開く」と「取り出す」があります。そのボリ
ューム上のウィンドウは先に `/Storage` へ移ります。まだファイルが開かれているリ
ムーバブルディスクは取り出されず、その旨が表示されます。リムーバブルディスクを
取り出す権限がないとき（コンピューターの前にいるのが自分ではないとき）は、デス
クトップが管理者の名前とパスワードを尋ね、その管理者の承認を得て取り出します。
ディスクが取り外されたりサーバーとの接続が切れたりして、自分が書き込んだ内容が
すべて保存される前に消えたボリュームは、場所の一覧からは外れますが `/Storage`
にはアイコンが残り、保存されなかった内容は失われます。そのアイコンで「取り出す」
を選ぶと、手放す前に確認を求めます。

右クリックメニューの「新規」サブメニューは、フォルダー、またはインストールさ
れたエディターが書ける種類ごとの空の文書を作り、その名前を編集できる状態にし
ます。

右クリックメニューの「表示」サブメニューでは、項目を大きいアイコン（既定）、
小さいアイコン（名前を画像の横に1行で表示）、またはリスト（1項目1行で、画
像、サイズ、最終更新日時、種類を表示）で表示できます。リストに含まれるドライ
ブは、代わりに空き容量、ファイルシステム、動作状態を表示します。表示方法の下
の項目では、ウィンドウを名前、種類、サイズ、最終更新日時のいずれかで（ドライ
ブの一覧なら名前、空き容量、ファイルシステム、動作状態のいずれかで）、昇順ま
たは降順に並べ替えます。列の見出しをクリックしてもその列で並べ替えられ、もう
一度クリックすると順序が逆になります。どの順序を選んでも、設定でファイルと混
ぜて並べるようにしない限り、フォルダーは先頭に置かれます。

`Ctrl+,` で、設定アプリ
ケーションの「ファイル」にあるブラウザーの設定が開きます。新しいウィンドウを
開く場所、ウィンドウでの項目の表示方法と並べ方、新しいウィンドウに場所の列と
ツールバーを表示するかどうか、フォルダーを先頭に置くかどうか、どの拡張子とど
の項目を隠すか、画像にその内容を、フォルダーに中身を表示するかどうか、項目を
ゴミ箱に移す前に確認するかどうか、開いたディスクイメージまたはアーカイブをそ
のウィンドウを閉じたらアンマウントするかどうかを設定できます。変更はすべての
ウィンドウに一度に適用されて記憶されますが、ウィンドウは、その中で自分で選ん
だ表示方法や並び順を保ちます。

`Alt+Enter` は選択した項目の「情報」ウィンドウを開きます。
右クリックメニューのサブメニューにある「情報を見る…」も同じです。独立したウィンドウなので一
度に複数開くことができ、その間も一覧は使えます。項目の種類、サイズ、タイムス
タンプ、エイリアスの指す先、アクセス権と所有者、そしてボリュームがその項目に
ついて保存している拡張属性を表示します。アクセス権、所有者、属性はそこで変更
でき、どれも自分の身元で行う通常のアクセス権確認付きの書き込みです。拒否され
た場合は理由を示し、何も変わりません。所有者の変更には`CAP_FS_CHOWN` の
権限が必要です。それを持たないセッションでは、所有者とグループに鍵の印が付き、
理由を示す行が表示されます。ドライブの「情報」ウィンドウは「ドライブ」セクシ
ョンで開き、その「タイトル」欄で同じようにボリュームのタイトルを変更できます。
欄をクリックするか `Tab` を押し、新しいタイトルを入力して `Return` を押しま
す。`Escape` を押すと元に戻ります。

矢印キーの `Left` と `Right` でウィンドウのセクション間を移動します。「アク
セス権」では `Down` または `Tab` でその操作部品に入ります。矢印キーで部品間
を移動し、`Space` でアクセス権を切り替えるか所有者やグループを編集用に開き、
`Tab` または `Escape` でセクションに戻ります。

`path` オペランドは信頼できない入力として扱われます。システムのパス長
制限に収まる絶対パスでなければならず、その各構成要素は本物の名前でなけ
ればなりません。`.` と `..` はそれに当たらないため、ある綴りが読めると
おりの場所以外を指すことは決してありません。これらの規則のいずれかに反
するパス、または起動したユーザーが一覧できないパスは、理由を標準エラー
ストリームに示して拒否され、ウィンドウは代わりに `Home` フォルダーで開
きます。したがって、誤った引数によってユーザーがウィンドウを得られなく
なることはありません。二つ目のオペランドは無視されるのではなく、そのま
ま拒否されます。

## OPTIONS

- `--desktop` — デスクトップ自身のファイルマネージャーとして動作する。アイ
  コンバー上の恒久的なスロットが自分の場所とマウント済みボリュームを提示し、
  終了する手段はない。デスクトップセッションはファイルマネージャーを起動する
  たびにこれを渡し、ファイルマネージャーはこれがなければ動作しない。これと
  併せて `path` を指定すると、そこにウィンドウが開く。
- `--mount` — ウィンドウの中で開いたときと同じように、`path` をディスクイ
  メージまたはアーカイブとして開く。マウントされてそのウィンドウが開き、設定
  に従って、そのウィンドウを閉じると再びアンマウントされる。`path` を必要と
  する。
- `-h, -?` — このコマンド自身の短いヘルプを表示して終了する。

## EXIT STATUS

デスクトップが動作している間は終了しません。短いヘルプを表示した後はゼロ。コ
マンド行を解釈できなかった場合、または `--desktop` の指定がなかった場合は
`2`。ウィンドウチャネルまたは共有フレーム領域が拒否された場合は非ゼロ（理由
は標準エラーストリームに出力されます）。
