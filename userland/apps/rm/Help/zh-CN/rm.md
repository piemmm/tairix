## NAME

rm — 删除文件和目录

## SYNOPSIS

`rm [-dfiIrRv] [--] file...`

## DESCRIPTION

按顺序删除每个文件操作数。非目录操作数被解除链接——符号链接删除的是它本
身，绝不是它所指的对象；目录操作数只有带 `-r`（先深度优先删除其内容，再
删除目录本身）或在其为空时带 `-d` 才被删除。无论哪种情况，最后一个组成部
分为 `.` 或 `..` 的操作数都会按 POSIX 的要求被拒绝。

带 `-f` 时，不存在的操作数被静默跳过，且从不发问。`-i` 在每次删除前在标
准错误流上询问，并指明将要删除的对象
（`remove regular empty file 'a'?`、`remove symbolic link 'l'?`），进入
含有任何内容的目录前也会询问；`-I` 在删除多于三个操作数或递归删除之前先
问一次。被拒绝的询问无错误地保留该对象（对 `-I` 则跳过整次运行）；无法读
取的回答绝不被当作同意。`-f`、`-i` 和 `-I` 以最后者为准。

不带 `-f` 时，若标准输入是终端，调用者无权写入的文件在删除前会被询问
（`remove write-protected regular file 'x'?`），只有以 `y` 或 `Y` 开头的
回答才会删除它；符号链接从不被询问。带 `-i` 时，询问也会指明该保护。

无法检查、读取或删除的路径会被报告，其余的仍会被删除；仍留有内容的目录会
被默默保留。在 `--preserve-root`（默认）下，对 `/` 的递归删除无论如何拼
写都会被拒绝。`--` 结束选项解析：之后的每个参数都是路径。

## OPTIONS

- `-r, -R, --recursive` — 删除目录及其内容。
- `-f, --force` — 忽略不存在的操作数；从不询问。
- `-d, --dir` — 删除空目录。
- `-i, --interactive` — 每次删除前询问；只有以 `y`/`Y` 开头的回答才算同
  意。
- `-I` — 在删除多于三个操作数或递归删除之前问一次。
- `-v, --verbose` — 以 `removed 'file'` 报告每次删除。
- `--preserve-root` — 拒绝递归删除 `/`（默认）。
- `--no-preserve-root` — 允许删除 `/`。只有完整拼写时才被接受。
- `-h, -?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `rm notes.txt` — 删除一个文件。
- `rm -r Scratch` — 删除 `Scratch` 树及其中的一切。
- `rm -I a b c d` — 问一次，回答 `y` 后删除全部四个文件。

## EXIT STATUS

- `0` — 每次删除都成功（被拒绝的询问和 `-f` 的跳过不算失败）。
- `1` — 有路径无法删除，或询问或输出失败；每个原因都打印在标准错误上。无
  法理解的命令行同样以 `1` 退出。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
