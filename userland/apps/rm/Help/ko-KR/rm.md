## NAME

rm — 파일과 디렉터리 제거하기

## SYNOPSIS

`rm [-dfiIrRv] [--] file...`

## DESCRIPTION

각 파일 피연산자를 순서대로 제거합니다. 디렉터리가 아닌 피연산자는 연결
해제됩니다. 심볼릭 링크는 링크 자체가 제거되며, 그것이 가리키는 대상은
결코 제거되지 않습니다. 디렉터리 피연산자는 `-r`(내용을 깊이 우선으로
제거한 뒤 디렉터리 자체를 제거)이 있을 때만, 또는 비어 있을 때 `-d`가
있으면 제거됩니다. 어느 경우든 마지막 구성 요소가 `.`이나 `..`인
피연산자는 POSIX가 요구하는 대로 거부됩니다.

`-f`가 있으면 존재하지 않는 피연산자는 조용히 건너뛰고 어떤 질문도 하지
않습니다. `-i`는 매 제거 전에 표준 오류 스트림에서 제거할 대상을 밝혀
물어보고(`remove regular empty file 'a'?`, `remove symbolic link 'l'?`),
무언가가 들어 있는 디렉터리로 내려가기 전에도 물어봅니다. `-I`는 셋보다
많은 피연산자를 제거하기 전이나 재귀 제거 전에 처음에 한 번 물어봅니다.
거절된 질문은 오류 없이 그 대상을 남겨 둡니다(`-I`에서는 실행 전체를
건너뜁니다). 읽을 수 없는 대답은 결코 동의로 취급되지 않습니다. `-f`,
`-i`, `-I` 중 마지막 것이 이깁니다.

`-f`가 없으면, 표준 입력이 터미널일 때 호출자가 쓸 수 없는 파일은
제거하기 전에 물어보고(`remove write-protected regular file 'x'?`) `y`나
`Y`로 시작하는 대답에만 제거합니다. 심볼릭 링크에 대해서는 결코 묻지
않습니다. `-i`에서는 질문이 그 보호도 밝힙니다.

검사하거나 읽거나 제거할 수 없는 경로는 보고되고, 나머지는 그래도
제거됩니다. 무언가가 남아 있는 디렉터리는 아무 말 없이 유지됩니다. `/`의
재귀 제거는 어떻게 적혔든 기본값인 `--preserve-root`에서 거부됩니다.
`--`는 옵션 해석을 끝내며, 이후의 모든 인수는 경로입니다.

## OPTIONS

- `-r, -R, --recursive` — 디렉터리와 그 내용을 제거합니다.
- `-f, --force` — 존재하지 않는 피연산자를 무시합니다. 결코 묻지
  않습니다.
- `-d, --dir` — 빈 디렉터리를 제거합니다.
- `-i, --interactive` — 매 제거 전에 물어봅니다. `y`/`Y`로 시작하는
  대답만 동의합니다.
- `-I` — 셋보다 많은 피연산자를 제거하기 전이나 재귀 제거 전에 한 번
  물어봅니다.
- `-v, --verbose` — 각 제거를 `removed 'file'`로 보고합니다.
- `--preserve-root` — `/`의 재귀 제거를 거부합니다(기본값).
- `--no-preserve-root` — `/` 제거를 허용합니다. 이 옵션은 줄여 쓰지 않고
  전부 적었을 때만 받아들여집니다.
- `-h, -?, --help` — 이 명령 자체의 짧은 도움말을 표시합니다.

## EXAMPLES

- `rm notes.txt` — 파일 하나를 제거합니다.
- `rm -r Scratch` — `Scratch` 트리와 그 안의 모든 것을 제거합니다.
- `rm -I a b c d` — 한 번 물어본 뒤 `y`에 네 파일을 모두 제거합니다.

## EXIT STATUS

- `0` — 모든 제거가 성공했습니다(거절된 질문과 `-f`의 건너뜀은 실패가
  아닙니다).
- `1` — 경로를 제거할 수 없었거나, 질문 또는 출력이 실패했습니다. 각
  이유가 표준 오류에 인쇄됩니다. 이해하지 못한 명령줄도 `1`로 끝납니다.

## ENVIRONMENT

- `LANG` — 짧은 도움말의 선호 로캘(`ko-KR` 같은 BCP-47 태그).
