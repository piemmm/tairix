## NAME

rm — ファイルとディレクトリを削除する

## SYNOPSIS

`rm [-dfiIrRv] [--] file...`

## DESCRIPTION

各ファイルオペランドを順に削除します。ディレクトリでないオペランドはアン
リンクされます（シンボリックリンクはそれ自体が削除され、それが指すものが
削除されることは決してありません）。ディレクトリオペランドは `-r`（中身
を深さ優先で削除してからディレクトリ自体を削除）があるとき、または空なら
`-d` があるときだけ削除されます。どちらの場合も、最後の要素が `.` または
`..` のオペランドは、POSIX の求めるとおり拒否されます。

`-f` があれば、存在しないオペランドは静かに飛ばされ、質問は決してされま
せん。`-i` は各削除の前に、削除しようとするものを名指して
（`remove regular empty file 'a'?`、`remove symbolic link 'l'?`）、また
何かを含むディレクトリへ降りる前に、標準エラーストリーム上で尋ねま
す。`-I` は三つを超えるオペランドを削除する前、または再帰的な削除の前
に、最初に一度だけ尋ねます。断られた質問はその対象をエラーなしで残します
（`-I` なら実行全体を飛ばします）。読めない返答が同意として扱われること
は決してありません。`-f`、`-i`、`-I` は最後に書かれたものが勝ちます。

`-f` がなく、標準入力が端末のときは、呼び出し元が書き込めないファイルを
削除する前に尋ね（`remove write-protected regular file 'x'?`）、`y` また
は `Y` で始まる返答があったときだけ削除します。シンボリックリンクについ
て尋ねることはありません。`-i` では、質問がその保護にも触れます。

調べられない、読めない、または削除できないパスは報告され、それでも残りは
削除されます。中に何かが残ったディレクトリは、黙ってそのまま残されま
す。`/` の再帰的な削除は、どう綴られていても、既定の `--preserve-root`
の下では拒否されます。`--` はオプション解析を終え、以降のすべての引数は
パスです。

## OPTIONS

- `-r, -R, --recursive` — ディレクトリとその中身を削除する。
- `-f, --force` — 存在しないオペランドを無視する。決して尋ねない。
- `-d, --dir` — 空のディレクトリを削除する。
- `-i, --interactive` — 各削除の前に尋ねる。`y`/`Y` で始まる返答だけが同
  意。
- `-I` — 三つを超えるオペランドの削除前、または再帰削除の前に一度だけ尋
  ねる。
- `-v, --verbose` — 各削除を `removed 'file'` の形で報告する。
- `--preserve-root` — `/` の再帰的な削除を拒む（既定）。
- `--no-preserve-root` — `/` の削除を許す。省略せずに綴ったときだけ受け
  付けられる。
- `-h, -?, --help` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `rm notes.txt` — ファイルを一つ削除する。
- `rm -r Scratch` — `Scratch` の木とその中のすべてを削除する。
- `rm -I a b c d` — 一度尋ね、`y` で四つのファイルすべてを削除する。

## EXIT STATUS

- `0` — すべての削除が成功した（断られた質問と `-f` による飛ばしは失敗で
  はない）。
- `1` — 削除できないパスがあった、または問いかけか出力が失敗した。それぞ
  れの理由は標準エラーに印字される。解釈できなかったコマンド行も `1` で
  終了する。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
