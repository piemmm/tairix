## NAME

beeb — BBC Micro Model B エミュレーター

## SYNOPSIS

`beeb`

## DESCRIPTION

BBC Micro Model B をデスクトップのウィンドウで、本来の速さのまま 1 サイクル
ずつ実行します。クリーンルーム方式で書いた独自の MOS、BBC BASIC、DFS を
備えているので、ディスクのファイルシステムを持った BASIC のプロンプトで
起動します。画面はテレビのもので、幅 4 に対して高さ 3 の比率です。音は
デスクトップのオーディオから鳴ります。

エミュレーターで開いた、ウィンドウにドロップした、またはメニューの「ディスクを
入れる」「テープを入れる」で選んだディスクイメージ（`.ssd`、`.dsd`）やテープ
イメージ（`.uef`、`.csw`）は、ドライブまたはカセットデッキに入ります。マシンが
ディスクに書いた内容は、そのファイルに書き込める限りディスクのファイルに書き
戻されます。ファイルに書き込めないディスクは書き込み禁止になります。「取り
出す」でディスクを取り出し、「ディスクを別名で保存」で好きな場所にコピーを
保存します。録音したテープは取り出すときに保存されます。「スナップショットを
保存」はマシン全体をファイルに残し、「スナップショットを復元」はディスクと
テープごとそれを戻します。

画面の右クリック、またはアイコンバーのエミュレーターのアイコンから開くメニュー
には、BREAK、リセット、一時停止、速度、全画面表示、シャープまたはスムーズな
拡大と走査線、キーボードの割り当て、そしてクリップボードの文字を打ち込む
「貼り付け」もあります。文字で割り当てると、キーは表示どおりの文字を打ち、
英字の大文字小文字はマシンの CAPS LOCK が決めます。位置で割り当てると、各キー
はその位置にある BBC のキーになります。F1〜F9 は f1〜f9、F10 は f0、F12 は
BREAK、End は COPY、Home は SHIFT LOCK です。

「設定」では、OS ソケットと 16 個のサイドウェイスロットに入れるもの（同梱の
ROM、サイドウェイ RAM、またはエミュレーターの保管場所にインストールした自分の
ROM イメージ）、キーボードのリンクによる画面モード、起動、ディスクのタイミング、
画面、キー、音量、そしてカセットのモーターが回っている間マシンを全速で動かす
テープの高速読み込みを選びます。ROM とリンクの変更は次のリセットで有効に
なります。

ウィンドウ下端のランプは、CAPS LOCK、SHIFT LOCK、カセットのモーター、各ドライブ
を示します。マシンは何の権限も持たないワーカーの中で動くので、そのソフトウェア
もメディアも信頼されません。失敗したワーカーは置き換えられ、マシンは電源投入
時から再び動き出し、その理由が表示されます。

## OPTIONS

`-h`, `-?`, `--help`
: このヘルプを標準出力に書き出して終了します。

## EXIT STATUS

ウィンドウを閉じるか、アイコンバーのアイコンのメニューで「終了」を選ぶと 0 です。ウィンドウチャネル、イベントメールボックス、またはデスクトップセッションが拒否されたときは 0 以外で、その理由を標準エラー出力に示します。
