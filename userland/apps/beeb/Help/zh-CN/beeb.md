## NAME

beeb — BBC Micro Model B 模拟器

## SYNOPSIS

`beeb`

## DESCRIPTION

在桌面窗口中以原机的速度逐周期运行 BBC Micro Model B，并配有以净室方式编写的
自有 MOS、BBC BASIC 和 DFS，因此启动后即停在带磁盘文件系统的 BASIC 提示符下。
画面是电视的画面，宽四高三，声音通过桌面的音频播放。

用模拟器打开、拖放到其窗口上、或在其菜单中用“插入磁盘”“插入磁带”选取的磁盘
映像（`.ssd`、`.dsd`）或磁带映像（`.uef`、`.csw`）会放入驱动器或卡带机。只要
磁盘的文件可写，机器写到磁盘上的内容就会写回该文件；文件不可写的磁盘处于写保护
状态。“弹出”取出磁盘，“磁盘另存为”把副本保存到任意位置。录过音的磁带在取出时
保存。“保存快照”把整台机器存入文件，“恢复快照”连同其磁盘和磁带一并取回。

在画面上右击或从图标栏上的模拟器图标打开的菜单，还提供 BREAK、复位、暂停和速度；
全屏、锐利或平滑缩放以及扫描线；键盘的映射方式；以及输入剪贴板文本的“粘贴”。
按字符映射时，按键输入其上所示的字符，字母大小写由机器的 CAPS LOCK 决定。按位置
映射时，每个键都是其位置上的 BBC 键：F1 至 F9 为 f1 至 f9，F10 为 f0，F12 为
BREAK，End 为 COPY，Home 为 SHIFT LOCK。

“设置”选择操作系统插座和十六个侧向插槽中装入的内容——随附的 ROM、侧向 RAM，或
安装到模拟器存储中的用户自有 ROM 映像——以及键盘跳线的屏幕模式、启动方式和磁盘
时序、画面、按键、音量，以及在卡带电机转动期间让机器全速运行的磁带快速加载。对
ROM 和跳线的更改在下次复位时生效。

窗口底部的指示灯显示 CAPS LOCK、SHIFT LOCK、卡带电机和各驱动器。机器运行在不持有
任何权限的工作进程中，因此其软件和介质都不被信任；失败的工作进程会被替换，机器
像通电时一样重新启动，并显示原因。

## OPTIONS

`-h`, `-?`, `--help`
: 将本帮助写到标准输出并退出。

## EXIT STATUS

关闭窗口或在图标栏图标的菜单中选择“退出”后为零。窗口通道、事件信箱或桌面会话被拒绝时为非零；原因写到标准错误流。
