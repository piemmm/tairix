## NAME

gpucheck — 提供されている各 GPU をソフトウェアデバイスと照合する

## SYNOPSIS

`gpucheck`

## DESCRIPTION

ドライバーが提供するすべての GPU と、システムのソフトウェアデバイスで同じ
短い処理を実行し、GPU ごとに両者が一致するかどうかを示す。

この処理は、コマンドが読めるメモリに既知のパターンを書き込み、その隣の
メモリを埋め、両方を GPU が自分専用に保持するメモリへコピーして戻し、
続いてバッファの末尾を越える塗りつぶしを要求する。どのデバイスもこの
要求を拒否しなければならない。次に、既知の画像に対してシステム自身の
各グラフィックスプログラムを実行する。次の段階で使うあらゆる種類の
画像を GPU が保持できる場合は、画像をメモリとの間で、また画像どうしで
コピーし、画像をクリアし、画像の読み取り、書き込み、サンプリングを行う
プログラムを実行する。GPU が描画できる場合は、既知の色の図形、
点、1 本の線を画像に描画する。その際、奥にあるものを隠し、
裏を向いた図形を省き、色をブレンドし、一部の色はそのまま残す。また、
各ピクセルの 4 つのサンプルを 1 つにまとめる。さらに、描画する図形の
最初のコピーを指定するメモリ上のリストに基づいて描画する。それができない
GPU は、この描画を放棄することで応えなければならない。
最後に、GPU が許す数を超える処理のグループにわたってプログラムを
実行するよう要求する。どのデバイスもこの要求には、その処理を
放棄することで応えなければならない。GPU は、ソフトウェアデバイスと
同じバイトを残し、その塗りつぶしを同じ理由で拒否し、同じ処理を
放棄したときに一致する。

コマンドは GPU ごとに、そのハードウェアノードを示す 1 行を出力する。内容は
GPU が一致したこと、または最初に見つかった相違点 — 拒否された処理と
その段階、異なる値として読めるバイト、塗りつぶしへの異なる応答、
グラフィックスプログラムが残した異なる値、異なる値として読める画像の
バイト、異なる値として読める描画のバイト、リストに基づく描画への
異なる応答、GPU の上限を超える処理への異なる応答 — のいずれかである。

`sysinfo gpu` は、このコマンドが照合する GPU を一覧表示する。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `gpucheck` — 提供されているすべての GPU を照合する。

## EXIT STATUS

- `0` — 提供されているすべての GPU がソフトウェアデバイスと一致した。
- `1` — いずれかの GPU が相違した、または到達できなかった、GPU が一つも
  提供されていない、提供されている GPU を一覧できなかった、または
  ソフトウェアデバイスが処理を実行できなかった。解釈できなかったコマンド行も
  `1` で終了する。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`fr-FR` のような BCP-47 タグ）。
