## NAME

gpucheck — 提供されている各 GPU、うち 1 つの描画を映す画面、
および自分で用意したカーネルを検査する

## SYNOPSIS

`gpucheck`

`gpucheck --present`

`gpucheck --shader FILE [--words N]`

## DESCRIPTION

ドライバーが提供するすべての GPU と、システムのソフトウェアデバイスで同じ
短い処理を実行し、GPU ごとに両者が一致するかどうかを示す。

この処理は、コマンドが読めるメモリに既知のパターンを書き込み、その隣の
メモリを埋め、両方を GPU が自分専用に保持するメモリへコピーして戻し、
続いてバッファの末尾を越える塗りつぶしを要求する。どのデバイスもこの
要求を拒否しなければならない。次に、既知の画像に対してシステム自身の
各グラフィックスプログラムを実行する。次の段階で使うあらゆる種類の
画像を GPU が保持できる場合は、画像をメモリとの間で、また画像どうしで
コピーし、画像をクリアし、画像の読み取り、書き込み、サンプリングを行う
プログラムを実行する。GPU が描画できる場合は、既知の色の図形、
点、1 本の線を画像に描画する。その際、奥にあるものを隠し、
裏を向いた図形を省き、色をブレンドし、一部の色はそのまま残す。また、
各ピクセルの 4 つのサンプルを 1 つにまとめる。さらに、描画する図形の
最初のコピーを指定するメモリ上のリストに基づいて描画する。それができない
GPU は、この描画を放棄することで応えなければならない。
次いで、GPU が許す数を超える処理のグループにわたってプログラムを
実行するよう要求する。どのデバイスもこの要求には、その処理を
放棄することで応えなければならない。最後に、GPU プログラムが
使用できるすべての命令を全体で網羅する小さなプログラム群を実行し、
それぞれの答えを、その命令の定義が保証する精度の範囲で
ソフトウェアデバイスの答えと照合する。GPU が実行できないプログラム
については、その GPU は照合されない。GPU は、ソフトウェアデバイスと
同じバイトを残し、その塗りつぶしを同じ理由で拒否し、同じ処理を
放棄し、それらの各プログラムで同じ答えを出したときに一致する。

コマンドは GPU ごとに、そのハードウェアノードを示す 1 行を出力する。内容は
GPU が一致したこと、または最初に見つかった相違点 — 拒否された処理と
その段階、異なる値として読めるバイト、塗りつぶしへの異なる応答、
グラフィックスプログラムが残した異なる値、異なる値として読める画像の
バイト、異なる値として読める描画のバイト、リストに基づく描画への
異なる応答、GPU の上限を超える処理への異なる応答、小さなプログラムの
いずれかで、ソフトウェアデバイスの答えから定義上許される以上に離れた
答えを出した命令 — のいずれかである。

`sysinfo gpu` は、このコマンドが照合する GPU を一覧表示する。

`--present` を指定すると、代わりに既知の画像を、画面全体を覆う
ウィンドウに表示する。画像は、青い背景、色の帯、1 列に並んだ市松模様の
タイル、反対側の隅にコピーした 1 枚のタイルからなる。
これを描画するのは、ドライバーが提供する最初の GPU であり、GPU が一つも
提供されていないときはソフトウェアデバイスである。Esc キーが押されるか
ウィンドウが閉じられるまで、フレームごとに 1 回画像を提示し、その後、
提示したフレームの数、何がそれらを描画したか、画面がそのすべてを
表示したかどうかを出力する。

`--shader` を指定すると、代わりに自分で用意したプログラムを実行する。
これは FILE に収めたコンピュートカーネルで、WGSL で書いたものか SPIR-V に
コンパイルしたものであり、どちらであるかはファイルの先頭で
見分ける。WGSL は、ほかの何にもアクセスできない別のプロセスで
コンパイルされ、どちらの場合もいずれかの GPU に渡す前に検査される。
拒否されたカーネルは実行されず、拒否の内容が出力される。WGSL の場合は、
その原因がある行と列も示される。カーネルは、グループ 0、
バインディング 0 のストレージバッファ 1 つを使うコンピュートの
エントリポイントを 1 つ持たなければならない。バッファは N ワードを
保持し、`--words` で別の値を指定しない限り 256 ワードである。ワード *i* の
初期値は *i* で、カーネルはワードごとに 1 回実行される。カーネルは、
ドライバーが提供するすべての GPU とソフトウェアデバイスで実行される。
その隣で GPU は、別のプログラムに属するメモリに目印の値を保持しており、
カーネルのバッファがこの値を持つことは決してあってはならない。
コマンドは GPU ごとに、両者が一致したこと、または最初に見つかった相違点を
出力する。一致とは、バッファが同じ値として読めるか、制限時間を超えた
カーネルを両者とも放棄し、その後も処理を続けたことである。相違点は、異なる
値として読めるワード、バッファ内で見つかった目印の値、
ソフトウェアデバイスが実行したカーネルを GPU が拒否または放棄したか、
一度も応答しなかったこと、カーネルを放棄した後に何も処理しなくなった
GPU のいずれかである。

## OPTIONS

- `--present` — 画像をフルスクリーンで表示し、提示したすべてのフレームを
  画面が表示したことを確認する。
- `--shader FILE` — FILE に収めたコンピュートカーネル（WGSL の
  ソースまたは SPIR-V モジュール）を、提供されているすべての GPU と
  ソフトウェアデバイスで実行する。
- `--words N` — `--shader` とともに使い、カーネルのバッファが保持する
  ワード数を指定する。1 から 65536 までで、指定しないときは 256 である。
- `-h, -?` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `gpucheck` — 提供されているすべての GPU を照合する。
- `gpucheck --present` — 画像をフルスクリーンで表示する。停止するには
  Esc キーを押す。
- `gpucheck --shader double.wgsl` — 提供されているすべての
  GPU で、256 ワードにわたって WGSL カーネルを実行する。
- `gpucheck --shader kernel.spv --words 4096` — コンパイル済み
  カーネルを 4096 ワードにわたって実行する。

## EXIT STATUS

- `0` — 提供されているすべての GPU がソフトウェアデバイスと一致した。
  `--present` では、提示したすべてのフレームを画面が表示した。
  `--shader` では、提供されているすべての GPU がカーネルについて
  ソフトウェアデバイスと一致した。
- `1` — いずれかの GPU が相違した、または到達できなかった、GPU が一つも
  提供されていない、提供されている GPU を一覧できなかった、または
  ソフトウェアデバイスが処理を実行できなかった。`--present` では、
  表示されなかったフレームがあった、フレームを一つも提示しなかった、
  またはウィンドウかデバイスがいずれかの段階を拒否した。`--shader` では、
  ファイルを読めなかった、カーネルが拒否された、またはいずれかの GPU が
  相違した。解釈できなかったコマンド行も `1` で終了する。
