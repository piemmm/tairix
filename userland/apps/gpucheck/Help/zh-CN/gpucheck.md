## NAME

gpucheck — 检查驱动程序提供的每个 GPU、显示其中一个所绘内容的屏幕，
以及你自己的内核

## SYNOPSIS

`gpucheck`

`gpucheck --present`

`gpucheck --shader FILE [--words N]`

## DESCRIPTION

在驱动程序提供的每个 GPU 上以及系统的软件设备上运行同一段简短的工作，并针对
每个 GPU 说明两者是否一致。

该工作将一个已知图案写入命令可以读取的内存，填充其旁边的内存，再将两者复制到
GPU 为自己保留的内存中并复制回来，然后请求一次超出缓冲区末尾的填充，任何设备
都必须拒绝该填充。接着，它在一幅已知图像上运行系统自身的每个图形程序。如果
下一个步骤所用的每一种图像 GPU 都能存放，它会在图像与内存之间来回复制，
也在图像之间相互复制，清除这些图像，并运行一个读取、写入和采样图像的程序。
如果 GPU 能够绘制，它会在图像中绘制已知颜色的形状、点和一条线，
遮挡位于后方的内容，略去背向的形状，混合颜色并保持部分颜色不变，
还会将每个像素的四个样本合并为一个。此外，它会依据内存中的一个列表进行绘制，
该列表指明要绘制的形状的第一个副本，无法做到这一点的 GPU 必须以
放弃该绘制作为应答。随后，它请求 GPU 在比其所允许的更多组工作上运行
一个程序，任何设备都必须以放弃这部分工作作为应答。最后，它运行若干
简短程序，这些程序合起来用到 GPU 程序可以使用的每一条指令，每个结果
都须在其指令的定义所保证的精度内与软件设备的结果相符；无法运行其中
某个程序的 GPU 不受该程序的检验。当 GPU 留下的字节与软件设备相同、
以相同的原因拒绝该填充、放弃相同的工作，并且对这些程序中的每一个都
给出相同的结果时，即为一致。

命令为每个 GPU 打印一行，注明其硬件节点：要么说明该 GPU 一致，要么给出发现的
第一处差异——被拒绝的工作及其所在步骤、读出不同值的字节、对填充的不同应答、
图形程序留下的不同值、图像中读出不同值的字节、绘制结果中读出不同值的字节、
对依据列表进行绘制的不同应答、对超出 GPU 限制的工作所作的不同应答，
或某个简短程序中的一条指令，其结果与软件设备的结果相差超出了
其定义所允许的程度。

`sysinfo gpu` 列出本命令核对的 GPU。

指定 `--present` 时，它改为在覆盖整个屏幕的窗口中显示一幅已知图像：
蓝色的底色、一条彩色条带、一排棋盘格图块，以及复制到远端角落的一个图块。
该图像由驱动程序提供的第一个 GPU 绘制；若没有驱动程序提供任何 GPU，则由
软件设备绘制。它每帧呈现一次该图像，直到按下 Esc 键或关闭窗口为止，然后
打印它呈现了多少帧、这些帧由什么绘制，以及屏幕是否显示了其中的每一帧。

指定 `--shader` 时，它改为运行你自己的程序：FILE 中的计算内核，
以 WGSL 编写或已编译为 SPIR-V，二者依据文件的开头加以区分。WGSL 在一个
无法访问其他任何内容的独立进程中编译；无论哪一种，都会在交给任何 GPU 之前
先行检查。被拒绝的内核不会运行，命令会打印拒绝的原因；对于 WGSL，还会给出
原因所在的行和列。内核必须有一个计算入口点，并使用位于组 0、绑定 0 的一个
存储缓冲区。该缓冲区包含 N 个字，未用 `--words` 另行指定时为 256 个；
下标为 *i* 的字初始值为 *i*，内核对每个字运行一次。内核在驱动程序提供的
每个 GPU 上以及软件设备上运行；在它旁边，GPU 在属于另一个独立程序的内存中
保存一个标记值，内核的缓冲区中绝不能出现该值。对于每个 GPU，它要么说明
两者一致——缓冲区读出的值相同，或者两者都放弃了超出时间限制的内核并继续
提供服务——要么给出第一处差异：读出不同值的字、在缓冲区中发现的标记值、
软件设备已运行而该 GPU 拒绝、放弃或始终未应答的内核，或者放弃内核后
不再提供任何服务的 GPU。

## OPTIONS

- `--present` — 全屏显示该图像，并检查屏幕是否显示了所呈现的每一帧。
- `--shader FILE` — 在驱动程序提供的每个 GPU 上以及软件设备上
  运行 FILE 中的计算内核（WGSL 源代码或 SPIR-V 模块）。
- `--words N` — 与 `--shader` 一起使用，指定内核的缓冲区包含的
  字数：1 到 65536，未指定时为 256。
- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `gpucheck` — 核对驱动程序提供的每个 GPU。
- `gpucheck --present` — 全屏显示该图像；按 Esc 键停止。
- `gpucheck --shader double.wgsl` — 在驱动程序提供的每个 GPU 上，
  对 256 个字运行一个 WGSL 内核。
- `gpucheck --shader kernel.spv --words 4096` — 对 4096 个字运行一个
  已编译的内核。

## EXIT STATUS

- `0` — 驱动程序提供的每个 GPU 都与软件设备一致；指定 `--present` 时，
  屏幕显示了所呈现的每一帧；指定 `--shader` 时，驱动程序提供的每个 GPU
  就该内核而言都与软件设备一致。
- `1` — 某个 GPU 存在差异或无法访问、没有驱动程序提供任何 GPU、无法列出
  驱动程序提供的 GPU，或软件设备无法运行该工作；指定 `--present` 时，
  某一帧未被显示、未呈现任何帧，或者窗口或设备拒绝了某个步骤；指定
  `--shader` 时，无法读取该文件、内核被拒绝，或者某个 GPU 存在差异。
  无法理解的命令行同样以 `1` 退出。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `fr-FR`）。
