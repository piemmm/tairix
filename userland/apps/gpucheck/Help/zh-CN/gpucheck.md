## NAME

gpucheck — 将驱动程序提供的每个 GPU 与软件设备进行核对

## SYNOPSIS

`gpucheck`

## DESCRIPTION

在驱动程序提供的每个 GPU 上以及系统的软件设备上运行同一段简短的工作，并针对
每个 GPU 说明两者是否一致。

该工作将一个已知图案写入命令可以读取的内存，填充其旁边的内存，再将两者复制到
GPU 为自己保留的内存中并复制回来，最后请求一次超出缓冲区末尾的填充，任何设备
都必须拒绝该填充。当 GPU 留下的字节与软件设备相同，并且以相同的原因拒绝该填充
时，即为一致。

命令为每个 GPU 打印一行，注明其硬件节点：要么说明该 GPU 一致，要么给出发现的
第一处差异——读出不同值的字节、被拒绝的工作，或对填充的不同应答。

`sysinfo gpu` 列出本命令核对的 GPU。

## OPTIONS

- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `gpucheck` — 核对驱动程序提供的每个 GPU。

## EXIT STATUS

- `0` — 驱动程序提供的每个 GPU 都与软件设备一致。
- `1` — 某个 GPU 存在差异或无法访问、没有驱动程序提供任何 GPU、无法列出驱动
  程序提供的 GPU，或软件设备无法运行该工作。无法理解的命令行同样以 `1` 退出。
