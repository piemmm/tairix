## NAME

TextEdit — 图形化文本与十六进制编辑器

## SYNOPSIS

`TextEdit`

## DESCRIPTION

在桌面窗口中编辑任何文件：文本、源代码、系统的设置文件或原始字节。若在启动
时带有文档——由文件管理器或桌面启动，或把文件拖放到它在图标栏上的图标——它
就为该文件开一个窗口。若单独启动，它开一个空窗口。每个文档都是这一个编辑器
的一个窗口；关闭最后一个窗口后它仍留在图标栏上，图标菜单中的“退出”一行
才会结束它。

文件所含的任何内容都不会被隐藏。控制字节显示为 `[x03]`，不是有效 UTF-8 的
字节显示为 `[xC3]`，不可见字符或改变书写方向的字符显示为 `[U+202E]`，各有
各的颜色，且各自只占光标的一步。看似二进制数据的文件会在十六进制视图中打开，
该视图在每个字节的字符旁以两位十六进制数显示它，并与文本视图编辑同样的字节。

可执行文件（TAIRiX 程序映像、ELF64 文件或 WebAssembly 模块）会改为在代码
视图中打开：先列出其各个区域,再列出每个代码区域的指令,每行一条,附带地址和
编码字节,并标注指令起始处的符号和分支到达的符号。代码视图为只读；文本视图和
十六进制视图编辑同一个文件。代码由专属的第二个工作进程解码（同样无法触及任何
东西）,并按文件指明的指令集读取,否则按本机的指令集读取；“查看”菜单中的
“指令集”可按其他指令集读取,状态栏的视图字段在文本和十六进制之外还提供代码
视图。

图片（PNG、JPEG、GIF、BMP、TIFF、WEBP、图标或指针文件、RISC OS 精
灵区或 OpenRaster 文档）则会以数据视图打开：显示文件由什么组成，
每条记录及其偏移、长度和所声明的内容，每个 EXIF 标签的名称和值，然后以
十六进制逐字节显示整个文件及其对应字符。数据视图是只读的；十六进制视图可编辑
相同的字节。图片由专用的第三个工作进程读取，它同样无法访问任何内容；“视图”菜
单在文本和十六进制旁提供数据视图。

源代码会被着色：HTML、XML 与 SVG、CSS、JavaScript、JSON、YAML、TOML、Markdown、Rust、C、Java、Python 以及 shell 脚本。
系统的设置文件——应用设置、
程序库、系统与网络配置、服务覆盖设置、用户与组数据库，以及字体家族清单——也会
被着色，并用系统读取它们时所用的同一个解析器检查：问题会在其所在行旁的边栏
中标出，并在状态行中说明。格式先按文件名选择，再按文件开头的字节选择；在
“视图”菜单或状态行中选择的格式始终优先。

编辑器不持有任何文件系统能力。它只编辑交给它的那个文件。用户可以修改的文件
会以可写方式交给它，“保存”会把它写回；其他文件都是只读的，“保存”会询问把
副本保存到哪里。着色、格式识别与检查都在一个毫无访问能力的独立工作进程中
运行，因此含有恶意的文件无法触及编辑器所能触及的任何东西。

在窗口中任意位置按下辅助（右）鼠标按钮会打开其菜单：“剪切”“复制”“粘贴”
和“全选”，随后是“文件”“编辑”“查找”和“视图”，每一项都会打开各自的
子菜单。窗口没有菜单栏。

状态行显示光标所在的行与列、检查发现的问题，以及点击即可打开菜单的几个字段：
格式、文本或十六进制、换行方式和缩进。在有未保存的修改时关闭窗口或退出，会先
询问。用辅助（右）按钮点击关闭按钮来关闭窗口时，文件管理器还会在窗口的文件所
在的文件夹中显示该文件。

* `Ctrl+N` — 新建窗口
* `Ctrl+O` — 打开文件
* `Ctrl+S` — 保存；`Ctrl+Shift+S` — 另存为
* `Ctrl+W` — 关闭窗口
* `Ctrl+Z` — 撤销；`Ctrl+Shift+Z` 或 `Ctrl+Y` — 重做
* `Ctrl+X`、`Ctrl+C`、`Ctrl+V` — 剪切、复制、粘贴
* `Ctrl+A` — 全选
* `Ctrl+F` — 查找；`Ctrl+H` — 替换
* `F3` / `Shift+F3` — 下一个或上一个匹配
* `Ctrl+L` — 转到某一行
* `F8` — 检查发现的下一个问题
* `Ctrl+]` / `Ctrl+[` — 增加或减少所选行的缩进
* `Ctrl+/` — 把所选行注释掉或恢复
* `Ctrl+Shift+H` — 在文本视图与十六进制视图之间切换
* `Insert` — 在插入与改写之间切换
* `Tab` — 在十六进制视图中，在十六进制列与字符列之间移动

## OPTIONS

`-h`, `-?`, `--help`
: 将本帮助写至标准输出并退出。

## EXIT STATUS

“退出”后为零。当窗口通道、事件邮箱或桌面会话被拒绝时为非零；原因会在标准
错误流上说明。
