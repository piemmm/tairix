## NAME

TextEdit — テキストと16進数のグラフィカルエディタ

## SYNOPSIS

`TextEdit`

## DESCRIPTION

あらゆるファイルをデスクトップウィンドウで編集します。テキスト、ソース
コード、システムの設定ファイル、生のバイト列のいずれも扱えます。文書を伴って
起動された場合（ファイルマネージャやデスクトップからの起動、またはアイコン
バーのアイコンにファイルをドロップした場合）はそのファイルのウィンドウを
開きます。単独で起動された場合は空のウィンドウを開きます。文書はそれぞれ一つの
エディタのウィンドウです。最後のウィンドウを閉じてもエディタはアイコンバーに
残り、アイコンメニューの「終了」の行で終わります。

ファイルが含むものは何も隠されません。制御バイトは `[x03]`、正しい UTF-8 で
はないバイトは `[xC3]`、見えない文字や書字方向を変える文字は `[U+202E]` と
して表示され、それぞれ固有の色で、それぞれカーソルの一歩になります。
バイナリデータに見えるファイルは16進表示で開き、各バイトを文字の横に2桁の16進数で示し、
テキスト表示と同じバイトを編集します。

実行ファイル（TAIRiX のプログラムイメージ、ドライバー、ELF64 ファイ
ル、WebAssembly モジュール）は、代わりにコード表示で開きます。まずヘッダーが示
す内容として、各部分をそのオフセット、長さ、宣言内容とともに示します。ビルド対
象のシステムのバージョン、エントリーポイント、セグメントと必要なライブラリ、ド
ライバーの署名付きマニフェストとそれが求める権能および結び付くハードウェ
ア、ELF ファイルのプログラムヘッダーとセクションヘッダー、モジュールのセクショ
ンがこれに当たります。次に各コード領域の命令を、アドレスと符号化バイトとともに
1 行に 1 つずつ並べ、命令が始めるシンボルと分岐先のシンボルで印を付けます。鍵
と署名は書かれているとおりに示され、検証はされません。コード表示は読み取り専用
で、テキスト表示と 16 進表示が同じファイルを編集します。コードは専用の 2 つ目
のワーカープロセス（こちらも何にも手が届きません）が解読し、ファイルが示す命令
セット、なければこのマシンの命令セットとして読みます。表示メニューの「命令セッ
ト」で別の命令セットとして読み直せ、ステータス行の表示欄ではテキストと 16 進に
並んでコード表示を選べます。

画像（PNG、JPEG、GIF、BMP、TIFF、WEBP、アイコンファイル
やカーソルファイル、RISC OS のスプライト領域、OpenRaster 文
書）は、代わりにデータ表示で開きます。ファイルが何でできているか、各レコード
をそのオフセット、長さ、宣言内容とともに示し、EXIF タグをすべて名前と値
で示したあと、ファイルの全バイトを文字と並べて 16 進で表示します。署名付きマ
ニフェスト（アプリケーションの `AppInfo` やプログラムのマニフェスト）もデー
タ表示で開き、記載された名前、求める権能、扱うと宣言するファイル形式、探索す
るサービスを示したあと、そのバイト列を示します。データ表示は読み取り専用
で、16 進表示が同じバイトを編集します。画像は専用の 3 つ目のワーカープロセス
が、マニフェストはコード表示のワーカープロセスが読み取り、どちらも何にも手が
届きません。表示メニューではテキストと 16 進に並んでデータ表示を選べます。

ソースコードは色分けされます。
対象は HTML、XML と SVG、CSS、JavaScript、JSON、YAML、TOML、Markdown、Rust、C、Java、Python、シェルスクリプトです。
システムの設定ファイル（アプリケーション設定、プログラムライブラリ、システム
とネットワークの構成、サービスの上書き、ユーザーとグループのデータベース、
フォントファミリーのマニフェスト）も色分けされ、システムが読み取るときと
同じパーサで検査されます。問題はその行の横の余白に印が付き、ステータス行に
述べられます。形式はファイル名から選ばれ、次に先頭のバイトから選ばれます。
「表示」メニューやステータス行で選んだ形式が常に優先されます。

エディタはファイルシステムに対する権能をいっさい保持しません。渡された
ファイルだけを編集します。利用者が変更できるファイルは書き込み可能として
渡され、「保存」で書き戻されます。それ以外は読み取り専用で、「保存」は
コピーの保存先を尋ねます。色分け、形式の判定、検査はどこにも到達できない
別の作業プロセスで実行されるため、敵対的なファイルがエディタの到達しうる
ものに触れることはありません。

ウィンドウ内の任意の場所で副（右）マウスボタンを押すと、そのメニューが
開きます。「切り取り」「コピー」「貼り付け」「すべてを選択」に続いて
「ファイル」「編集」「検索」「表示」があり、それぞれが独自のサブメニュー
を開きます。ウィンドウにメニューバーはありません。

ステータス行にはカーソルの行と桁、検査で見つかったこと、そしてクリックすると
メニューが開く欄として、形式、テキストか16進か、改行の方式、字下げが
示されます。保存していない変更があるままウィンドウを閉じたり終了したり
すると、先に確認を求めます。ウィンドウの閉じるボタンを副（右）ボタンで押して
閉じると、あわせてそのファイルが、それを含むフォルダーの中でファイルマネー
ジャに表示されます。

* `Ctrl+N` — 新しいウィンドウ
* `Ctrl+O` — ファイルを開く
* `Ctrl+S` — 保存、`Ctrl+Shift+S` — 名前を付けて保存
* `Ctrl+W` — ウィンドウを閉じる
* `Ctrl+Z` — 元に戻す、`Ctrl+Shift+Z` または `Ctrl+Y` — やり直す
* `Ctrl+X`、`Ctrl+C`、`Ctrl+V` — 切り取り、コピー、貼り付け
* `Ctrl+A` — すべて選択
* `Ctrl+F` — 検索、`Ctrl+H` — 置換
* `F3` / `Shift+F3` — 次または前の一致
* `Ctrl+L` — 指定した行へ移動
* `F8` — 検査で見つかった次の問題
* `Ctrl+]` / `Ctrl+[` — 選んだ行の字下げを増やす、または減らす
* `Ctrl+/` — 選んだ行をコメントにする、または戻す
* `Ctrl+Shift+H` — テキスト表示と16進表示を切り替える
* `Insert` — 挿入と上書きを切り替える
* `Tab` — 16進表示で、16進の列と文字の列の間を移動する

## OPTIONS

`-h`, `-?`, `--help`
: このヘルプを標準出力に書き出して終了します。

## EXIT STATUS

「終了」の後はゼロ。ウィンドウチャネル、イベントメールボックス、または
デスクトップセッションが拒まれた場合は非ゼロで、理由は標準エラー出力に
述べられます。
