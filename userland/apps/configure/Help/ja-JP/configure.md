## NAME

configure — マシンの設定を読み取り・変更する

## SYNOPSIS

`configure [<key> [<value> [<key> <value>]...]]`

## DESCRIPTION

マシンの設定を一覧・表示・変更します。設定は
`/System/Settings/Configuration/system.conf` に保存されています。オペラ
ンドなしでは各設定が現在の値とともに一覧されます。キーのみを与えるとその
設定の値が表示され、`<key> <value>` の組を 1 つ以上与えるとそれらの設定
がまとめて変更されます。

複数の組を与えても変更は 1 つで、複数にはなりません。何かを変更する前に
すべての組が検査され、そのうえで設定がまとめて保存されます。未知のキー、
そのキーの集合外の値、または同じキーを 2 回指定したコマンド行は何ひとつ
変更しないため、一群の設定が中途半端に適用されたまま残ることは決してあり
ません。

設定を変更できるのは管理者だけです。一般のアカウントはマシンの設定を読め
ますが、どれも変更できません。システムは独自の設定を備えており、管理者が
いずれかを変更するまではそれが有効です。最初の変更でも、システムが備えて
いたほかの設定はすべて保たれます。変更は、それを読み取るシステムの部分が
次に起動したときに有効になります（`os.loginType` は次回のログイン時、
`cache.*` スイッチは次回の起動時）。ただし、下のキーの説明に別の記載があ
る場合はそれに従います。

キーの集合は閉じています。未知のキーや、キーの集合外の値は、有効な
選択肢を示して拒否され、何も変更しません。

- `os.loginType` — `text` または `graphical`：ログインサービスが認証
  済みユーザーに対して開始するセッション種別。`graphical`（既定）は
  認証後にデスクトップセッションを直接開始し、デスクトップを動かせな
  い機械ではテキストログインに退避します。`text` はアカウントのシェ
  ルを開始します（デスクトップはグラフィカルログインからのみ起動しま
  す）。
- `cache.all` — `on` または `off`：キャッシュのマスタースイッ
  チ。`on`（既定）は下の各キャッシュ分類がそれぞれの設定に
  従うようにします。`off` は上限であり、分類ごとの設定に
  かかわらずすべてのメモリキャッシュを無効にします。
- `cache.filesystem`、`cache.block`、`cache.transform`、
  `cache.semantic` — `auto` または `off`：回収可能な4つのメモ
  リキャッシュ（ファイルシステム、ディスク全体のブロック、
  展開済みクラスタ、アプリケーション起動の各キャッシュ）に
  対する分類ごとのスイッチ。`auto`（既定）はメモリ圧迫マネ
  ージャーに分類を管理させます。`off` はそれを完全に無効にし
  ます。分類ごとの `on` はありません。分類にメモリ圧迫を無
  視させることはできません。`cache.all` が `off` のときは常に、
  その分類は実質的に `off` です。

どのキャッシュも回収可能なアクセラレーターであり、決して真実の
源ではありません。そのためいずれか、またはすべてを切っても、
影響を受ける処理が遅くなるだけで、結果が変わることは決してあり
ません。

- `net.ipv4.enabled`、`net.ipv6.enabled` — `true` または `false`:
  スタック全体のアドレスファミリー切り替え。既定はどちらも `true`
  です。無効化されたファミリーはアドレスを割り当てず、パケットに
  応答せず、そのファミリーのソケットを型付きエラーで拒否します
  — 黙って破棄することはありません。
- `net.ipv6.privacy` — `true` または `false`: 安定アドレスに加えて
  一時的（プライバシー）IPv6 アドレスを生成するかどうか。`false`
  （既定）は安定した SLAAC アドレスのみを使います。
- `net.tcp.syncookies` — `auto` または `always`: SYN フラッド防御の
  方針。`auto`（既定）は上限付きの半開きキューを保持し、あふれた
  ときにステートレス cookie へ切り替えます。`always` はすべての接続
  要求にステートレスで応答します。`off` はありません — 無防備な
  接続キューは設定ではありません。
- `net.tcp.keepalive` — `true` または `false`: アイドル状態のリンクで
  TCP 接続がキープアライブ探査を送るかどうか。`false`（既定）は決して
  探査せず、アイドル接続を切断しません。`true` は通常の間隔の後に
  アイドルの相手へ探査を送り、応答が止まれば接続を切断します。
- `net.tcp.ecn` — `true` または `false`: TCP 接続が明示的輻輳通知
  （ECN）をネゴシエートするかどうか。`false`（既定）は接続を Not-ECT
  のままにします。`true` はハンドシェイクで ECN を提示し、以後は輻輳
  マークをパケット破棄の強制ではなく減速の合図として扱います。
- `net.sockets.mem` — `auto` または `64M` のようなバイト数: ネットワーク
  スタックが全プリンシパル合計でソケット状態として保持できるメモリー量。
  `auto`（既定）はマシンの RAM から算出するので、大きなサーバーが小さな
  マシンで選ばれた値に縛られません。サイズを指定すると、事情をよく知る
  運用者がそれを上書きできます。各プリンシパルは実効予算の十六分の一まで
  保持できるので、常に 16 プリンシパル分の余地があります。ソケット数では
  なくバイト数なのは、同じ数のソケットが遊休時には数キロバイト、バッ
  ファーが満ちれば数メガバイトになるためです。予算は実際の負荷に応じて、
  多数の静かな接続か、より少数の多忙な接続を収めます。
- `time.servers` — `none` またはカンマ区切りのネットワーク時刻サーバー
  一覧。各項目はホスト名かアドレスです。`none`（既定）は自分のサーバーを
  指定しないという意味で、その場合はネットワークのアドレス割り当てが示す
  サーバー、それもなければ公開プール `pool.ntp.org` から時刻を合わせます。
  ここで指定したサーバーはその両方より優先されます。
- `time.refresh` — `6h`、`12h`、`1d`、`2d`、`7d` のいずれか: 時刻が判明
  したあと、次に時刻を問い合わせるまでの稼働時間です。既定は `1d` です。
  未設定・不自然・長く古いままの時刻は、この設定にかかわらずネットワーク
  が使えるようになった時点で直ちに修正されます。
- `time.network` — `on`（既定）または `off`: そもそもネットワークから時刻
  を合わせるかどうか。`off` ではどのサーバーにも時刻を問い合わせず、時刻は
  手動で、またはボードの時計チップから設定されます。時計チップはどちらの
  場合も起動のたびに読み取られます。変更はすぐに反映されます。この設定は
  システムディスクにあるため、起動直後、そのディスクに届くまでは既定値が
  使われます。
- `time.zone` — `default` または `Europe/London` のようなタイムゾーン名:
  マシンが従うタイムゾーンです。ログイン画面に表示され、タイムゾーンを選
  んでいないアカウントが使います。`default` はシステムが独自に備えるゾー
  ンです。システムのゾーン一覧にない名前は無視され、`default` として扱わ
  れます。変更はすぐに反映されます。
- `input.mouse.debounce` — 整数ミリ秒、既定は `25`、`0` で無効、最大は
  `100`: マウスボタンを離したあと、同じボタンの次の押下を新しいクリックと
  みなさずスイッチのチャタリングとして無視する時間です。摩耗したスイッチ
  は、1 回のクリックのつもりでも離してから数ミリ秒後に 2 回目の押下を報告
  することがあります。連射モードが意図的にクリックの組を送るマウスでは
  `0` にしてください。
- `audio.output`、`audio.input` — 既定は `auto`、または `audioctl` が表示
  するエンドポイントの位置（16 桁の 16 進数、ドット、エンドポイントの番号）:
  このマシンが既定として優先する出力と入力です。セッション自身の選択が
  先に来ます。これは誰もサインインする前と、デスクトップのないマシンでの
  選択です。`auto` は最初に見つかったデバイスです。
- `audio.level` — デシベル値で、既定は `0dB`、または `-12dB` や `-6.5dB`
  のような減衰（小数点以下 2 桁まで）: すべての出力と入力の開始レベルです。
  `0dB` を超えることはありません。オーディオサービスは変更された値を次回の
  起動時に採用し、`audioctl` は動作中のマシンを変更します。

上の一覧にないキーは、2 つ目のレジストリで調べられます。それは各インター
フェースのネットワーク設定で、`/System/Settings/Network/network.conf` に
保存されています。キーは `<interface>.<setting>` の形で書き、
`<interface>` は管理者がネットワークインターフェースに付けた別名
（`wan`、`lan0`）、`<setting>` は `kind`、`match.mac`、`match.node`、
`ipv4.method`、`ipv4.address`、`ipv4.gateway`、`ipv6.method`、
`ipv6.address`、`ipv6.gateway`、`dns.servers`、`mtu`、`bond.members`、
`bond.mode`、`bond.monitor-interval`、`bond.primary` のいずれかです。

上のマシンのレジストリが常に先に検索されるので、インターフェースの別名が
マシンの設定の名前を乗っ取ることはありません。

ネットワーク設定には既定値がないため、一覧には設定済みの項目だけが表示さ
れ、設定されていない項目を表示すると、値を作り出す代わりに空行を返しま
す。これらを読み取ったり変更したりできるのは管理者だけです。各インター
フェースのハードウェアとこのマシンのアドレスを示すものだからです。それ以
外の人の一覧にはマシンの設定が表示され、ネットワーク設定は表示されない旨
が示されます。

このレジストリには既定値がないため、設定はリセットではなく削除となり、削
除には**空の値**を使います: `configure wan.ipv4.address ""`。空の値を受
け付けるインターフェース設定はないので、この書き方が値の設定と取り違えら
れることはありません。これにより、1 つのコマンドでインターフェースを静的
アドレスから DHCP に切り替えられます:
`configure wan.ipv4.method dhcp wan.ipv4.address "" wan.ipv4.gateway ""`。
この変更は、どちらの半分も単独では整合した構成を表しません。最後の設定が
削除されたインターフェースは、もはやまったく宣言されていない状態になりま
す。

何かを保存する前に、編集後の構成全体が検査されます。構成を矛盾した状態に
する変更（アドレスのない静的方式、メンバーが 2 つ未満のボンディング）は
拒否され、何も保存されません。

`net.*` 設定やインターフェースごとの設定を変更すると、それが保存されて動
作中のネットワークスタックに届けられるので、すぐに有効になります。届けら
れるのは、変更が実際に影響したインターフェースだけです。動作中のスタック
が受け付けない場合（動作中のスタックがない、またはあなたのアカウントに
ネットワークを管理する権限がない場合）でも、設定は保存され、`configure`
がその旨を伝えます。その設定は次回の起動時に適用されます。

2 つの制限は隠さずに報告されます。構成から削除したインターフェースは、ス
タックにはインターフェースを退役させるメッセージがないため、次回の起動ま
で、スタックに最後に渡された構成のまま動作し続けます。`match.mac` も
`match.node` も持たずに保存されたインターフェースは決してデバイスに結び
付けられないため、保存されたうえで、拒否されたことが明示されます。

## OPTIONS

- `-h, -?` — このコマンドの短いヘルプを表示する。

## EXAMPLES

- `configure` — すべての設定を一覧する。
- `configure os.loginType` — 既定のセッション種別を表示する。
- `configure os.loginType graphical` — グラフィカルログインで起動する。
- `configure cache.all off` — システム全体のすべてのメモリキャッ
  シュを無効にする。
- `configure cache.filesystem off` — ファイルシステムキャッシュ
  のみを無効にする。
- `configure net.ipv6.enabled false` — スタック全体で IPv6 を無効にす
  る。
- `configure time.servers 0.example.test,1.example.test` — 時計の同期元
  となるネットワーク時刻サーバーを設定する。
- `configure time.zone Europe/London` — マシンをロンドン時間に合わせる。
- `configure wan.ipv4.address` — `wan` という名前のインターフェースに設
  定された静的 IPv4 アドレスを表示する。
- `configure wan.ipv4.address 10.0.0.7/24 wan.ipv4.gateway 10.0.0.1` —
  `wan` に静的 IPv4 アドレスとデフォルトゲートウェイを設定する。
- `configure wan.ipv4.method dhcp wan.ipv4.address "" wan.ipv4.gateway ""`
  — `wan` を静的アドレス指定から DHCP に切り替える。
- `configure wan.dns.servers 9.9.9.9,2001:db8::53` — `wan` で使う再帰
  DNS サーバーを設定する。

## EXIT STATUS

- `0` — 一覧・値・短いヘルプ・変更が完了した。
- `1` — 設定を読み取れなかった、または変更できなかった（例：呼び出し側に
  マシンの設定を変更する権限がない、またはそのネットワーク設定を読み取る
  権限がない）か、出力を届けられなかった。
- `2` — コマンド行を解釈できなかった、キーが未知、値がキーの集合外だっ
  た、または変更によってネットワーク構成が矛盾した状態になる。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`fr-FR` のような BCP-47 タグ）。
