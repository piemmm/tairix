## NAME

Paint — 画像とスプライトのグラフィカルエディター

## SYNOPSIS

`Paint`

## DESCRIPTION

デスクトップのウィンドウで、ピクセル単位で、あるいはブラシや図形を使って
画像を描き、編集します。ドキュメントを伴って起動すると——ファイルマネー
ジャーから、デスクトップから、またはアイコンバーのアイコンにファイルを
ドロップして——そのドキュメントのウィンドウを開きます。単独で起動すると、
新しい白い画像を開きます。各ドキュメントはひとつのプログラムのウィンドウ
であり、最後のウィンドウを閉じてもアイコンバーに残り、アイコンメニューの
「終了」の行で終わります。

システムが読めるすべての画像形式を開きます：PNG、JPEG、GIF、BMP、TIFF、
WebP、Windows アイコン、そして RISC OS のスプライトファイルです。書き出せる
のは PNG、JPEG、スプライトファイルで、それ以外の形式から読んだ画像は新しい
ファイルとして保存されます。PNG はパレットを保ち、JPEG は「ファイル」
メニューの「JPEG の品質」で設定した品質で書き出されます。

スプライトファイルは任意の数のスプライトを持ち、それぞれに名前、画面
モード、パレット、マスクがあります。どの色深度も保存されているとおりに
編集されます：2、4、16、256 色、そして数百万色です。独自のパレットを持た
ないスプライトは RISC OS デスクトップの色で表示されます——16 色では色 n が
Wimp の色 n、2 色では Wimp の色 0 と 7、4 色では Wimp の色 0、2、4、7、
256 色では RISC OS の色合い配列——PC のパレットになることはありません。
モード 12 のようにピクセルが横より縦に長いスプライトは、そのとおりに表示
されます。このエディターが読めないスプライト（CMYK のものなど）は元の
とおりに保持され、変更されないまま保存し直されます。「スプライト」メニュー
では、スプライトへの移動、追加、複製、名前の変更、削除、並べ替えができます。

主（左）ボタンは主の色で、中ボタンは副の色で描きます。Alt を押している
間は、代わりに色を拾います。ツールは選択、鉛筆、ブラシ、スプレー、消しゴム、
塗りつぶし、スポイト、直線、長方形、楕円です。画像の横のパネルには二つの色、
画像のパレットまたはデスクトップの色、そして使用中のツールの設定があります。
色の枠をクリックするとその色を編集し、パレットの色をダブルクリックすると
パレットを編集します。Shift を押しながら描くと、正方形、円、または 45 度の
倍数の角度の直線になります。

選択ツールでは、ドラッグして画像の一部を囲み、次に選択範囲をドラッグして
移動します。選択範囲は置かれるまで浮いており、移動はひとつの取り消し
単位です。コピーした画像は PNG としてクリップボードを通り、貼り付けたもの
も置かれるまで浮いています。

このプログラムはファイルシステムの権限を一切持ちません。渡されたファイル
だけを編集します。ユーザーが変更できるファイルは書き込み可能として渡され、
「保存」でそこへ書き戻します。それ以外は読み取り専用で、「保存」はコピーの
保存先を尋ねます。画像も、クリップボードから貼り付けた画像も、何にも触れ
られない別の作業プロセスでデコードされ、ドキュメントごとに新しいプロセスが
使われます。悪意あるファイルでも、このプログラムが触れられるものには何も
触れられません。

ウィンドウ内のどこかでマウスの副（右）ボタンを押すと、そのメニューが開き
ます：「切り取り」「コピー」「貼り付け」「すべてを選択」「選択の解除」、続いて
「ファイル」「編集」「画像」「色」「スプライト」「表示」「ツール」で、それぞれが
サブメニューを開きます。ウィンドウにメニューバーはありません。保存して
いない変更があるままウィンドウを閉じたり終了したりすると、先に確認します。

* `Ctrl+N` — 新しい画像；`Ctrl+O` — ファイルを開く
* `Ctrl+S` — 保存；`Ctrl+Shift+S` — 名前を付けて保存
* `Ctrl+W` — ウィンドウを閉じる
* `Ctrl+Z` — 取り消し；`Ctrl+Shift+Z` または `Ctrl+Y` — やり直し
* `Ctrl+X`、`Ctrl+C`、`Ctrl+V` — 切り取り、コピー、貼り付け
* `Ctrl+A` — すべてを選択；`Ctrl+D` — 選択の解除
* `Enter` — 浮いている選択範囲を置く；`Escape` — 元に戻す
* `Delete` — 選択範囲を消去する
* `Ctrl+Shift+X` — 選択範囲で切り抜く
* `Ctrl+R` — サイズの変更；`Ctrl+Shift+R` — キャンバスのサイズ
* `Ctrl+[` / `Ctrl+]` — 左または右に回転
* `Ctrl+I` — 色を反転する
* `S`、`P`、`B`、`A`、`E`、`F`、`I`、`L`、`R`、`O` — 順に各ツール
* `X` — 主の色と副の色を入れ替える
* `+` / `-` — 拡大または縮小；`1` — 実寸；`Ctrl+0` — ウィンドウに合わせる
* `Ctrl` + ホイール — ポインターを中心に拡大・縮小する
* 2本の指でピンチ — なめらかに拡大・縮小する。タッチスクリーンでは画像が指に追従する
* `G` — ピクセル間のグリッドの表示・非表示
* `Page Up` / `Page Down` — 前または次のスプライト
* 矢印キー — 浮いている選択範囲を 1 ピクセル動かす；`Shift` と一緒なら 10

## OPTIONS

`-h`, `-?`, `--help`
: このヘルプを標準出力に書き出して終了します。

## EXIT STATUS

「終了」の後はゼロ。ウィンドウチャネル、イベントメールボックス、または
デスクトップセッションが拒まれた場合は非ゼロで、理由は標準エラー出力に
述べられます。
