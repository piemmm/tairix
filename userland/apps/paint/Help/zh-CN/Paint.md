## NAME

Paint — 图形化的图片与精灵编辑器

## SYNOPSIS

`Paint`

## DESCRIPTION

在桌面窗口中逐像素地，或用画笔和形状，绘制和编辑图片。带着文档启动时——
从文件管理器、从桌面，或把文件拖放到图标栏中它的图标上——它为该文档打开
一个窗口。单独启动时，它打开一张新的白色图片。每个文档都是同一个程序的一个
窗口；关闭最后一个窗口后它仍留在图标栏上，其图标菜单中的“退出”一行会结束它。

它能打开系统可读的每一种图片格式：PNG、JPEG、GIF、BMP、TIFF、WebP、
Windows 图标、RISC OS 精灵文件和 OpenRaster。它写出 PNG、JPEG、GIF、BMP、
TIFF、精灵文件和 OpenRaster；从其他格式读取的图片，或从包含图片以外内容
（例如颜色配置文件）的文件读取的图片，会另存为新文件。“新建图片”先询问
图片用于哪种格式，并给出该格式能容纳的颜色。“另存为”询问格式及该格式自身
的设置——JPEG 的质量、GIF 是否隔行、TIFF 的压缩方式——并说明该格式无法
保留的内容，然后才询问保存位置。只要格式能容纳调色板，调色板就会保留，
图片的密度也是如此。

一张图片可以由图层组成，最下面的在前，每个图层都有名称、不透明度以及是否
显示；绘制每次落在一个图层上，窗口把它们叠在一起显示。OpenRaster 保留各个
图层；其他格式写出的是叠合后的结果。“图层”菜单可添加、复制、删除、上移和
下移图层，把一个图层向下合并到下面的图层，并拼合图片；其中的“图层属性”可
重命名图层并设定它显示的程度。调整、填充和笔画改变正在绘制的图层；旋转、
翻转、调整大小和裁剪改变每一个图层。带调色板的图片只有一个图层。

精灵文件可以容纳任意数量的精灵，每个精灵都有名称、屏幕模式、调色板和遮罩。
每种颜色深度都按存储时的样子编辑：2、4、16、256 色以及数百万种颜色。没有
自身调色板的精灵显示 RISC OS 桌面的颜色——16 色时颜色 n 是 Wimp 颜色 n；
2 色时为 Wimp 颜色 0 和 7；4 色时为 Wimp 颜色 0、2、4 和 7；256 色时为
RISC OS 的色调排列——绝不是 PC 调色板。像素高大于宽的精灵（如模式 12）
就照此显示。本编辑器无法读取的精灵（如 CMYK 精灵）会原样保留，并原封不动
地写回。“精灵”菜单可前往、添加、复制、重命名、删除和重新排列精灵。TIFF
可以容纳任意数量的页面，此时“页面”菜单可前往、添加、复制、删除和重新排列
页面。

主（左）键用主颜色绘制，中键用副颜色绘制；按住 Alt 则改为按图层显示的样子
拾取颜色。工具面板中的工具箱把工具排成两列：选择、铅笔、画笔、喷枪、橡皮擦、
仿制、填充、渐变、吸管、文字、直线、矩形、椭圆、多边形、裁剪、抓手和缩放。
顶部的栏显示正在使用的工具名称，并包含它的设置——画笔的大小、硬度、不透明度、
流量和间距，填充的容差，渐变的形状，文字的大小，矩形的圆角——可以输入，也可
以用方向键调节；还有缩放和显示像素网格的按钮。图片下方的调色板条包含图片的
调色板，或桌面颜色。喷枪在保持不动时仍会持续喷涂。按住 Shift 会画出正方形、
圆形或角度为 45 度倍数的直线。

窗口两侧排列着面板：默认左侧是工具面板，右侧是颜色面板，打开调整后其下方会出
现调整面板。每个面板顶部有一条细带写着它的名称，带有把它卷起到细带的控件和关
闭它的标记；视图 ▸ 面板 会重新显示已关闭的面板，重置面板 会把每个面板放回新
窗口中的样子。拖动细带可把面板移到同一侧的其他位置或另一侧，拖动时会标出它将
落下的位置；在远离两侧的地方松开，或拖出窗口后，面板会浮在一个属于它自己的小
窗口中，由细带移动、保持在图片上方，并可用其标记关闭；再拖回到某一侧上方，它
就会重新停靠在那里。

选择工具可以框出矩形、椭圆、徒手套索、逐角点击的多边形，或用魔棒选出与某个
像素通过相似颜色相连的像素。Shift 加入选区，Alt 从选区中减去，两者同时按住
则只保留两者共有的部分；“羽化”使其边缘变柔和。选区存在时，每个工具、填充和
调整都被限制在其中。在选区内拖动会把它提起并移动：它会一直浮动，直到被放下，
而移动是一次可撤销的更改。复制的图片以 PNG 形式经过剪贴板，粘贴的内容会
一直浮动，直到被放下。

仿制工具绘制图片中其他位置的内容：按住 Alt 点击要复制的来源，然后绘制。
渐变工具沿着拖动方向把主颜色混合到副颜色，呈条带状或环状。文字工具把输入的
文字放在点击的位置；Enter 开始新的一行，再点击一次或换用其他工具即放下文字，
Escape 则丢弃它们。多边形工具的各个角依次点击，点击第一个角或按 Enter 即可
闭合。裁剪工具标出要保留的部分，拖动它的手柄可移动边缘，按 Enter 即裁剪。
抓手在窗口中拖动图片，按住 Space 时任何工具都能如此；缩放工具点击放大，按住
Alt 点击缩小，拖出的方框会充满窗口。

调整菜单在调整面板中打开一项调整，此时其他工具、面板和菜单都仍可使用：亮度
和对比度、色相和饱和度、色彩平衡、色阶、曲线、白平衡、色调分离、阈值、模糊、
锐化、像素化和添加杂色；没有设置的去色和查找边缘会立即应用。设置变动时图片会
显示调整效果，预览 可以关闭再打开以便比较，重置 恢复它的设置，应用 把它保留为
一次可撤销的更改；绘制、填充或选择另一项调整会先应用它。色阶在图层的直方图上
设置黑、灰、白三个点，可对所有通道一起或逐个通道设置，并有从图片取点的吸管和
自动；曲线通过在直方图上拖动的点来弯曲某个通道的色调；白平衡根据选取的中性像
素或通过自动设置光线的色温和色调；色相和饱和度可旋转、增强并提亮全部颜色或其
中一个范围；色彩平衡把阴影、中间调和高光推向红、绿或蓝，并可按要求保持其亮度。
一切都限于选区之内。在带调色板的图片上，调整会改变它的调色板，需要相邻颜色的
调整不会提供。

颜色面板包含主颜色和副颜色，以及用于所选颜色的取色器：点击一种颜色将其选中，
然后可以在色相条旁的饱和度与明度方块上、在三角形外的色相环上或在每个通道的滑
块上选取，并以 RGB、HSV、HSL、CMYK、Lab、LCh 或灰度输入，或以十六进制写法
输入；在图片带有透明度之处，还可输入其不透明度。屏幕无法显示的 Lab 或 LCh 颜
色会尽可能接近地显示，并加以标记。交换 互换两种颜色，重置 把它们设为黑和白，
拾取 取得接下来在图片中点击的颜色。原来的颜色显示在旁边，点击即可恢复，最近选
过的颜色列在下方，可以再次选择。在带调色板的图片中，颜色就是它的条目，因此取
色器编辑的是调色板，每次编辑都是一次可撤销的更改。

图标栏菜单中的 设置 会打开 Paint 的设置窗口：新窗口开始时使用的工具，以及图
片打开时是适合窗口还是实际大小；新建图片 提供的大小、格式、颜色和背景；网格
的间距、偏移、颜色、不透明度和样式——实线、虚线、点或交叉点——，新窗口是否显
示网格、是否对齐到网格，以及从多大缩放开始显示像素之间的网格；棋盘格的大小和
色调以及图片周围的颜色；还有新窗口打开时的面板。更改会立即应用到每个窗口并保
留到下次；恢复默认值 会全部还原。视图 ▸ 网格 显示窗口的网格。网格显示且对齐
开启时，形状、选区和裁剪框会覆盖整个格子，直线和渐变的端点以及多边形的角会落
在网格交点上，拖动的选区会以其角落在某个交点上。

本程序不持有任何文件系统权限。它只编辑交给它的文件。用户可以修改的文件会以
可写方式交给它，“保存”会把它写回；其他文件都是只读的，“保存”会询问把副本
保存到哪里。图片以及从剪贴板粘贴的图片都在一个毫无访问能力的独立工作进程中
解码，每个文档都会得到一个新的进程：恶意文件无法触及本程序能触及的任何东西。

在窗口任意位置按下鼠标副（右）键会打开其菜单：剪切、复制、粘贴、全选和取消
选择，接着是文件、编辑、图片、图层、颜色、调整、精灵或页面、视图和工具，
每一项都打开自己的子菜单。窗口没有菜单栏。在有未保存的更改时关闭窗口或退出，
会先询问。

* `Ctrl+N` — 新建图片；`Ctrl+O` — 打开文件
* `Ctrl+S` — 保存；`Ctrl+Shift+S` — 另存为
* `Ctrl+W` — 关闭窗口
* `Ctrl+Z` — 撤销；`Ctrl+Shift+Z` 或 `Ctrl+Y` — 重做
* `Ctrl+X`, `Ctrl+C`, `Ctrl+V` — 剪切、复制、粘贴
* `Ctrl+A` — 全选；`Ctrl+D` — 取消选择
* `Enter` — 放下浮动的选区、闭合多边形或裁剪；`Escape` — 退回
* `Delete` — 清除选区；`Alt+Backspace` — 用主颜色填充它
* `Ctrl+Shift+X` — 裁剪到选区
* `Ctrl+R` — 调整大小；`Ctrl+Shift+R` — 画布大小
* `Ctrl+[` / `Ctrl+]` — 向左或向右旋转
* `Ctrl+I` — 反转颜色
* `Ctrl+Shift+N` — 新建图层；`Ctrl+E` — 向下合并；`Ctrl+Shift+E` — 拼合
* `Ctrl+Page Up` / `Ctrl+Page Down` — 在上方或下方的图层上绘制
* `Ctrl+Shift+Page Up` / `Ctrl+Shift+Page Down` — 上移或下移图层
* `S`, `P`, `B`, `A`, `E`, `C`, `F`, `D`, `I`, `T`, `L`, `R`, `O`, `Y`, `K`, `H`, `Z` — 依次对应各个工具
* `Space` — 按住时，用任何工具拖动图片
* `X` — 交换主颜色和副颜色
* `Tab` — 依次经过工具设置、调色板条和颜色停靠栏；`Shift+Tab` — 反向移动；`Escape` — 回到图片
* `+` / `-` — 放大或缩小；`1` — 实际大小；`Ctrl+0` — 适合窗口
* `Ctrl` + 滚轮 — 以指针为中心放大或缩小
* 双指捏合 — 平滑缩放；在触摸屏上图片会跟随手指
* `G` — 显示或隐藏像素之间的网格
* `Ctrl+'` — 显示或隐藏网格
* `Page Up` / `Page Down` — 上一个或下一个精灵或页面
* 方向键 — 将浮动的选区移动一个像素；按住 `Shift` 则移动十个；在调色板条中依次经过各个颜色

## OPTIONS

`-h`, `-?`, `--help`
: 将本帮助写到标准输出并退出。

## EXIT STATUS

执行“退出”后为零。当窗口通道、事件邮箱或桌面会话被拒绝时为非零值；
原因会写在标准错误输出上。
