## NAME

Paint — 图形化的图片与精灵编辑器

## SYNOPSIS

`Paint`

## DESCRIPTION

在桌面窗口中绘制和编辑图片，可以逐像素编辑，也可以使用画笔和形状。
带着文档启动时——从文件管理器、从桌面，或把文件拖放到图标栏中的图标
上——它会为该文档打开一个窗口。单独启动时，它会打开一张新的白色图片。
每个文档都是同一个程序的一个窗口；关闭最后一个窗口后程序仍留在图标栏
中，图标菜单中的“退出”一行才会结束它。

它能打开系统可读取的所有图片格式：PNG、JPEG、GIF、BMP、TIFF、WebP、
Windows 图标以及 RISC OS 精灵文件。它可以写入 PNG、JPEG 和精灵文件；
从其他任何格式读取的图片会另存为新文件。PNG 会保留其调色板，JPEG
按“文件”菜单中“JPEG 质量”所设的质量写入。

一个精灵文件可以容纳任意数量的精灵，每个精灵都有自己的名称、屏幕模式、
调色板和蒙版。每种色深都按其存储方式编辑：2、4、16、256 色以及数百万
色。没有自带调色板的精灵显示 RISC OS 桌面的颜色——16 色时，第 n 种颜色
就是 Wimp 颜色 n；2 色时为 Wimp 颜色 0 和 7；4 色时为 Wimp 颜色 0、2、
4 和 7；256 色时为 RISC OS 的色调排列——绝不会是 PC 的调色板。像素高
大于宽的精灵（如模式 12）会按此显示。本编辑器无法读取的精灵（例如
CMYK 精灵）会原样保留，并在保存时原封不动地写回。“精灵”菜单可以转到、
添加、复制、重命名、删除和重新排列精灵。

主（左）键用主颜色绘画，中键用副颜色绘画；按住 Alt 则改为取色。工具有：
选择、铅笔、画笔、喷枪、橡皮擦、填充、取色器、直线、矩形和椭圆；图片
旁边的面板中有这两种颜色、图片的调色板或桌面颜色，以及当前工具的设置。
单击颜色框可以编辑该颜色；双击调色板中的颜色可以编辑调色板。按住 Shift
可绘制正方形、圆形，或角度为 45 度倍数的直线。

使用选择工具时，拖动以框选图片的一部分，然后拖动选区来移动它；选区会
一直浮动，直到被放下，而移动它只算一步可撤销的更改。复制的图片以 PNG
格式经由剪贴板传递，粘贴的内容也会一直浮动，直到被放下。

本程序不持有任何文件系统权限，只编辑交给它的那个文件。用户可以修改的
文件会以可写方式交给它，“保存”会把它写回；其他文件都是只读的，“保存”
会询问副本的保存位置。图片以及从剪贴板粘贴的图片都在一个完全没有访问
权限的独立工作进程中解码，而且每个文档都会得到一个新的工作进程：恶意
文件无法触及本程序能触及的任何东西。

在窗口中任意位置按下鼠标副（右）键会打开其菜单：剪切、复制、粘贴、全选
和取消选择，然后是“文件”“编辑”“图片”“颜色”“精灵”“视图”和“工具”，
每一项都会打开自己的子菜单。窗口没有菜单栏。关闭窗口或退出时若有未保存
的更改，会先进行询问。

* `Ctrl+N` — 新建图片；`Ctrl+O` — 打开文件
* `Ctrl+S` — 保存；`Ctrl+Shift+S` — 另存为
* `Ctrl+W` — 关闭窗口
* `Ctrl+Z` — 撤销；`Ctrl+Shift+Z` 或 `Ctrl+Y` — 重做
* `Ctrl+X`、`Ctrl+C`、`Ctrl+V` — 剪切、复制、粘贴
* `Ctrl+A` — 全选；`Ctrl+D` — 取消选择
* `Enter` — 放下浮动的选区；`Escape` — 放回原处
* `Delete` — 清除选区
* `Ctrl+Shift+X` — 裁剪到选区
* `Ctrl+R` — 调整大小；`Ctrl+Shift+R` — 画布大小
* `Ctrl+[` / `Ctrl+]` — 向左或向右旋转
* `Ctrl+I` — 反转颜色
* `S`、`P`、`B`、`A`、`E`、`F`、`I`、`L`、`R`、`O` — 按顺序对应各个工具
* `X` — 交换主颜色和副颜色
* `+` / `-` — 放大或缩小；`1` — 实际大小；`Ctrl+0` — 适合窗口
* `G` — 显示或隐藏像素之间的网格
* `Page Up` / `Page Down` — 上一个或下一个精灵
* 方向键 — 将浮动选区移动一个像素；按住 `Shift` 则移动十个

## OPTIONS

`-h`, `-?`, `--help`
: 将本帮助写到标准输出并退出。

## EXIT STATUS

执行“退出”后为零。当窗口通道、事件邮箱或桌面会话被拒绝时为非零值；
原因会写在标准错误输出上。
