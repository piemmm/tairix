## NAME

tail — 输出文件的末尾部分

## SYNOPSIS

`tail [option...] [file...]`

## DESCRIPTION

将每个 `file` 的最后 10 行打印到标准输出。当有多个 `file` 时，每部分前面
都会加上 `==> file <==` 标题。没有 `file`，或当 `file` 为 `-` 时，读取
标准输入。

`-n` 和 `-c` 改变打印的数量：普通计数（或以 `-` 开头写出的计数）打印最后
`num` 行或字节；以 `+` 开头写出的计数打印从第 `num` 行或字节
（从 1 开始计数）**起**到末尾的全部内容。计数可以带一个乘数后缀：`b`
(512)、`kB` (1000)、`K` (1024)、`MB`、`M`、`GB`、`G`，`T`、`P`、`E`、
`Z`、`Y`、`R`、`Q` 依此类推（单个字母按 1024 的幂相乘；带 `B` 按 1000 的
幂；带 `iB` 按 1024 的幂）。

历史的首参数形式 `tail -num` / `tail +num`（可带一个可选的末尾字母
`b`/`c`/`l`）也被接受，与 GNU 工具一致。

跟随模式保持每个文件打开，并随着文件增长输出新数据。`-f` 按描述符跟随已打
开的文件——重命名或移动后仍跟随同一个文件。`-F` 跟随*名称*：当文件被轮换
（被改名移走，并有新文件放在原处）时，它会重新打开新文件；`--retry` 会持续
尝试一个尚不存在的名称。跟随会阻塞直到文件确实发生变化——绝不让 CPU 空转。
`--pid=PID` 在进程 `PID` 退出后结束跟随，每隔 `--sleep-interval`（秒，默认
1）检查一次。`--max-unchanged-stats=N` 控制 `-F` 为检查轮换而重新检查名称
之前要经过多少个静止周期（默认 5）。截断（文件缩小）会被报告，并从文件的
新起点重新跟随。

当未显示开头内容时，会向标准信息流（fd 3）写入一条提示记录；它绝不会改变
输出或退出状态。无法读取的文件会在错误输出上报告，运行会继续处理下一个
文件。

在终端上，输出所显示的每个名称都在 shell 需要之处加上引号，其中的控制字
符或其他不可见字符均以转义形式写出，因此名称无法操控或重排屏幕；GNU 则原
样显示名称。管道或文件逐字节原样接收名称。

## OPTIONS

- `-c, --bytes <num>` — 打印每个文件的最后 `num` 个字节；以 `+` 开头时，
  打印从第 `num` 字节起的全部内容。
- `-n, --lines <num>` — 打印每个文件的最后 `num` 行；以 `+` 开头时，打印
  从第 `num` 行起的全部内容。
- `-q, --quiet, --silent` — 从不打印 `==> file <==` 标题。
- `-v, --verbose` — 始终打印 `==> file <==` 标题。
- `-z, --zero-terminated` — 行以 NUL 分隔，而不是换行符。
- `-f, --follow[=descriptor]` — 保持文件打开，并在数据追加时输出，按描述
  符跟随。
- `-F` — 按名称跟随（`--follow=name --retry`）：文件轮换时重新打开它。
- `--follow=name` — 跟随名称而非描述符。
- `--retry` — 持续尝试打开尚不可访问的文件。
- `--pid <PID>` — 跟随时，一旦进程 `PID` 结束就停止。
- `--sleep-interval <N>` — 两次 `--pid`/轮换重新检查之间的秒数（允许小数；
  默认 1）。
- `--max-unchanged-stats <N>` — `-F` 为检查轮换而重新检查名称之前的静止周
  期数（默认 5）。
- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `tail log.txt` — 打印 `log.txt` 的最后 10 行。
- `tail -n 3 a b` — 打印 `a` 和 `b` 的最后 3 行，各自在其标题之下。
- `tail -c 1K image` — 打印 `image` 的最后 1024 个字节。
- `tail -n +5 notes` — 从第 5 行起打印 `notes`。
- `tail -f log.txt` — 打印最后 10 行，然后在新行写入时打印它们。
- `tail -F /System/Logs/system` — 跨轮换跟随系统日志。
- `tail -f --pid 1234 out` — 跟随 `out`，直到进程 1234 退出。

## EXIT STATUS

- `0` — 每个文件都已打印（或已写出简短帮助）。
- `1` — 某个文件无法读取，或输出无法送达。无法理解的命令行同样以 `1` 退
  出。

## ENVIRONMENT

- `LANG` — 简短帮助所偏好的区域设置（如 `fr-FR` 这样的 BCP-47 标记）。
