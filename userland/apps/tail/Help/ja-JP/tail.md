## NAME

tail — ファイルの末尾部分を出力する

## SYNOPSIS

`tail [option...] [file...]`

## DESCRIPTION

各 `file` の最後の 10 行を標準出力に表示します。複数の `file` がある場合、
各部分の前に `==> file <==` ヘッダーが付きます。`file` がない場合、または
`file` が `-` の場合は標準入力を読み取ります。

`-n` と `-c` は表示量を変えます。単純な数（または先頭に `-` を付けて書いた
数）は最後の `num` 行またはバイトを表示します。先頭に `+` を付けて書いた数
は、`num` 行目またはバイト目（1 から数える）**から**末尾までのすべてを表示
します。数には乗数の接尾辞を付けられます。`b` (512)、`kB` (1000)、`K`
(1024)、`MB`、`M`、`GB`、`G`、以降 `T`、`P`、`E`、`Z`、`Y`、`R`、`Q` も同様
です（単独の文字は 1024 の累乗を掛け、`B` を付けると 1000 の累乗、`iB` を
付けると 1024 の累乗になります）。

歴史的な先頭引数の形式 `tail -num` / `tail +num`（末尾に任意の `b`/`c`/`l`
の文字を付けられます）も、GNU ツールと同様に受け付けます。

追従モードは各ファイルを開いたままにし、ファイルが伸びるにつれて新しいデー
タを出力します。`-f` は開いたファイルをディスクリプタで追従します。名前の
変更や移動があっても同じファイルを追い続けます。`-F` は*名前*を追従しま
す。ファイルがローテーションされる（名前を変えて退けられ、その場所に新し
いファイルが置かれる）と新しいファイルを開き直し、`--retry` はまだ存在し
ない名前を試し続けます。追従はファイルが実際に変化するまでブロックし、
CPU を空回りさせることはありません。`--pid=PID` はプロセス `PID` が終了し
た時点で追従を終えます。確認は `--sleep-interval`（秒、既定 1）ごとです。
`--max-unchanged-stats=N` は、`-F` がローテーションの有無を名前で再確認す
るまでに経過する静止サイクル数を決めます（既定 5）。切り詰め（ファイルが
縮むこと）は報告され、ファイルは新しい先頭から追従し直されます。

先頭の内容が表示されない場合、標準情報ストリーム（fd 3）に助言レコードが
書き込まれます。これが出力や終了ステータスを変えることはありません。読み
取れないファイルは標準エラーに報告され、実行は次のファイルへ続きます。

端末では、出力に現れる各名前をシェルが必要とする箇所で引用符で囲み、その
中の制御文字やその他の見えない文字をエスケープとして書くため、名前が画面
を操作したり表示を並べ替えたりすることはできません。GNU は名前をそのまま
表示します。パイプやファイルには名前をバイト単位でそのまま渡します。

## OPTIONS

- `-c, --bytes <num>` — 各ファイルの最後の `num` バイトを表示します。先頭
  に `+` を付けると、`num` バイト目以降のすべてを表示します。
- `-n, --lines <num>` — 各ファイルの最後の `num` 行を表示します。先頭に
  `+` を付けると、`num` 行目以降のすべてを表示します。
- `-q, --quiet, --silent` — `==> file <==` ヘッダーを決して表示しません。
- `-v, --verbose` — `==> file <==` ヘッダーを常に表示します。
- `-z, --zero-terminated` — 行は改行ではなく NUL で区切られます。
- `-f, --follow[=descriptor]` — ファイルを開いたままにし、追記されるデー
  タを出力します。追従はディスクリプタで行います。
- `-F` — 名前で追従します（`--follow=name --retry`）。ファイルがローテー
  ションされたら開き直します。
- `--follow=name` — ディスクリプタではなく名前で追従します。
- `--retry` — まだアクセスできないファイルを開こうと試み続けます。
- `--pid <PID>` — 追従中、プロセス `PID` が終了したら停止します。
- `--sleep-interval <N>` — `--pid`/ローテーションを再確認する間隔の秒数
  （小数可、既定 1）。
- `--max-unchanged-stats <N>` — `-F` がローテーションの有無を名前で再確認
  するまでの静止サイクル数（既定 5）。
- `-h, -?` — このコマンド自身の簡単なヘルプを表示します。

## EXAMPLES

- `tail log.txt` — `log.txt` の最後の 10 行を表示します。
- `tail -n 3 a b` — `a` と `b` の最後の 3 行を、それぞれのヘッダーの下に
  表示します。
- `tail -c 1K image` — `image` の最後の 1024 バイトを表示します。
- `tail -n +5 notes` — `notes` を 5 行目から表示します。
- `tail -f log.txt` — 最後の 10 行を表示し、その後は新しい行が書かれるた
  びに表示します。
- `tail -F /System/Logs/system` — ローテーションをまたいでシステムログを
  追従します。
- `tail -f --pid 1234 out` — プロセス 1234 が終了するまで `out` を追従し
  ます。

## EXIT STATUS

- `0` — すべてのファイルを表示した（または簡単なヘルプを書き出した）。
- `1` — ファイルを読み取れなかった、または出力を配信できなかった。理解でき
  なかったコマンドラインも `1` で終了する。

## ENVIRONMENT

- `LANG` — 簡単なヘルプで優先されるロケール（`fr-FR` のような BCP-47 タグ）。
