## NAME

tail — виводити останню частину файлів

## SYNOPSIS

`tail [option...] [file...]`

## DESCRIPTION

Виводить останні 10 рядків кожного `file` до стандартного виводу. За
наявності кількох `file` кожну частину випереджає заголовок
`==> file <==`. Без `file`, або коли `file` дорівнює `-`, читається
стандартний ввід.

`-n` та `-c` змінюють, скільки виводиться: проста кількість (або
записана з `-` на початку) виводить останні `num` рядків або байтів;
кількість, записана з `+` на початку, виводить усе **починаючи** з рядка
чи байта `num` (рахуючи від 1) до кінця. Кількість може мати суфікс
множника: `b` (512), `kB` (1000), `K` (1024), `MB`, `M`, `GB`, `G`, і
так далі для `T`, `P`, `E`, `Z`, `Y`, `R`, `Q` (окрема літера множить на
степені 1024; із `B` на степені 1000; із `iB` на степені 1024).

Історична форма першого аргументу `tail -num` / `tail +num` (з
необовʼязковою кінцевою літерою `b`/`c`/`l`) приймається, як і в
інструменті GNU.

Режим стеження тримає кожен файл відкритим і виводить нові дані в міру
зростання файлу. `-f` стежить за відкритим файлом через дескриптор —
після перейменування чи переміщення стеження триває за тим самим
файлом. `-F` стежить за *іменем*: коли файл ротують (перейменовують геть
і кладуть на його місце новий файл), він повторно відкриває новий файл, а
`--retry` продовжує пробувати ім'я, якого ще немає. Стеження блокується,
доки файл справді не зміниться, — воно ніколи не крутить CPU вхолосту.
`--pid=PID` завершує стеження, щойно процес `PID` завершиться; перевірка
відбувається кожні `--sleep-interval` (секунди, типово 1).
`--max-unchanged-stats=N` визначає, скільки тихих циклів мине, перш ніж
`-F` знову перевірить ім'я на ротацію (типово 5). Про усічення (файл
зменшується) повідомляється, і за файлом знову стежать з його нового
початку.

Коли початковий вміст не показано, до стандартного потоку інформації
(fd 3) записується довідковий запис; він ніколи не змінює вивід чи код
виходу. Файл, який неможливо прочитати, повідомляється в потоці помилок,
і виконання триває з наступним файлом.

У терміналі кожне ім'я у виводі береться в лапки там, де вони потрібні
оболонці, а будь-який керівний чи інший невидимий символ у ньому
записується як екранована послідовність, тож ім'я не може ні керувати
екраном, ні переставляти на ньому текст; GNU показує його без змін.
Канал або файл отримує ім'я байт у байт.

## OPTIONS

- `-c, --bytes <num>` — вивести останні `num` байтів кожного файлу; із
  `+` на початку — усе, починаючи з байта `num`.
- `-n, --lines <num>` — вивести останні `num` рядків кожного файлу; із
  `+` на початку — усе, починаючи з рядка `num`.
- `-q, --quiet, --silent` — ніколи не виводити заголовки `==> file <==`.
- `-v, --verbose` — завжди виводити заголовки `==> file <==`.
- `-z, --zero-terminated` — рядки розділяються NUL замість символу
  нового рядка.
- `-f, --follow[=descriptor]` — тримати файл відкритим і виводити дані в
  міру їх дописування, стежачи за ним через дескриптор.
- `-F` — стежити за іменем (`--follow=name --retry`): повторно
  відкривати файл, коли його ротують.
- `--follow=name` — стежити за іменем, а не за дескриптором.
- `--retry` — продовжувати спроби відкрити ще недоступний файл.
- `--pid <PID>` — під час стеження зупинитися, щойно процес `PID`
  завершиться.
- `--sleep-interval <N>` — секунди між повторними перевірками
  `--pid`/ротації (дробові значення дозволено; типово 1).
- `--max-unchanged-stats <N>` — тихі цикли, перш ніж `-F` знову перевірить
  ім'я на ротацію (типово 5).
- `-h, -?` — показати коротку довідку цієї команди.

## EXAMPLES

- `tail log.txt` — вивести останні 10 рядків `log.txt`.
- `tail -n 3 a b` — вивести останні 3 рядки `a` та `b`, кожен під своїм
  заголовком.
- `tail -c 1K image` — вивести останні 1024 байти `image`.
- `tail -n +5 notes` — вивести `notes` починаючи з 5-го рядка.
- `tail -f log.txt` — вивести останні 10 рядків, а потім нові рядки в
  міру їх запису.
- `tail -F /System/Logs/system` — стежити за системним журналом крізь
  ротації.
- `tail -f --pid 1234 out` — стежити за `out`, доки процес 1234 не
  завершиться.

## EXIT STATUS

- `0` — кожен файл виведено (або записано коротку довідку).
- `1` — файл не вдалося прочитати, або вивід не вдалося доставити.
  Незрозумілий командний рядок теж завершується з `1`.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (мітка BCP-47, наприклад
  `fr-FR`).
