## NAME

blendcheck — 比较显示引擎的混合与桌面自身的混合

## SYNOPSIS

`blendcheck`

## DESCRIPTION

接管屏幕，在整个屏幕宽度上显示一条灰度渐变，并在其上覆盖三块上下排列的
深色玻璃：

1. 由桌面混合，带抖动处理，与桌面绘制半透明窗口的方式相同；
2. 由桌面混合，不带抖动处理，可以看到色带在平滑渐变中留下的台阶；
3. 由显示硬件自身混合。

如果最下面那块看起来与最上面那块相同，说明显示硬件混合半透明效果时不会产
生色带；如果它呈现出中间那块那样的台阶，则并非如此。命令还会打印显示驱动
程序是否声明其混合不产生色带。

按任意键或指针按钮即可交还屏幕。

该命令需要独占显示设备，因此请从文本会话中运行它，而不要从桌面上的终端运
行。没有硬件图层的显示设备没有自身的混合可供比较，命令会对此加以说明。

## OPTIONS

- `-h, -?` — 显示本命令自身的简短帮助。

## EXAMPLES

- `blendcheck` — 显示比较画面，直到按下某个键。

## EXIT STATUS

- `0` — 比较画面已显示并已关闭。
- `1` — 显示设备被某个会话占用、没有硬件图层、拒绝了该图案，或者座席在
  显示期间丢失。无法理解的命令行同样以 `1` 退出。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `fr-FR`）。
