## NAME

blendcheck — ディスプレイエンジンのブレンドをデスクトップ自身のものと比較する

## SYNOPSIS

`blendcheck`

## DESCRIPTION

画面を占有し、その幅いっぱいにグレーのグラデーションを表示して、その上に
暗いガラス板を 3 枚、上から順に並べて重ねます。

1. デスクトップが、半透明のウィンドウを描くときと同じくディザリングを
   施してブレンドしたもの。
2. デスクトップがディザリングなしでブレンドしたもの。滑らかな
   グラデーションにバンディングが残す段差が見えます。
3. ディスプレイハードウェア自体がブレンドしたもの。

一番下のガラス板が一番上のものと同じに見えれば、ディスプレイハードウェア
は半透明をバンディングなしでブレンドします。真ん中のガラス板のような段差
が見えれば、そうではありません。コマンドは、ディスプレイのドライバーが、
自らのブレンドにはバンディングがないと表明しているかどうかも出力します。

任意のキーまたはポインターのボタンを押すと、画面を解放します。

このコマンドはディスプレイを独占する必要があるため、デスクトップ上の端末
ではなく、テキストセッションから実行してください。ハードウェアレイヤーを
持たないディスプレイには比較すべき独自のブレンドがなく、コマンドはその旨
を伝えます。

## OPTIONS

- `-h, -?` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `blendcheck` — キーが押されるまで比較を表示する。

## EXIT STATUS

- `0` — 比較が表示され、閉じられた。
- `1` — ディスプレイをセッションが保持していた、ハードウェアレイヤーを
  持たない、パターンを拒否した、または表示中にシートが失われた。解釈でき
  なかったコマンド行も `1` で終了する。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`fr-FR` のような BCP-47 タグ）。
