## NAME

cp — 复制文件和目录

## SYNOPSIS

`cp [-dfHilLnPrRsvT] [--sparse=WHEN] [--preserve=LIST] [--no-preserve=LIST] [-t dir] [--] source... dest`

## DESCRIPTION

把每个来源操作数复制到目的地。只有一个来源、且目的地不指目录时，来源被复
制到那个确切路径。当目的地指向已存在的目录 — 以及来源多于一个的任何时候
— 每个来源都以其自身的基本名被复制*进*该目录。

目录来源只有带 `-r` 才被复制，它重现整棵子树；没有 `-r` 时目录操作数被拒
绝。已存在的目标文件默认被覆盖，带 `-n` 时被跳过，带 `-i` 时在标准错误流
上询问（被拒绝的询问跳过该次复制并使运行失败，与 GNU 相同；无法读取的回
答绝不被当作同意）。目标若就是来源文件本身——同一个名字、它的另一个名字或
指向它的链接——就作为同一文件被拒绝，并保持原样，只是 `-l` 会把它当作已经
链接好的。`-f` 放到已有名称位置上的链接一步就占据该位置，并且在替换任何
东西之前就已建立，因此无法建立的链接会让该名称原样保留。

无法读取、创建或写入的文件会被报告，其余的仍会被复制，其所在目录的其余部
分也是如此。`--` 结束选项解析：之后的每个参数都是路径。

新文件以来源的权限位创建，去掉 set-ID 位和粘滞位，再减去 umask，因此私有
文件的副本仍是私有的；已存在的目标保留其自身的模式。新目录最终获得来源的
权限位和粘滞位减去 umask 后的模式；在向其中复制条目期间，它对其所有者开
放，因此即使来源目录是只读的，或 umask 不给所有者写权限，也能完整复制。
绝不会经由目标树中遇到的符号链接写入。

GNU 的 `-a`/`--archive`，以及 `--preserve=links,xattr` 之外的
`--preserve` 组合，都会被**拒绝**，而不是被缩小。`-a` 即
`-dR --preserve=all`，而 `--preserve=all` 包括节点的时间戳，本系统没有任
何调用能设置它们——因此遵从 `-a` 会报告一次并未发生的保留。其余部分请使用
`-dR`。

每次复制都会在目标能够保存的地方带上源的扩展属性（RISC OS 文件类型、Mac
的类型和创建者），并将稀疏文件的空洞保留为空洞。目标无法保存的属性会在运
行结束时以一条警告报告，并在标准信息流上以一条 `omission` 记录报告；使用
`--preserve=xattr` 时，这样的复制会改为失败。

目录绝不会被复制到其自身之中：位于源内部的目标——无论如何拼写，经由链
接、`..` 还是卷的另一个名称——都会在写入任何内容之前被拒绝；复制进行期间
被移入源中的目录，会在遍历遇到它时使复制停止。

## OPTIONS

- `-r, -R, --recursive` — 复制目录及其内容。
- `-f, --force` — 目标文件无法创建时，删除它并把复制重试一次；配合
  `-l`、`-s`，或对 `-P` 重现的链接，把链接放到已有名称的位置上。
- `-i, --interactive` — 覆盖已存在的文件前询问；只有以 `y`/`Y` 开头的回
  答才算同意，被拒绝的询问会跳过该文件并使运行失败。
- `-n, --no-clobber` — 从不覆盖已存在的文件。`-i` 与 `-n` 以后者为准。
- `-l, --link` — 给目标一个指向来源节点的第二个名称，而不是复制它的字
  节，这样两个名称不会在此后的写入中分歧。目录来源仍然需要 `-r`。
- `-s, --symbolic-link` — 创建一个指向来源的符号链接，而不是复制它。
- `-P, --no-dereference` — 将源中的每个符号链接重现为原样保存相同目标的
  链接，而不是复制其所指的内容（因此相对链接或悬空链接在复制后依然保
  留）。
- `-L, --dereference` — 跟随源中的每个符号链接，复制其所指的内容。
- `-H` — 跟随作为操作数给出的符号链接，但重现树内遇到的链接。若未给出
  `-H`、`-L` 或 `-P`，递归复制会重现每个链接（包括其操作数的链接），而其
  他复制则跟随其操作数的链接，与 GNU 相同；`-l` 链接被跟随的链接所指的内
  容。
- `--preserve=links` — 命名同一个节点的两个来源在目标处得到两个名称，而
  不是两份副本，因此复制不会悄悄把占用翻倍。
- `--preserve=xattr` — 必须带上每一个扩展属性：如果目标无法保存其中某一
  个，该复制将失败并指出它。`--preserve=links,xattr` 同时要求两者。
- `--no-preserve=xattr` — 不复制任何扩展属性。也接受 `ownership` 和
  `timestamps`，它们本来就不会被保留。
- `--no-preserve=mode` — 以未指定模式时新建对象所取的模式减去 umask 来创
  建每个新文件和目录，而不是采用其来源的模式。`--no-preserve=all` 也会这
  样做。
- `--sparse=WHEN` — 稀疏文件的复制方式：默认的 `auto` 保留其空
  洞；`always` 还会让其存储的每个全零块保持未写入；`never` 写入每一个字
  节。
- `-d` — 等同于 `-P` 与 `--preserve=links` 一起，与 GNU 工具相同。
- `-v, --verbose` — 以 `'source' -> 'dest'` 报告每次复制。
- `-t dir, --target-directory=dir` — 把每个来源复制进 `dir`，它必须是已
  存在的目录。值可紧跟（`-tdir`、`--target-directory=dir`）或作为下一个
  参数。
- `-T, --no-target-directory` — 把目的地当作普通文件；恰好允许一个来源。
  不能与 `-t` 组合。
- `-h, -?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `cp notes.txt backup.txt` — 把一个文件复制为新名字。
- `cp -r Projects Archive` — 在 `Archive` 里重现 `Projects` 树（若不存在
  则复制为 `Archive`）。
- `cp -v -t Backup a.txt b.txt` — 把两个文件都复制进 `Backup`，并报告每
  次复制。

## EXIT STATUS

- `0` — 每次复制都成功（`-n` 的跳过不算失败）。
- `1` — 有文件无法复制、`-i` 询问被拒绝，或询问或输出失败；每个失败的原
  因都打印在标准错误上。无法理解的命令行同样以 `1` 退出。

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
