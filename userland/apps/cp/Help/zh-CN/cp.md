## NAME

cp — 复制文件和目录

## SYNOPSIS

`cp [-dfilnPrRsvT] [--sparse=WHEN] [--preserve=LIST] [--no-preserve=LIST] [-t dir] [--] source... dest`

## DESCRIPTION

把每个来源操作数复制到目的地。只有一个来源、且目的地不指目录时，来源被复
制到那个确切路径。当目的地指向已存在的目录 — 以及来源多于一个的任何时候 —
每个来源都以其自身的基本名被复制*进*该目录。

目录来源只有带 `-r` 才被复制，它重现整棵子树；没有 `-r` 时目录操作数被拒
绝。已存在的目标文件默认被覆盖，带 `-n` 时被跳过，带 `-i` 时在标准错误流
上询问（被拒绝的询问无错误地跳过该次复制；无法读取的回答绝不被当作同
意）。
目标若就是来源文件本身——同一个名字、它的另一个名字或指向它的链接——就作为同一文件被拒绝，并保持原样。

第一个失败会在任何后续操作数之前停止运行。`--` 结束选项解析：之后的每个
参数都是路径。

每次复制都会在目标能够保存的地方带上源的扩展属性(RISC OS 文件类型、
Mac 的类型和创建者),并将稀疏文件的空洞保留为空洞。目标无法保存的属性会在
运行结束时以一条警告报告,并在标准信息流上以一条 `omission` 记录报告;使用
`--preserve=xattr` 时,这样的复制会改为失败。

## OPTIONS

- `-r, -R, --recursive` — 复制目录及其内容。
- `-f, --force` — 目标文件无法创建时，删除它并把复制重试一次。
- `-i, --interactive` — 覆盖已存在的文件前询问；只有以 `y`/`Y` 开头的回答
  才算同意。
- `-n, --no-clobber` — 从不覆盖已存在的文件。`-i` 与 `-n` 以后者为准。
- `-l, --link` — 给目标一个指向来源节点的第二个名称，而不是复制它的字节，
  这样两个名称不会在此后的写入中分歧。目录来源仍然需要 `-r`。
- `-s, --symbolic-link` — 创建一个指向来源的符号链接，而不是复制它。
- `-P, --no-dereference` — 把符号链接来源原样复现为一个存储相同目标的链
  接，而不是复制它所指向的对象（这样相对链接或悬空链接也能在复制后保
  留）。不给此选项时，来源链接会被跟随。
- `--preserve=links` — 命名同一个节点的两个来源在目标处得到两个名称，而
  不是两份副本，因此复制不会悄悄把占用翻倍。
- `--preserve=xattr` — 必须带上每一个扩展属性:如果目标无法保存其中某一个,
  该复制将失败并指出它。`--preserve=links,xattr` 同时要求两者。
- `--no-preserve=xattr` — 不复制任何扩展属性。也接受 `mode`、`ownership`
  和 `timestamps`,它们本来就不会被保留。
- `--sparse=WHEN` — 稀疏文件的复制方式:默认的 `auto` 保留其空洞;`always`
  还会让其存储的每个全零块保持未写入;`never` 写入每一个字节。
- `-d` — 等同于 `-P` 与 `--preserve=links` 一起，与 GNU 工具相同。
- `-v, --verbose` — 以 `'source' -> 'dest'` 报告每次复制。
- `-t dir, --target-directory=dir` — 把每个来源复制进 `dir`，它必须是已存
  在的目录。值可紧跟（`-tdir`、`--target-directory=dir`）或作为下一个参
  数。
- `-T, --no-target-directory` — 把目的地当作普通文件；恰好允许一个来源。
  不能与 `-t` 组合。
- `-h, -?, --help` — 显示本命令自身的简短帮助。

## EXAMPLES

- `cp notes.txt backup.txt` — 把一个文件复制为新名字。
- `cp -r Projects Archive` — 在 `Archive` 里重现 `Projects` 树（若
  `Archive` 不存在则复制为 `Archive`）。
- `cp -v -t Backup a.txt b.txt` — 把两个文件都复制进 `Backup`，并报告每次
  复制。

## EXIT STATUS

- `0` — 每次复制都成功（`-n` 的跳过和被拒绝的 `-i` 询问不算失败）。
- `1` — 文件系统、询问或输出失败；原因打印在标准错误上。
- `2` — 无法理解命令行。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，例如 `zh-CN`）。
