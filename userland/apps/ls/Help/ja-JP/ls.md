## NAME

ls — ディレクトリの内容を一覧する

## SYNOPSIS

`ls [-aABbCcdFfGghikIlmNnopQqrRsSTtUuvXx1] [-w cols] [-I PATTERN]`
`[--block-size=SIZE] [--si] [--format=WORD] [--indicator-style=WORD]`
`[--hide=PATTERN] [--time=WORD] [--time-style=STYLE] [--sort=WORD]`
`[--quoting-style=STYLE] [--full-time] [--author] [--file-type]`
`[--group-directories-first] [--zero] [--color[=WHEN]] [--] [path...]`

## DESCRIPTION

各パスオペランドを一覧します。ディレクトリオペランドはその項目が読まれ
て一覧され（`-d` がディレクトリ自体を指す場合を除く）、それ以外のオペラ
ンドはそれ自体として一覧されます。オペランドがなければ現在のディレクト
リ（`.`）が一覧されます。

項目は名前順に並びます（`-S` ならサイズの大きい順、`-t` ならタイムスタンプの
新しい順、`-X` なら拡張子順、`-v` なら自然な「バージョン」順、`-U` なら並べ替
えなし——ディレクトリの順序——、`--sort` なら名前で選んだ基準、`-r` なら逆順）。
`--group-directories-first` はディレクトリを並びの先頭に浮かせます。出力が端末
のときは端末の幅に合わせた列に、上から下へ埋めて配置されます（`-C`）。端末でな
いとき（パイプやファイル）は一行に一つの名前で一覧されます。`-x` は代わりに列を
左から右へ埋め、`-m` はコンマ区切りで一覧し、`-1` は一行に一つを強制し、`-w` は
幅を明示的に設定します。名前が `.` で始まる項目は、`-a` か `-A` が与えられない
限り隠されます。項目が隠されたときは、標準情報ストリーム（fd 3）に注記が出ます。
一覧そのものには決して混ざりません。

長い形式（`-l`）は、種別と許可ビット、所有者とグループ、サイズ、タイムスタンプ、
そして名前を描きます。所有者とグループは数値の id です。アカウント名の解決には
権能で守られたユーザーデータベースが必要で、一覧がそれを要求してはならないため、
出力は GNU ツールの数値フォールバックに一致します（`-n` は同一の描画になります）。
タイムスタンプは既定で更新時刻です。`-c`・`-u`・`--time` は四つのうちどの
タイムスタンプを表示（および並べ替え）に使うかを選び、`--time-style`（または
`--full-time`）がその書式を決めます。リンク数の列は、そのファイルを名指すディレ
クトリエントリの数を、ファイルシステム自身が記録しているとおりに示します。数を
保持しない形式は `1` と答えます。

シンボリックリンクは型文字 `l` で表示され、長形式では `name -> target` として
現れる。ターゲットは保存されたそのままで、解決されていない——それがリンクの内容
である。したがって宙ぶらりんのリンクも普通に一覧される。到達できないと報告する
のは、それを解決する姿勢（`-L`、またはオペランドに対する `-H`）だけである。

名前は、扱いにくい文字が見えるように、またシェルに貼り戻しても
安全なように引用されます。端末での既定は `shell-escape`（空白や
メタ文字を含む名前は引用され、制御文字は `$'…'` のエスケープとして
示されます）、それ以外では `literal`（名前をそのまま）です。`-N`、
`-Q`、`-b`、`--quoting-style` がスタイルを選び、`-q` は制御文字を
`?` として示します。`-F` と `--file-type` の下では、`*`、`=`、`>`、
`@`、`|` のいずれかを含む名前は、シェル系のスタイルでは引用され、
`-Q` と `-b` ではその文字がエスケープされるため、種別記号と
見誤られることはありません。GNU の `-F` は `*` に印を付けないので、
そこではその文字で終わる名前が実行可能ファイルのように見えます。

色対応の端末では、名前は種類ごとに色付けされます——ディレクトリ、実行可能ファイ
ル、通常ファイルがそれぞれ標準配色の役割で——。これは `--color` で制御されます。
色は表示上のものにすぎません。端末への描画にだけ加えられ、パイプやリダイレクト
された出力には決して加えられません。エスケープシーケンスを除けば出力は素の一覧と
バイト単位で同一なので、色が列や並び順、スクリプトから見える内容を変えることは
決してありません。

オペランドが複数与えられたとき — そして `-R` の下では常に — 各ディレクト
リの一覧の前に `path:` の見出しが付き、ブロックは空行で区切られます。見
出しのパスは一覧と同じ形式で引用され、その中の `:` も引用されます。

## OPTIONS

- `-t` — 表示されるタイムスタンプ順に、新しいものから並べる。
- `-c` — メタデータ変更時刻（ctime）を使う。`-l` では表示し、`-t` ではそれで
  並べ替える。`-l` がなければそれで並べ替える。
- `-u` — `-c` と同様だが、アクセス時刻（atime）。
- `-i, --inode` — 各項目のノード番号を印字する。
- `-B, --ignore-backups` — 名前が `~` で終わる項目を、すべてのモードで
  表示しない（バックアップは `-a` でも隠される）。
- `-I, --ignore=PATTERN` — シェルグロブ `PATTERN` に一致する項目を表示
  しない（繰り返し可）。すべてのモードで適用される。先頭の `.` に一致する
  のはパターン中の `.` だけで、ワイルドカードは決して一致しない。
- `--hide=PATTERN` — `--ignore` と同様だが、`-a` または `-A` が指定
  された場合は効果がない。
- `--time=WORD` — どのタイムスタンプを表示・並べ替えに使うか。`atime`
  （`access`、`use`）、`ctime`（`status`）、`mtime`（`modification`）、
  または `birth`（`creation`）。
- `--time-style=STYLE` — タイムスタンプの書式。`locale`（既定）、
  `long-iso`、`full-iso`、`iso`。独自の `+FORMAT` は非対応。
- `--full-time` — `-l --time-style=full-iso` と同じ。
- `-a, --all` — 名前が `.` で始まる項目を隠さない。
- `-A, --almost-all` — `-a` と同様だが、`.` と `..` は決して一覧しない。
- `-d, --directory` — ディレクトリオペランド自体を一覧し、その中身は一
  覧しない。
- `-F, --classify` — ディレクトリに `/`、実行可能ファイルに `*` を付け
  る。
- `-g` — 所有者の列を省いた長い形式。`-l` を含意する。
- `-h, --human-readable` — サイズを `1.1K`、`23M` のように印字する（1024 の
  累乗）。長い形式のファイルサイズと `-s` のブロックの両方に適用される。
- `-l` — 長い形式。許可ビット、所有者、グループ、サイズ、そして名前。
- `-m` — コンマ区切りの名前を出力幅で折り返す。
- `-n, --numeric-uid-gid` — 所有者とグループを数値にした長い形式。`-l`
  を含意する。ここでは所有者とグループは常に数値なので（上記参照）、
  `-l` と一致する。
- `-o` — グループの列を省いた長い形式。`-l` を含意する。
- `-p` — ディレクトリに `/` を付ける。
- `-N, --literal` — 名前を引用せずにそのまま表示する
  （`--quoting-style=literal`）。
- `-Q, --quote-name` — Cスタイルの引用：各名前を二重引用符で囲み、
  引用符・バックスラッシュ・制御文字をエスケープする
  （`--quoting-style=c`）。
- `-b, --escape` — `-Q` と同様だが囲みの引用符を付けず、空白を
  エスケープする（`--quoting-style=escape`）。
- `--quoting-style=WORD` — 名前の引用方法：`literal`（`-N`）、
  `shell`、`shell-always`、`shell-escape`、`shell-escape-always`、
  `c`（`-Q`）、または `escape`（`-b`）。既定は端末では
  `shell-escape`、それ以外では `literal`。`locale` と `clocale`
  のスタイルは非対応。
- `-q, --hide-control-chars` — 非表示文字を `?` として表示する
  （端末での既定）。エスケープしないスタイルにのみ影響する。
- `--show-control-chars` — 非表示文字をそのまま表示する
  （出力が端末でないときの既定）。
- `-r, --reverse` — 並び順を逆にする。
- `-R, --recursive` — サブディレクトリを再帰的に一覧する。
- `-L, --dereference` — シンボリックリンクがどこに現れても、リンク自身ではなく
  それが指すファイルの情報を表示する。ターゲットに到達できないリンクは標準
  エラーに報告され、一覧は続き、終了状態は非ゼロになる。
- `-H, --dereference-command-line` — コマンド行で指定されたシンボリックリンク
  だけをたどる。一覧の内側のリンクはリンクとして表示される。`-L` と `-H` は
  後に指定した方が効く。
- `--dereference-command-line-symlink-to-dir` — 書式オプションが別を強制しない
  ときの既定。コマンド行の*ディレクトリを指す*リンクはたどられるので
  `ls linkdir` はそのディレクトリを一覧し、それ以外のリンクは自身を表示する。
  `-l`、`-d`、`-F` は逆に、既定でどのリンクも自身を表示する。
- `-s, --size` — 各項目の割り当てサイズをブロック単位で印字し（`-h` / `--si` /
  `--block-size` / `-k` で換算）、ディレクトリ一覧ごとに `total` の行を付ける。
- `-C` — 列で一覧表示し、上から下へ埋める（出力が端末のときの既定）。
- `-S` — サイズ順、大きいものから。
- `-U` — 並べ替えず、ディレクトリの順序で一覧します。
- `-X` — 拡張子（最後の `.` 以降）で並べ替えます。同じ場合は
  名前順。
- `-v` — 自然な「バージョン」順で並べ替え、`f2` は `f10` より
  前になります。同じ場合は名前順。
- `-f` — 並べ替えずすべての項目を表示します。`-a` と `-U` を
  有効にし、`-l` と `-s` を無効にします。指定位置で適用される
  ため、後続の `-l`/`-s`/並べ替えフラグが優先されます。
- `--sort=WORD` — 並べ替えの基準を名前で選びます: `none`（`-U`）、
  `size`（`-S`）、`time`（`-t`）、`version`（`-v`）、
  `extension`（`-X`）、`name`。
- `--group-directories-first` — 他の項目の前にディレクトリを一覧
  します。`-r` を付けてもディレクトリが先になります。
- `-w, --width <cols>` — 出力幅を桁数で指定する。`0` は行の長さを無制限に
  する。指定しなければ端末の幅を使い、それが決められないときは 80。
- `-x` — 列で一覧表示し、左から右へ埋める。
- `-1` — 一行に一つの名前（出力が端末でないときの既定）。
- `-?` — このコマンド自身の短いヘルプを表示する（長い形は `--help`）。
- `--file-type` — ディレクトリに `/` を付けるが、実行可能ファイルに
  `*` は付けない（`--indicator-style=file-type`）。
- `--indicator-style=WORD` — 種別記号を名前で選ぶ：`none`、`slash`
  （`-p`）、`file-type`（`--file-type`）、`classify`（`-F`）。
- `-G, --no-group` — 長形式でグループ列を省く。`-o` と違い、それ
  自体では長形式を選ばない。
- `--author` — `-l` とともに、所有者の後・グループの前に作成者
  列（所有ユーザー。別個の作成者はないため）を表示する。
- `--si` — `-h` と同様だが 1000 のべき乗（`1.1k`、`23M`）。
- `-k, --kibibytes` — `-s` のセルと `total` に 1024 バイトブロックを使う。
  これはすでに既定なので、出力を変えるのではなく確認するだけになる。サイズ
  指定が優先される。
- `--block-size=SIZE` — 長い形式のファイルサイズと `-s` ブロックを SIZE で
  換算する：素の整数（バイト）、単位 `K`/`M`/`G`/`T`/`P`/`E`（1024 基準）、
  `KiB` 系の単位（1024 基準）、または `KB` 系の単位（1000 基準）で、任意で
  先頭に整数の係数を付けられる。単位だけならその接尾辞を印字し、係数を付ける
  と接尾辞は付かない。不正な SIZE はエラーになる。
- `--format=WORD` — 並べ方を名前で選ぶ：`long`（`-l`）／`verbose`、
  `single-column`（`-1`）、`vertical`（`-C`）、`across`／`horizontal`
  （`-x`）、`commas`（`-m`）。
- `-T, --tabsize <cols>` — 桁揃えのタブ幅を設定する（既定 8）。`0`
  は空白のみで埋める。
- `--zero` — 各行を改行ではなく NUL で終える。さらに、上書きされない限り、
  単一列・そのままの引用・制御文字の表示を選ぶ。

- `--color[=WHEN]` — 名前を種類ごとに色付けする（ディレクトリ、
  実行可能ファイル、通常ファイル）。`WHEN` は `auto`（既定:
  出力が確認済みの端末のときのみ色付け）、`always`（そうで
  なくても色付け、例: シリアルコンソール）、`never` のいずれか。
  `WHEN` を省いた `--color` は `always` を意味する。パイプや
  リダイレクトされた出力は決して色付けされない。

## EXAMPLES

- `ls` — 現在のディレクトリを一覧する。
- `ls -al /System` — 隠し項目も含めた `/System` の長い形式の一覧。
- `ls -lhS` — 長い形式、読みやすいサイズ、大きいものから。
- `ls -v` — 自然順に並べ、`f2` が `f10` より前に来る。
- `ls --group-directories-first` — ディレクトリを先に、次にファイル。
- `ls -R Documents` — `Documents` を再帰的にたどり、ディレクトリごとに
  見出しを付ける。
- `ls -F` — ディレクトリを `/`、実行可能ファイルを `*` で標す。
- `ls -d Documents` — `Documents` の項目自体を一覧し、その中身は一覧し
  ない。

## EXIT STATUS

- `0` — すべてのオペランドを一覧した。
- `1` — 軽微な問題：一覧の内側の項目またはサブディレクトリを
  調べられなかった、または読めなかった。
- `2` — 深刻な問題：コマンド行を解釈できなかった、オペランドを
  調べられなかったか読めなかった、`-R` がリンクを通じて再び
  ディレクトリに到達した、メモリが尽きた、または出力を届けられなかった。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。

- `TERM` — 端末の種類。`--color` 出力の色数を決める。未設定
  または色なしの `TERM` では `auto` は素のテキストを出力する。
