## NAME

TAIRiXBridge — TAIRiX Bridge, TAIRiX 데스크톱에서 실행되는 RISC OS 프로그램

## SYNOPSIS

`TAIRiXBridge`

## DESCRIPTION

RISC OS 프로그램(BASIC 프로그램, 명령줄 도구, 단일 작업 게임)을 TAIRiX 데스크톱
에서 실행하며, 각 프로그램의 화면을 저마다의 창에 보여 줍니다. 프로그램이 실행되
는 RISC OS는 공개된 문서를 바탕으로 작성된 TAIRiX Bridge 자체의 것이며, RISC OS
코드는 들어 있지 않습니다.

프로그램은 세션 안에서 실행됩니다. 공유 세션은 TAIRiX Bridge 창이 보여 주는 RISC
OS 기기입니다. 그 고유 디스크는 문서 안의 RISC OS 폴더이고, 시작할 때 부트 시퀀스
가 실행되며, 사용자 자신의 저장소에 있는 프로그램은 여기에서 실행됩니다. 다른 곳
(이동식 매체, 디스크 이미지, 네트워크 공유)에서 왔거나 출처를 알 수 없는 프로그
램은 저마다의 격리된 세션에서 실행됩니다. 격리된 세션은 사용자의 RISC OS 폴더를
결코 보지 못하며 마지막 프로그램과 함께 끝납니다. "공유 세션에서 실행"은 출처와
관계없이 파일을 공유 세션에서 실행합니다.

세션 창에는 작업 목록(각 작업의 메모리와 일시 중지 또는 처리 중 여부)과 세션의 공유 영역이 차
지하는 양이 표시됩니다. "실행"으로 실행할 파일을 고릅니다. 창에 끌어다 놓은 파일
이나 TAIRiX Bridge로 연 파일도 실행됩니다. 작업을 고른 뒤 "일시 중지"나 "종료"를
누르면 그 작업을 멈추거나 끝냅니다.

각 프로그램의 화면은 저마다의 창이며, 그림은 해당 모드 본래의 비율로 창에 맞게
확대·축소됩니다. "화면" 단추는 창의 메뉴를 엽니다. 전체 화면, 선명하게 또는 부드
럽게 확대·축소, 일시 중지, 그리고 프로그램을 끝내고 같은 창에서 다시 실행하는 "재
설정"이 있습니다. 화면은 키보드 전체를 받으며, 각 키는 RISC OS가 매긴 번호로 전달
됩니다. Select, Menu, Adjust는 각각 기본 단추, 보조 단추, 가운데 단추입니다. 프로
그램이 스스로 마우스를 움직이기 시작하면 클릭 한 번으로 마우스가 그 프로그램에 붙
잡히고, Meta 키를 한 번만 가볍게 누르면 풀려납니다.

"설정"에서는 단추의 순서, 각 세션이 쓸 수 있는 메모리, 모든 프로그램을 격리할지
여부, 화면을 확대·축소하는 방식을 고릅니다. 세션의 작업 프로세스는 아무런 권한도
갖지 않습니다. 읽고 쓰는 파일은 대신 전달되며, 실패한 작업 프로세스는 그 세션을 끝
내고 그 이유는 세션 창에 표시됩니다.

## OPTIONS

`-h`, `-?`, `--help`
: 이 도움말을 표준 출력에 쓰고 끝냅니다.

## EXIT STATUS

마지막 세션의 창이 닫히면 0입니다. 창 채널, 이벤트 우편함, 데스크톱 세션 가운데
하나가 거부되면 0이 아니며, 그 이유는 표준 오류 스트림에 나타납니다.
