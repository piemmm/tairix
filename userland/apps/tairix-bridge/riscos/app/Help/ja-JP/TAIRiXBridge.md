## NAME

TAIRiXBridge — TAIRiX Bridge、TAIRiX デスクトップで動く RISC OS のプログラム

## SYNOPSIS

`TAIRiXBridge`

## DESCRIPTION

RISC OS のプログラム（BASIC プログラム、コマンドラインのツール、シングルタスクの
ゲーム）を TAIRiX デスクトップで実行し、それぞれの画面を専用のウィンドウに表示し
ます。プログラムが動く RISC OS は TAIRiX Bridge 独自のもので、公開された資料をも
とに書かれており、RISC OS のコードは含まれていません。

プログラムはセッションの中で動きます。共有セッションは TAIRiX Bridge ウィンドウ
が示す RISC OS マシンです。その専用ディスクは書類の中の RISC OS フォルダーで、起
動時にブートシーケンスが実行され、あなた自身のストレージにあるプログラムはここで
動きます。それ以外の場所（リムーバブルメディア、ディスクイメージ、ネットワーク共
有）から来たプログラムや、出どころの分からないプログラムは、専用の隔離セッション
で動きます。隔離セッションはあなたの RISC OS フォルダーを決して見ず、最後のプロ
グラムとともに終わります。「共有セッションで実行」は、出どころにかかわらずファイ
ルを共有セッションで実行します。

セッションのウィンドウには、タスクの一覧（それぞれのメモリーと、一時停止中か処
理中か）と、セッションの共有領域が使っている量が表示されます。「実行」で実行するファ
イルを選びます。ウィンドウにドロップしたファイルや TAIRiX Bridge で開いたファイ
ルも実行されます。タスクを選んで「一時停止」または「終了」を選ぶと、そのタスクを
止めるか終わらせます。

各プログラムの画面は専用のウィンドウで、画像はそのモード本来の縦横比でウィンド
ウに合わせて拡大縮小されます。「画面」ボタンはウィンドウのメニューを開きます。
フルスクリーン、シャープまたはスムーズな拡大縮小、一時停止、そしてプログラムを終
えて同じウィンドウで再び実行する「リセット」があります。画面はキーボード全体を受
け取り、各キーは RISC OS が付けた番号で届きます。Select、Menu、Adjust はそれぞれ
主ボタン、副ボタン、中ボタンです。プログラムが自分でマウスを動かすようになると、
クリックでマウスがそのプログラムに捕捉され、Meta キーを単独で軽く押すと解放され
ます。

「設定」では、ボタンの順序、各セッションが使えるメモリー、すべてのプログラムを
隔離するかどうか、画面の拡大縮小の方法を選びます。セッションのワーカーは何の権
限も持ちません。読み書きするファイルは代わりに受け渡され、失敗したワーカーはその
セッションを終わらせ、理由はセッションのウィンドウに表示されます。

## OPTIONS

`-h`, `-?`, `--help`
: このヘルプを標準出力に書き出して終了します。

## EXIT STATUS

最後のセッションのウィンドウが閉じられると 0 です。ウィンドウチャネル、イベント
メールボックス、デスクトップセッションのいずれかが拒否された場合は 0 以外で、その
理由は標準エラー出力に示されます。
