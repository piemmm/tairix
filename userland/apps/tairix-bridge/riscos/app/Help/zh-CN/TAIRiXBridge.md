## NAME

TAIRiXBridge — TAIRiX Bridge，在 TAIRiX 桌面上运行的 RISC OS 程序

## SYNOPSIS

`TAIRiXBridge`

## DESCRIPTION

在 TAIRiX 桌面上运行 RISC OS 程序——BASIC 程序、命令行工具和单任务游戏——每个程
序都在自己的窗口中显示其屏幕。它们所运行的 RISC OS 是 TAIRiX Bridge 自己的，依据
公开的文档编写，不含任何 RISC OS 代码。

程序在会话中运行。共享会话就是 TAIRiX Bridge 窗口所显示的那台 RISC OS 机器：它自
己的磁盘是“文稿”中的 RISC OS 文件夹，启动时会运行它的引导序列，来自您自己存储设
备的程序就在其中运行。来自其他地方（可移动介质、磁盘映像、网络共享）或来历不明的
程序，则在属于它自己的隔离会话中运行；隔离会话永远看不到您的 RISC OS 文件夹，并随
其最后一个程序结束。“在共享会话中运行”会把文件放在共享会话中运行，无论它来自何处。

会话窗口列出它的任务——每个任务的内存以及是否已暂停或正忙——以及会话共享区域的占用情况。
“运行”用来选择要运行的文件；拖放到窗口上的文件，或用 TAIRiX Bridge 打开的文件，
也会被运行。选中一个任务后选择“暂停”或“退出”，即可让它暂停或结束。

每个程序的屏幕都是一个独立的窗口，其画面按该模式本身的比例缩放以适应窗口。“屏幕”
按钮会打开窗口的菜单：全屏、清晰或平滑缩放、暂停，以及“重置”——结束程序并在同一窗
口中再次运行它。屏幕会接管整个键盘，每个按键都以 RISC OS 给它的编号送达。Select、
Menu 和 Adjust 分别是主按钮、副按钮和中键。一旦程序自己移动鼠标，单击一次就会为它
捕获鼠标，单独轻按一下 Meta 键即可释放。

“设置”用来选择按钮的顺序、每个会话可使用的内存、是否隔离每个程序，以及屏幕的缩放
方式。会话的工作进程不持有任何权限：它读写的文件由他人代为传递，失败的工作进程会结
束其会话，原因显示在会话窗口中。

## OPTIONS

`-h`, `-?`, `--help`
: 将本帮助写到标准输出并退出。

## EXIT STATUS

关闭最后一个会话的窗口后为零。当窗口通道、事件邮箱或桌面会话被拒绝时为非零，原因
会在标准错误流中说明。
