# BASIC's language: each program run by genuine RISC OS 5's BASIC V and
# BASIC VI and what it printed recorded, which the replay holds the
# interpreter to. A program opens `program NAME`; its lines follow; `input
# "TEXT"` gives what the keyboard types for it, `\xHH` for any byte. A
# program prints only its own text and numbers: an error is caught and its
# number printed, never its message, which is the ROM's. Each runs with its
# output redirected to a HostFS file, so what follows an error that reaches
# the error handler through the OS is not recorded; a file a program makes
# is named `Lang...` and deleted by it.
