# The VDU drivers' screens: each case run by genuine RISC OS 5's BASIC V on
# the screen, and what it read and drew recorded, which the replay holds the
# drivers to. A case opens `case NAME`; its lines follow, numbered 10 to
# 8999. The frame (`tairix_riscos_vdu::corpus::program`) defines every
# character from 32 to 255 as the first-party font draws it, gives the case
# `PROCmode`, `PROCscreen`, `PROCr`, `FNm`, `FNv` and `FNs`, and saves the
# screen at the end. A case that defines characters of its own defines the
# font again before it ends, since the frame refuses a screen whose
# characters no longer match the font. The cases run one after another in
# one session, as the replay runs them, so what a case leaves that a mode
# change does not reset is the next case's to find.
