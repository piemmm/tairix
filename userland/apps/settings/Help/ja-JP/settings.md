## NAME

settings — デスクトップとこのマシンを設定する

## SYNOPSIS

`settings`

## DESCRIPTION

このシステムが持つ設定のカテゴリーをすべて並べたデスクトップウィンドウを開きま
す。マシンの素性、デスクトップの見た目、画面、ネットワーク、操作に使う装置、利用
しているアカウント、保持しているボリュームです。サイドバーでカテゴリーを選ぶと、
そのペインが表示されます。複数のペインを持つカテゴリーは、代わりにその一覧をその
場で開閉します。開いておける一覧の数に制限はありません。

Settings 自身は何の権限も持ちません。変更はいずれも、利用者自身の設定を所有する
デスクトップセッションへの要求か、その保存先をすでに書き込んでいるコマンドを再認
証して実行するかのどちらかです。ここから権限を昇格させる手立てはありません。

このシステムが担えないカテゴリーは、そのことをはっきり述べ、担うために何が必要か
を挙げます。何も変えない操作部は決して表示しません。

サイドバー上部の検索欄に入力すると、語が届くカテゴリーと設定に絞り込まれます。
`Tab` と `Shift+Tab` は検索欄、位置の履歴、サイドバー、ペインの間で移動し、`Up`
と `Down` はサイドバーをたどり、`Enter` はその行を開きます。`Right` と `Left`
は、カーソルのあるカテゴリーの一覧を開閉します。幅が足りないウィンドウはサイド
バーを落とし、そのとき位置の履歴の先頭がカテゴリーを一覧します。

デスクトップのシステムメニューの *Settings…* 行から、プログラムライブラリから、
またはシェルから名前で起動します。動作中のグラフィカルセッションが必要です。それ
がなければウィンドウチャネルに到達できず、標準エラー出力に拒否の理由を述べて終了
します。

サウンドには 2 つのペインがあります。*Output & Input* では音を鳴らすデバイスと
録音するデバイスを選び、そのデバイスの音量とミュートを設定します。ミュートする
と解除するまで音量はゼロになり、解除すると元の音量に戻ります。録音中のものも示
し、自分の録音は名前で、他の人の録音は件数で示します。設定はすぐにデバイスへ反
映され、それはあなたのセッションがそのデバイスの受け持つルームを持っている間に
限られます。別のセッションのルームにあるデバイスは表示されますが、ここでは変更
できません。設定した内容はデスクトップが覚えています。*Sound Effects* ではデス
クトップ自身のサウンドのオンとオフ、テーマ、音量を設定し、通知、エラー、端末の
ベルといった各イベントで、テーマのサウンド、自分で選んだファイル、無音のどれを
鳴らすかを選びます。起動、サインイン、サインアウトのサウンドはこのマシンのもの
で、管理者が設定します。

## EXIT STATUS

正常に閉じたときは 0。ウィンドウチャネルまたは共有フレーム領域が拒否されたときは
非 0（理由は標準エラー出力に示されます）。
