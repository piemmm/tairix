## NAME

settings — 配置桌面与本机

## SYNOPSIS

`settings`

## DESCRIPTION

打开一个桌面窗口，列出本系统的每一类设置：这台机器是什么、桌面外观、屏幕、网络、
用于操作它的设备、使用它的账户，以及它所持有的卷。在侧栏中选择一个类别即显示其
面板。包含多个面板的类别则会就地展开或收起其面板列表，而且可以同时展开任意多个这
样的列表。

Settings 自身不持有任何权限。每一次更改要么是向拥有用户自身设置的桌面会话发出的
请求，要么是对已经写入该存储的命令进行重新认证后的运行；这里没有任何东西可以提升
权限。

本系统无法提供的类别会明确说明这一点，并指出需要具备什么才能提供。绝不显示不会改
变任何东西的控件。

在侧栏上方的搜索框中输入文字，即可把侧栏筛选为某个词所能到达的类别与设置。`Tab`
与 `Shift+Tab` 在搜索框、位置路径、侧栏与面板之间移动焦点；`Up` 与 `Down` 遍历
侧栏，`Enter` 打开该行。`Right` 与 `Left` 展开或收起光标所在类别的列表。窗口过窄
时会舍弃侧栏，此时位置路径的首项会列出各类别。

它可从桌面系统菜单的 *Settings…* 一行启动，可从程序库启动，也可在 shell 中按名称
启动。它需要正在运行的图形会话：没有会话时窗口通道不可达，程序会在标准错误流上报
告拒绝原因并退出。

声音显示每个输出和输入的默认选择、音量和静音，以及正在录音的内容：你自己的录
音按名称列出，其他人的录音则显示数量。其控制会立即更改设备，且仅在你的会话持
有该设备所服务的房间时才可更改；属于其他会话房间的设备会显示出来，但不能在此
更改。你的桌面会记住你的设置。

## EXIT STATUS

正常关闭后为零；当窗口通道或共享帧区域被拒绝时为非零（原因在标准错误流上说明）。
