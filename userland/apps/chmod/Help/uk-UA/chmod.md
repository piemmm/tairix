## NAME

chmod — змінити біти режиму файлу

## SYNOPSIS

`chmod [-cfRv] [--] MODE file...`

## DESCRIPTION

Змінює біти доступу кожного файлового операнда на `MODE`, по черзі.
`MODE` — це або абсолютне вісімкове значення (`644`, `0755`, …), яке
повністю замінює біти доступу, або розділений комами список символьних
виразів `[ugoa]*([-+=]([rwxXst]*|[ugo]))+` чи `[-+=][0-7]+` (`g+w`,
`o-rx`, `a=rx`, `u+s`, `g=u`, `=644`), які перетворюють поточні біти
файлу. Символьний `X` надає виконання лише каталогу або файлу, що вже
має біт виконання, `g=u` дає групі біти власника, `s` встановлює біти
set-ID власника та групи, а `t` встановлює біт sticky. Вираз, який
нікого не називає (`+x`, `=r`), змінює кожне поле, крім бітів, які
містить umask.

Для каталогу біти set-user-ID і set-group-ID лишаються такими, як є,
якщо режим їх не називає: літерою `s` (`g-s`), вісімковими цифрами після
оператора (`=755`) або вісімковим значенням із п'яти чи більше цифр
(`00755`). Саме біт set-group-ID каталогу дає новим елементам у ньому
групу каталогу, тож `chmod 755` його зберігає.

Лише власник файлу може змінити його режим; ядро відмовляє будь-кому
іншому, а володіння capability не дає жодних привілеїв. Для
символьного посилання, названого операндом, змінюється файл, який
воно називає. З `-R` каталог-операнд змінюється, а потім рекурсивно
змінюється його вміст; символьне посилання, що трапляється всередині
дерева, лишається недоторканим, як і те, що воно називає. Про
недосяжний файл або файл, який не вдається змінити, повідомляється,
а решта однаково змінюється. `--` завершує розбір параметрів: кожен
наступний аргумент є операндом. Режим, що починається з `-`, пишіть
без дефіса (`a-w`) або спершу завершіть
параметри (`chmod -- -w file`).

## OPTIONS

- `-R, --recursive` — змінювати файли й каталоги рекурсивно.
- `-c, --changes` — повідомляти лише про файли, режим яких справді
  змінився.
- `-v, --verbose` — повідомляти про кожен опрацьований файл, зокрема
  про той, зміну якого відхилено або який виявився недосяжним.
- `-f, --silent, --quiet` — не виводити більшість повідомлень про
  помилки; виконання все одно завершується невдачею, і код виходу це
  показує.
- `--preserve-root` — з `-R` відмовлятися змінювати `/`, хоч як до нього
  дійдено.
- `--no-preserve-root` — поводитися з `/` як з будь-яким іншим каталогом
  (типово).
- `-h, -?, --help` — показати коротку довідку цієї команди.

## EXAMPLES

- `chmod 644 notes.txt` — читання/запис для власника, лише читання
  для решти.
- `chmod g+w shared.txt` — додати запис для групи до поточних
  бітів.
- `chmod -R a=rx Docs` — зробити дерево `Docs` доступним для
  читання й проходу всім.
- `chmod +x build.sh` — зробити скрипт виконуваним для всіх, кому це
  дозволяє umask.

## EXIT STATUS

- `0` — кожна зміна режиму вдалася.
- `1` — файл виявився недосяжним або його не вдалося змінити, або
  вивід не вдався; кожну причину надруковано в потік помилок
  (приховано з `-f`). Незрозумілий командний рядок або рядок, чий
  операнд режиму не був ані вісімковим, ані символьним, теж
  завершується з `1`.

## ENVIRONMENT

- `LANG` — бажана локаль для короткої довідки (тег BCP-47, як-от
  `uk-UA`).
