## NAME

chmod — 更改文件模式位

## SYNOPSIS

`chmod [-cfRv] [--] MODE file...`

## DESCRIPTION

按顺序把每个文件操作数的权限位改为 `MODE`。`MODE` 要么是一个整体替换权限
位的绝对八进制值（`644`、`0755` 等），要么是一个以逗号分隔的符号子句列表
`[ugoa]*([-+=]([rwxXst]*|[ugo]))+` 或
`[-+=][0-7]+`（`g+w`、`o-rx`、`a=rx`、`u+s`、`g=u`、`=644`），用来变换文
件当前的权限位。符号 `X` 只对目录、或已带有执行位的文件授予执行权
限，`g=u` 把所有者的权限位赋给组，`s` 设置所有者和组的 set-ID 位，`t` 设
置粘滞位。不指定任何对象的子句（`+x`、`=r`）会更改所有字段，但 umask 所
含的位除外。

对于目录，set-user-ID 和 set-group-ID 位保持不变，除非模式指明了它们：使
用 `s`（`g-s`）、在运算符之后使用八进制数（`=755`），或使用五位或更多位
的八进制值（`00755`）。正是目录的 set-group-ID 位让其中的新条目获得该目
录的组，因此 `chmod 755` 会保留该位。

只有文件的所有者才能更改其模式；内核会拒绝其他任何人，持有
capability 也不能越权。作为操作数给出的符号链接，更改的是它所指向
的文件。加 `-R` 时，先更改目录操作数，然后递归更改其内容；在树中遇
到的符号链接保持不变，它所指向的对象也保持不变。无法到达或无法更改
的文件会被报告，其余的仍会被更改。`--` 结束选项解
析：之后的每个参数都是操作数。以 `-` 开头的模式请去掉短横线书写
（`a-w`），或先结束选项（`chmod -- -w file`）。

## OPTIONS

- `-R, --recursive` — 递归更改文件和目录。
- `-c, --changes` — 只报告模式确实发生变化的文件。
- `-v, --verbose` — 报告每个处理过的文件，包括更改被拒绝或无法到达
  的文件。
- `-f, --silent, --quiet` — 抑制大多数错误消息；运行仍会失败，
  退出状态会报告这一点。
- `--preserve-root` — 带 `-R` 时，无论经由何种途径到达，都拒绝更改 `/`。
- `--no-preserve-root` — 把 `/` 当作任何其他目录对待（默认）。
- `-h, -?, --help` — 显示本命令的简短帮助。

## EXAMPLES

- `chmod 644 notes.txt` — 所有者可读写，其他人只读。
- `chmod g+w shared.txt` — 在当前权限位上增加组写权限。
- `chmod -R a=rx Docs` — 让 `Docs` 树对所有人可读且可进入。
- `chmod +x build.sh` — 让脚本可由 umask 允许的所有人执行。

## EXIT STATUS

- `0` — 每次模式更改都成功。
- `1` — 有文件无法到达或无法更改，或输出失败；每个原因都打印到标准
  错误（`-f` 下被抑制）。无法理解的命令行，或其模式操作数既不是八
  进制也不是符号形式的命令行，同样以 `1` 退出。

## ENVIRONMENT

- `LANG` — 简短帮助的首选区域设置（BCP-47 标签，如 `zh-CN`）。
