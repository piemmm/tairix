by hand.

Source: the `SingleStepTests` ARM7TDMI suite (https://github.com/SingleStepTests/ARM7TDMI, commit

suite was generated by the NanoBoyAdvance emulator, not captured from

`arm7tdmi.bin` is the `tairix_riscos_arm::vectors` encoding of 128
vectors of each file, in file order, from those the 26-bit profile is
held to: up to 2 of each instruction shape (bits 27 to 20 and 7
to 4, with whether the condition passed), then evenly spaced others.
Every kept vector of every file passed when the sample was written.
