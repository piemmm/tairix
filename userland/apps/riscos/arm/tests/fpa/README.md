# FPA conformance vectors

Generated by `cargo xtask riscos-fpa <module> --write-sample`; never edit
by hand.

Source: the answers of

    FPEmulator 4.39 (30 Mar 2024) (1.13M)

run as an opaque program on the emulator's own processor,
unsqueezed as the kernel's module loader does.
The module file's SHA-256:

    117e5a84621845791360a19ef9bdf97f768be93b7dae7b0ff09b11c4443f8e44

Each vector is an FPA instruction run natively by the processor: the
registers, FPA state and memory the harness drew for it, and what the
processor left. It is kept only where FPEmulator, given the same, left
the same in every register, every word of memory, the FPA's registers
and FPSR, and a trap's exception dump. FPEmulator's answers are only
compared, so nothing of the module's is carried here.

`fpemulator.bin` is the `tairix_riscos_arm::vectors` encoding of the first
agreeing cases of each class, drawn from seed `0x46504134` over 20000
cases, 5 of them skipped as PC-relative stores over the
instruction. Every case agreed when the sample was written.
