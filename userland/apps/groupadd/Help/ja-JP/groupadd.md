## NAME

groupadd — グループを作る

## SYNOPSIS

`groupadd [-g GID] [--] NAME`

## DESCRIPTION

グループ台帳にグループを一つ追加します。グループ名は
`[a-z_][a-z0-9_-]*` に合致しなければならず、id は十進の値です。グループ
の作成は管理操作です。ユーザー管理の権能を持たない呼び出し元を台帳は拒否
します。

`-g` が省かれると、グループ id は、既存の id のうち 1000 以上で最大の
ものの一つ上へ自動的に割り当てられ、そのような id を持つグループがなけ
れば 1000 になります。1000 未満の id はシステムのもので、決して割り当て
られません。最大の id より上に id が残っていなければ、グループは作成さ
れません。すでに使われている id の要求は拒否されます。衝突の裁定者は台
帳です。

`--` はオプション解析を終え、以降のすべての引数はオペランドです。

## OPTIONS

- `-g, --gid GID` — 数値のグループ id。省くと自動割り当て（既存の id の
  うち 1000 以上で最大のものの一つ上、なければ 1000）。
- `-h, -?, --help` — このコマンド自身の短いヘルプを表示する。

## EXAMPLES

- `groupadd staff` — 自動割り当ての id で `staff` を作る。
- `groupadd -g 100 staff` — id `100` で `staff` を作る。

## EXIT STATUS

- `0` — グループを作成した。
- `1` — 台帳が作成を拒否または失敗した（権能の欠如や id の重複など）。理
  由は標準エラーに印字される。解釈できなかったコマンド行も `1` で終了す
  る。

## ENVIRONMENT

- `LANG` — 短いヘルプの優先ロケール（`ja-JP` のような BCP-47 タグ）。
