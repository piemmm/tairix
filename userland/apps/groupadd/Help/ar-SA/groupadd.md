## NAME

groupadd — إنشاء مجموعة

## SYNOPSIS

`groupadd [-g GID] [--] NAME`

## DESCRIPTION

يضيف مجموعة واحدة إلى سجل المجموعات. يجب أن يطابق اسم المجموعة
`[a-z_][a-z0-9_-]*` والمعرّف قيمة عشرية. إنشاء مجموعة عملية إدارية:
يرفض السجل مستدعيًا لا يحمل قدرة إدارة المستخدمين.

عند حذف `-g` يُخصص معرّف المجموعة تلقائيًا: واحدًا فوق أعلى معرّف
موجود قيمته 1000 أو أكثر، أو 1000 إن لم يكن لأي مجموعة معرّف كهذا.
والمعرّفات الأدنى من 1000 خاصة بالنظام ولا تُخصص أبدًا، وإذا لم يبقَ
معرّف فوق أعلى المعرّفات فلا تُنشأ المجموعة. المعرّف المطلوب المأخوذ
سلفًا يُرفض؛ والسجل هو المرجع في التصادمات.

ينهي `--` تحليل الخيارات: كل معطى لاحق هو معامل.

## OPTIONS

- `-g, --gid GID` — معرّف المجموعة الرقمي؛ يُخصص تلقائيًا عند حذفه
  (واحدًا فوق أعلى معرّف موجود قيمته 1000 أو أكثر، وإلا فهو 1000).
- `-h, -?, --help` — عرض المساعدة القصيرة لهذا الأمر نفسه.

## EXAMPLES

- `groupadd staff` — إنشاء `staff` بمعرّف مخصص تلقائيًا.
- `groupadd -g 100 staff` — إنشاء `staff` بالمعرّف `100`.

## EXIT STATUS

- `0` — أُنشئت المجموعة.
- `1` — رفض السجل الإنشاء أو فشل فيه (مثلًا قدرة مفقودة أو معرّف
  مكرر)؛ يُطبع السبب على الخطأ القياسي. وسطر أوامر غير مفهوم ينتهي
  بـ`1` أيضًا.

## ENVIRONMENT

- `LANG` — المنطقة المفضلة للمساعدة القصيرة (وسم BCP-47 مثل `ar-SA`).
