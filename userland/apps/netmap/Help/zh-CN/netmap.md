## NAME

netmap — 网络地图与清单

## SYNOPSIS

`netmap`

## DESCRIPTION

打开一个窗口，绘制本机所连接网络的地图：它的网络接口、接口所在的子网、其邻居缓存在每个子网上见过的主机、
其路由所经过的路由器，以及通往本地网络之外的默认网关。每一项都绘制为一个按其类型着色的圆盘上的图标——计算机为蓝色、
路由器为橙色、打印机为紫色、存储为青色、电话为绿色——每条线都采用其所通往对象的颜色。
地图识别出操作系统的主机会带有该系统的徽标；主机或接口旁的指示灯表示它上次被观察时是否可达（绿色）
或不可达（红色）。

用主按钮拖动、转动滚轮，或在触控板上用双指滚动，即可在地图上移动。按住 `Ctrl` 并转动滚轮，
或在触控板或触摸屏上捏合，即可围绕指针下的位置缩放；按 `Home` 可让整张地图重新适应窗口。
点击一个节点可查看已知的信息——它的地址、硬件地址及其制造商、可达性、它看起来是哪种设备以及运行什么系统，
并附上地图的把握程度及其依据——点击空白处可收起详情。只要有空间，就会显示名称。

通告了服务的主机会在一个小徽章上显示服务的数量。将指针停在任一节点上可查看其完整名称，
停在这样的主机上可查看其服务的名称；点击该主机可将其服务呈扇形展开在周围，再次点击它、点击别处或按 `Escape`
可将其收起。用副按钮点击节点会打开其菜单：显示或隐藏其服务，或复制其地址、名称或硬件地址——
对于服务，复制其地址和端口；对于 Web 服务，复制其 URL。

地图通过系统信息 API 和发现服务读取，地图上的主机以配置的 DNS 服务器给出的名字或设备自己取的名字命名；
地图从不自行联系任何主机，并且在窗口打开期间每隔几秒重新读取一次。它还收集设备在本地链路上通告的服务——打印机、文件共享、媒体播放器——
并将每项归入提供它的主机。
接口地址和路由需要 `CAP_SYSINFO_GLOBAL`；硬件地址和邻居缓存需要 `CAP_SYSINFO_HW`；
通告的服务需要 `CAP_NET_DISCOVER_ALL`；通过 DNS 为主机命名需要 `CAP_NET`。
缺少任何一项时，地图会说明无法显示的内容，并绘制其余部分。

Netmap 可从桌面的程序库启动，也可在 shell 中按名称启动，并且需要正在运行的
图形会话；没有图形会话时，它会在标准错误流上报告拒绝原因并退出。

## EXIT STATUS

选择“退出”后为零；当窗口通道或共享帧区域被拒绝时为非零（原因会写在标准错误流
上）。
