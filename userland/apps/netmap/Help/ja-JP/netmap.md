## NAME

netmap — ネットワークの地図と一覧

## SYNOPSIS

`netmap`

## DESCRIPTION

このマシンが接続しているネットワークの地図を表示するウィンドウを開きます。
ネットワークインターフェイス、それらが属するサブネット、近隣キャッシュが各サブネットで見つけたホスト、
経路が通るルーター、そしてローカルネットワークの外へ通じるデフォルトゲートウェイが表示されます。
各要素はその種類を示す色の円の上にアイコンで描かれ（コンピューターは青、
ルーターはオレンジ、プリンターは紫、ストレージは青緑、電話は緑）、各線はその行き先の色になります。
地図がオペレーティングシステムを認識したホストにはそのエンブレムが付き、
ホストやインターフェイスの横のランプは、最後に確認されたときに到達可能だったか（緑）
そうでなかったか（赤）を示します。

主ボタンでドラッグするか、ホイールを回すか、タッチパッドで二本指でスクロールすると、
地図の上を移動できます。`Ctrl` を押しながらホイールを回すか、タッチパッドやタッチスクリーンでピンチすると、
ポインターの下の点を中心に拡大縮小し、`Home` を押すと地図全体が再びウィンドウに収まります。
ノードをクリックすると、そのノードについて分かっていること（アドレス、ハードウェアアドレスとその製造元、
到達可能性、どの種類の機器らしいか、何が動いているか、地図がどれほど確かでなぜそう判断したか）
が表示され、何もない場所をクリックすると詳細が閉じます。名前は表示する余地のある場所に表示されます。

サービスを告知しているホストには、その数が小さなバッジで表示されます。
ノードの上でポインターを止めると完全な名前が、そのようなホストの上で止めるとサービスの名前が表示されます。
ホストをクリックするとそのサービスが周りに扇状に広がり、もう一度クリックするか、別の場所をクリックするか、
`Escape` を押すと畳まれます。副ボタンでノードをクリックするとメニューが開き、サービスの表示・非表示を切り替えたり、
アドレス、名前、ハードウェアアドレスをコピーしたりできます（サービスではアドレスとポート、
Web サービスでは URL）。

地図はシステム情報 API と検出サービスを通じて読み取られ、地図上のホストには設定された DNS サーバーが付けた名前か、
デバイスが自分に付けた名前が付きます。地図が自らホストに接続することはなく、
ウィンドウが開いている間は数秒ごとに読み直されます。また、デバイスがローカルリンクで告知するサービス（プリンター、
ファイル共有、メディアプレーヤー）を集め、それぞれを提供元のホストにまとめます。
インターフェイスのアドレスと経路には `CAP_SYSINFO_GLOBAL` が、
ハードウェアアドレスと近隣キャッシュには `CAP_SYSINFO_HW` が、
告知されたサービスには `CAP_NET_DISCOVER_ALL` が、
DNS によるホストの命名には `CAP_NET` が必要です。いずれかがない場合、
地図は表示できない内容を示したうえで残りを描きます。

Netmap はデスクトップのプログラムライブラリから、またはシェルから名前で
起動します。実行中のグラフィカルセッションが必要で、ない場合は標準エラー
ストリームに拒否を報告して終了します。

## EXIT STATUS

終了を選ぶと 0。ウィンドウチャネルまたは共有フレーム領域が拒否された場合は
0 以外（理由は標準エラーストリームに示されます）。
