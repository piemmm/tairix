## NAME

netmap — 네트워크 지도와 목록

## SYNOPSIS

`netmap`

## DESCRIPTION

이 컴퓨터가 연결된 네트워크의 지도를 보여 주는 창을 엽니다. 네트워크 인터페이스, 인터페이스가 속한 서브넷, 이웃 캐시가 각 서브넷에서 본
호스트, 경로가 지나가는 라우터, 그리고 로컬 네트워크 너머로 이어지는 기본 게이트웨이가 표시됩니다. 각 항목은 그 종류를 나타내는 색의 원
위에 아이콘으로 그려지며(컴퓨터는 파랑, 라우터는 주황, 프린터는 보라, 저장 장치는 청록, 전화기는 초록), 각 선은 이어지는 대상의 색을
띱니다. 지도가 운영 체제를 알아본 호스트에는 그 운영 체제의 표장이 붙고, 호스트나 인터페이스 옆의 표시등은 마지막으로 확인했을 때 연결할
수 있었는지(초록) 아닌지(빨강)를 보여 줍니다.

기본 버튼으로 끌거나, 휠을 돌리거나, 터치패드에서 두 손가락으로 스크롤하면 지도 위를 이동합니다. `Ctrl` 을 누른 채 휠을 돌리거나
터치패드나 터치스크린에서 손가락을 오므리고 벌리면 포인터 아래 지점을 중심으로 확대·축소하며, `Home` 을 누르면 지도 전체가 다시 창에
맞춰집니다. 노드를 클릭하면 그 노드에 대해 알려진 정보(주소, 하드웨어 주소와 제조사, 연결 가능 여부, 어떤 종류의 장치로 보이며 무엇을
실행하는지, 그리고 지도가 얼마나 확신하며 그 근거가 무엇인지)가 표시되고, 빈 곳을 클릭하면 세부 정보가 닫힙니다. 이름은 들어갈 자리가
있는 곳마다 나타납니다.

지도는 시스템 정보 API와 검색 서비스를 통해 읽히며, 지도 위의 호스트는 설정된 DNS 서버가 붙인 이름이나 장치가 스스로 붙인 이름으로
표시됩니다. 지도가 직접 호스트에 연결하는 일은 없으며, 창이 열려 있는 동안 몇 초마다 다시 읽힙니다. 호스트 옆에는 장치가 로컬 링크에
알리는 서비스(프린터, 파일 공유, 미디어 플레이어)가 그 서비스를 제공하는 호스트 아래에 표시됩니다. 인터페이스 주소와 경로에는
`CAP_SYSINFO_GLOBAL`이, 하드웨어 주소와 이웃 캐시에는 `CAP_SYSINFO_HW`가, 알려진 서비스에는
`CAP_NET_DISCOVER_ALL`이, DNS로 호스트 이름을 붙이는 데에는 `CAP_NET`이 필요합니다. 하나라도 없으면 지도는
보여 줄 수 없는 것을 알리고 나머지를 그립니다.

Netmap 은 데스크톱의 프로그램 라이브러리에서 또는 셸에서 이름으로 실행하며,
실행 중인 그래픽 세션이 필요합니다. 세션이 없으면 표준 오류 스트림에 거부를
보고하고 종료합니다.

## EXIT STATUS

종료하면 0, 창 채널이나 공유 프레임 영역이 거부되면 0 이 아닌 값(이유는 표준
오류 스트림에 표시됨).
