## NAME

OpenMicro — Open Micro Emulator、8 ビットマイクロコンピューターのエミュレーター

## SYNOPSIS

`OpenMicro`

## DESCRIPTION

8 ビットのマイクロコンピューター（BBC Micro Model B と Acorn Electron）を
デスクトップのウィンドウで、本来の速さのまま 1 サイクルずつ実行します。各マシン
はクリーンルーム方式で書いた独自のオペレーティングシステムと BASIC を備え、
Model B はさらにディスクのファイルシステムも備えているので、マシンは BASIC の
プロンプトで起動します。画面はテレビのもので、幅 4 に対して高さ 3 の比率です。
音はデスクトップのオーディオから鳴ります。

ライブラリウィンドウは、各マシンを最後の画面を載せたタイルとして表示します。
「新規」は、指定した名前で、ドライブ 0 に新しい空のディスクを入れた、または入れ
ない BBC Micro Model B か、Plus 1 を取り付けた、または取り付けない
Acorn Electron を作成します。「起動」、ダブルクリック、または Return キーで、選
んだマシンを専用のウィンドウで起動するか、そのウィンドウを前面に出します。
マシンは 20 台まで保持され、複数のマシンを同時に動かせます。「複製」はマシンを
保存済みの状態とフォルダごとコピーし、「削除」は確認のうえでマシンとその保存済
みの状態を削除し、フォルダは残します。マシンのタイルを右クリックすると、その
マシンについて「起動」「設定」「複製」「削除」を選べ、動作中はマシンのメニュー
も選べます。エミュレーターは最初の起動時に、空のディスクを入れた
BBC Micro Model B を作成します。

「設定」は、マシンの名前、音量、そしてカセットのモーターが回っている間マシンを
全速で動かすテープの高速読み込みを変更します。マシンに取り付けたものは、
シャットダウンした状態でのみ変更できます。対象は各ソケットの ROM（Model B の OS
と 16 個のサイドウェイスロット、Electron の OS と BASIC、その Plus 1 の ROM と
カートリッジ）で、それぞれ同梱の ROM、Model B のスロットならサイドウェイ RAM、
スロットやカートリッジなら何もなし、または「イメージをインストール」で
エミュレーターの保管場所に入れた自分の ROM イメージのいずれかです。さらに
Electron の Plus 1 と、起動時の画面モード、ディスクの起動のしかた、ディスクの
タイミングを決める Model B のキーボードのリンクも対象です。

マシンのウィンドウを閉じると、そのマシンはサスペンドされます。もう一度起動する
と止まったところから再開します。メニューの「シャットダウン」はディスクとテープ
を取り出してマシンの電源を切り、最後の画面だけを残します。

各マシンには、あなたの Documents フォルダの Open Micro の下に、マシンの名前の付
いた専用のフォルダがあります。「新規ディスク」と「新規テープ」はそこに空の
ディスクやテープを作って入れ、「フォルダから」はそこにすでにあるディスクと
テープを表示します。ドライブとデッキに入っている、そのフォルダのディスクや
テープは、マシンとともに保たれます。シャットダウンしたマシンは起動するとそれら
を再び入れ、再開したマシンは、サスペンドしてからほかのプログラムが変更していな
いものにだけ書き戻します。

エミュレーターで開いたディスクイメージ（`.ssd`、`.dsd`）やテープイメージ
（`.uef`、`.csw`）は、ウィンドウが最後にアクティブだった動作中のマシンか、それ
を受け付けるほかの動作中のマシンに入ります。どちらもなければ、それを受け付ける
ライブラリの最初のマシンがそのために起動され、そこに入ります。
「ディスクを入れる」や「テープを入れる」で選んだものはそのドライブや
カセットデッキに入り、マシンのウィンドウにドロップしたものは書き込み禁止で
ドライブ 0 かデッキに入ります。マシンがディスクに書いた内容は、そのファイルに書
き込める限りディスクのファイルに書き戻されます。ファイルに書き込めないディスク
は書き込み禁止になります。「取り出す」でディスクを取り出し、
「ディスクを別名で保存」で好きな場所にコピーを保存します。録音したテープは取り
出すときに保存されます。「スナップショットを保存」はマシン全体をファイルに残
し、「スナップショットを復元」はディスクとテープごとそれを戻します。

画面の右クリックで開くメニューには、Model B の各ドライブとテープ、BREAK、
「リセット」「一時停止」、速度、全画面表示、シャープまたはスムーズな拡大と走査
線、キーボードの割り当て、クリップボードの文字を打ち込む「貼り付け」、
スナップショット、「設定」「マシンライブラリ」「シャットダウン」があります。文
字で割り当てると、キーは表示どおりの文字を打ち、英字の大文字小文字はマシンの
CAPS LOCK が決めます。位置で割り当てると、各キーはその位置にあるマシンのキーに
なります。Model B では、F1〜F9 は f1〜f9、F10 は f0、Home は SHIFT LOCK、Insert
はバックスラッシュのキーです。Electron では、F1〜F10 は FUNC と 1〜9 およ
び 0 の組み合わせ、Alt は FUNC、Caps Lock は CAPS LK です。どちらでも、F12 は
BREAK、End は COPY、矢印キーはカーソルキーです。

マシンのウィンドウ下端のランプは、CAPS LOCK とカセットのモーターを、Model B で
はさらに SHIFT LOCK と各ドライブを示します。各マシンは何の権限も持たない専用の
ワーカーの中で動くので、そのソフトウェアもメディアも信頼されません。失敗した
ワーカーは置き換えられ、マシンは電源投入時から再び動き出し、その理由が表示され
ます。

ライブラリウィンドウを閉じても動作中のマシンは動き続け、すべてのウィンドウを閉
じてもエミュレーターはアイコンバーに残ります。そのアイコンをクリックするか、そ
のメニューの「マシンライブラリ」を選ぶとライブラリが戻り、同じメニューの
「終了」を選ぶと動作中のマシンがすべてサスペンドされ、エミュレーターが終了しま
す。

## OPTIONS

`-h`, `-?`, `--help`
: このヘルプを標準出力に書き出して終了します。

## EXIT STATUS

アイコンバーのアイコンのメニューで「終了」を選ぶと 0 です。ウィンドウチャネル、
イベントメールボックス、またはデスクトップセッションが拒否されたときは 0 以外
で、その理由を標準エラー出力に示します。
