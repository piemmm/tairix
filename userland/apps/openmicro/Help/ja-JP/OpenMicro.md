## NAME

OpenMicro — Open Micro Emulator、8 ビットマイクロコンピューターのエミュレーター

## SYNOPSIS

`OpenMicro`

## DESCRIPTION

8 ビットのマイクロコンピューター（BBC Micro Model B、Acorn Electron、
Commodore 64）をデスクトップのウィンドウで、本来の速さのまま 1 サイクルずつ実行
します。各マシンはクリーンルーム方式で書いた独自のオペレーティングシステムと
BASIC を備え、Model B はさらにディスクのファイルシステムも、Commodore 64 は独自
の DOS を持つ 1541 ディスクドライブも備えているので、マシンは BASIC の
プロンプトで起動します。画面はテレビのもので、幅 4 に対して高さ 3 の比率です。
音はデスクトップのオーディオから鳴ります。

ライブラリウィンドウは、各マシンを、最後の画面か、まだ一度も動かしていなければ
その機種の起動画面を載せたタイルとして表示します。「新規」は、指定した名前で、
スロット 4〜7 にサイドウェイ RAM を備え、ドライブ 0 に新しい空のディスクを入れ
た、または入れない BBC Micro Model B か、Plus 1 を取り付けた、または取り付けな
い Acorn Electron か、PAL または NTSC で 6581 か 8580 の SID を備え、1541
ドライブを 1 台か 2 台つないだ、またはつながない Commodore 64 を作成します。
「起動」、ダブルクリック、または Return キーで、選んだマシンを専用のウィンドウ
で起動するか、そのウィンドウを前面に出します。マシンは 20 台まで保持され、複数
のマシンを同時に動かせます。「複製」はマシンを保存済みの状態とフォルダごと
コピーし、「削除」は確認のうえでマシンとその保存済みの状態を削除し、フォルダは
残します。マシンのタイルを右クリックすると、そのマシンについて「起動」「設定」
「複製」「削除」「フォルダを表示」を選べ、動作中はマシンのメニューも選べます。
エミュレーターは最初の起動時に、空のディスクを入れた BBC Micro Model B を作成し
ます。

「設定」は、マシンの名前、音量、カセットのモーターが回っている間マシンを全速で
動かすテープの高速読み込み、そして Commodore 64 ではテンキーのジョイスティック
をつなぐコントロールポートを変更します。マシンに取り付けたものは、
シャットダウンした状態でのみ変更できます。対象は各ソケットの ROM（Model B の OS
と 16 個のサイドウェイスロット、Electron の OS と BASIC、その Plus 1 の ROM と
カートリッジ、Commodore 64 の KERNAL、BASIC、文字セットと各ドライブの DOS）で、
それぞれ同梱の ROM、Model B のスロットならサイドウェイ RAM、スロットや
カートリッジなら何もなし、または「イメージをインストール」でエミュレーターの保
管場所に入れた自分の ROM イメージのいずれかです。さらに Electron の Plus 1、
Commodore 64 のテレビ方式、SID とドライブ、そして起動時の画面モード、ディスクの
起動のしかた、ディスクのタイミングを決める Model B のキーボードのリンクも対象で
す。

Model B には、vi 風のエディターである VIM もスロット 13 に取り付けられていま
す。マシンのプロンプトでは、`*VIM` とファイル名でそのファイルを編集します。VIM
の中で BREAK を押しても、VIM が保持しているテキストは残ります。VIM は、`!BOOT`
ファイル（`*BUILD` が作るもの）のようなテキストと、BASIC プログラムを編集しま
す。BASIC プログラムはテキストとして一覧表示し、トークン化して保存し直します。
どちらも画面モードの色が許す限り色付けします。`:dis` とファイル名では、プログラ
ムの機械語をページ送りで表示します。VIM の中では、`:help` がそのコマンドと、画
面モードをそれぞれが残す空きとともに一覧表示し、`:mode` と数字でモードを変
え、`:q` で BASIC に戻ります。ROM の入っていないサイドウェイ RAM のバンクがあれ
ば、VIM はヤンクや削除したものを、そのうち最も番号の大きいバンクに保持するので、
テキストが使えるメモリを少しも使いません。

マシンのウィンドウを閉じると、そのマシンはサスペンドされます。もう一度起動する
と止まったところから再開します。メニューの「シャットダウン」はメディアを取り出
してマシンの電源を切り、最後の画面だけを残します。

各マシンには、あなたの Documents フォルダの Open Micro の下に、マシンの名前の付
いた専用のフォルダがあります。「新規ディスク」（Commodore 64 でも同じ）と
「新規テープ」はそこに空のディスクやテープを作って入れ、「フォルダから」はそこ
にすでにあるディスクとテープを表示し、「スナップショットを保存」はマシン全体を
そこに `.snapshot` ファイルとして残します。「フォルダを表示」はそのフォルダを
Files で開くので、マシンがそこに保管しているものを、ほかのメディアやほかの
コンピューターにコピーできます。ドライブとデッキに入っている、そのフォルダの
ディスクやテープは、マシンとともに保たれます。シャットダウンしたマシンは起動す
るとそれらを再び入れ、再開したマシンは、サスペンドしてからほかのプログラムが変
更していないものにだけ書き戻します。

エミュレーターで開いたディスクイメージ（`.ssd`、`.dsd`）やテープイメージ
（`.uef`、`.csw`）、Commodore 64 用のディスク（`.d64`、`.g64`）、テープ
（`.tap`）、カートリッジ（`.crt`）、プログラム（`.prg`、`.t64`）は、ウィンドウ
が最後にアクティブだった動作中のマシンか、それを受け付けるほかの動作中のマシン
に入ります。どちらもなければ、それを受け付けるライブラリの最初のマシンがそのた
めに起動され、そこに入ります。入ったマシンのウィンドウは前面に出ます。
BBC Micro のディスクを Files で開くと、マシンを起動する代わりに、そのディスク
にあるファイルが表示されます。「ディスクを入れる」や「テープを入れる」で選んだ
ものはそのドライブやカセットデッキに入り、マシンのウィンドウにドロップしたもの
は書き込み禁止で最初のドライブかデッキに入り、そのウィンドウがキーボードを受け
取ります。マシンがディスクに書いた内容は、そのファイルに書き込める限りディスク
のファイルに書き戻され、ディスクがドライブに入っている間は、マウントもほかの
マシンもそのファイルに書き込めません。ファイルに書き込めないディスクや、ほかの
プログラムが使っているディスクは書き込み禁止になり、ウィンドウがその理由を示し
ます。`.g64` が必要になった `.d64` のディスクは、その形式で保存するよう勧めら
れます。「取り出す」でディスクを取り出し、「ディスクを別名で保存」で好きな場所
にコピーを保存します。録音したテープは取り出すときに保存されます。Commodore 64
では、「テープ」メニューの「再生」「録音」「停止」「巻き戻し」で
データレコーダーを操作します。「カートリッジを入れる」はカートリッジを差し込
み、「カートリッジを取り出す」はそれを抜きます。どちらもマシンを再起動します。
「プログラムを読み込む」は、LOAD と同じようにプログラムをメモリに入れ、RUN で
実行できるようにします。「スナップショットを保存」はマシン全体をファイルに残し
（マシンのフォルダに、まだフォルダがなければ選んだ場所に）、
「スナップショットを復元」はそうしたファイルをひとつ、メディアごと戻します。

画面の右クリックで開くメニューには、Model B や Commodore 64 の各ドライブと
テープ、Commodore 64 のカートリッジと「プログラムを読み込む」、BREAK
（Commodore 64 では RESTORE）、Model B と Electron では SHIFT を押したまま
BREAK を押してディスクやテープから起動する SHIFT-BREAK、「リセット」
「一時停止」、速度、全画面表示、シャープまたはスムーズな拡大と走査線、
キーボードの割り当て、クリップボードの文字を、英字はマシンが表示するとおりの大
文字小文字で打ち込む「貼り付け」、スナップショット、「フォルダを表示」「設定」
「マシンライブラリ」「シャットダウン」があります。文字で割り当てると、キーは表
示どおりの文字を打ち、英字の大文字小文字はマシンの CAPS LOCK が、Commodore 64
では Shift が決めます。位置で割り当てると、各キーはその位置にあるマシンのキー
になります。Model B では、F1〜F9 は f1〜f9、F10 は f0、Home は SHIFT LOCK、
Insert はバックスラッシュのキーです。Electron では、F1〜F10 は FUNC と 1〜9 お
よび 0 の組み合わせ、Alt は FUNC、Caps Lock は CAPS LK です。どちらでも、F12
は BREAK、End は COPY、矢印キーはカーソルキーです。Commodore 64 では、F1、F3、
F5、F7 はそのファンクションキー、F2、F4、F6、F8 は SHIFT を押しながらの同じ
キー、Escape は RUN/STOP、Alt は Commodore キー、Ctrl は CTRL、Home は
CLR/HOME、F12 または Page Up は RESTORE、矢印キーはカーソルキーです。テンキー
のジョイスティックがオンのときは、テンキーの矢印キーでジョイスティックを動か
し、0 と 5 で発射します。

マシンのウィンドウ下端のランプは、CAPS LOCK とカセットのモーターを、Model B で
はさらに SHIFT LOCK と各ドライブを示し、Commodore 64 ではデータレコーダーの
モーターと各ドライブを示します。Model B と Electron では、下端の右にある
SHIFT-BREAK ボタンが、メニューの同じ項目と同じ働きをします。各マシンは何の権限
も持たない専用のワーカーの中で動くので、そのソフトウェアもメディアも信頼されま
せん。失敗したワーカーは置き換えられ、マシンは電源投入時から再び動き出し、その
理由が表示されます。

ライブラリウィンドウを閉じても動作中のマシンは動き続け、すべてのウィンドウを閉
じてもエミュレーターはアイコンバーに残ります。そのアイコンをクリックするか、そ
のメニューの「マシンライブラリ」を選ぶと必ずライブラリが前面に出て、同じ
メニューの「終了」を選ぶと動作中のマシンがすべてサスペンドされ、エミュレーター
が終了します。

## OPTIONS

`-h`, `-?`, `--help`
: このヘルプを標準出力に書き出して終了します。

## EXIT STATUS

アイコンバーのアイコンのメニューで「終了」を選ぶと 0 です。ウィンドウチャネル、
イベントメールボックス、またはデスクトップセッションが拒否されたときは 0 以外
で、その理由を標準エラー出力に示します。
