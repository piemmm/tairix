## NAME

OpenMicro — Open Micro Emulator，8 位微型计算机模拟器

## SYNOPSIS

`OpenMicro`

## DESCRIPTION

在桌面窗口中以原机的速度逐周期运行 8 位微型计算机——BBC Micro Model B 和
Acorn Electron——每台都配有以净室方式编写的自有操作系统和 BASIC，Model B 还配有
磁盘文件系统，因此机器启动后即停在 BASIC 提示符下。画面是电视的画面，宽四高三，
声音通过桌面的音频播放。

资料库窗口把每台机器显示为一块带有其最后画面的图块。“新建”按所给的名称创建一台
机器：一台在驱动器 0 中放有一张新的空白磁盘或不放磁盘的 BBC Micro Model B，或一
台装有或不装 Plus 1 的 Acorn Electron。“启动”、双击或 Return 键会在单独的窗口中
启动所选机器，或把它的窗口提到前面；最多保留二十台机器，多台机器可以同时运行。
“复制”连同已保存的状态和文件夹复制一台机器，“删除”在确认后删除一台机器及其已保
存的状态，但保留其文件夹。右键单击一台机器的图块，可对该机器使用“启动”“设置”
“复制”和“删除”；机器运行时，还会给出机器的菜单。模拟器首次启动时会创建一台带有
空白磁盘的 BBC Micro Model B。

“设置”更改机器的名称、音量，以及在卡带电机转动期间让机器全速运行的磁带快速加
载。装在机器上的部件只能在机器关机时更改：每个插座中的 ROM——Model B 的 OS 和
十六个侧向插槽、Electron 的 OS 和 BASIC，以及其 Plus 1 的 ROM 和卡匣——每个都可
以是随附的 ROM、Model B 插槽中的侧向 RAM、插槽或卡匣中什么也不装，或用
“安装映像”放入模拟器存储的你自己的 ROM 映像；Electron 的 Plus 1；以及 Model B
的键盘跳线，它们设定启动时的屏幕模式、磁盘的启动方式和磁盘时序。

关闭机器的窗口会让机器挂起：再次启动时，它从停下的地方继续。其菜单中的“关机”会
取出它的磁盘和磁带并关闭机器，只保留它的最后一个画面。

每台机器在你的 Documents 文件夹中都有一个自己的文件夹：Open Micro 下以机器名称
命名的文件夹。“新建磁盘”和“新建磁带”在那里创建一张空白磁盘或一盘空白磁带并将其
放入，“从文件夹”则提供那里已有的磁盘和磁带。驱动器和卡带机中来自其文件夹的磁盘
和磁带会随机器保留：关机的机器在启动时会重新放入它们；恢复运行的机器只写回自挂
起以来没有被其他程序改动过的那些。

用模拟器打开的磁盘映像（`.ssd`、`.dsd`）或磁带映像（`.uef`、`.csw`）会交给窗口
最后处于活动状态的那台正在运行的机器，或接受它的另一台正在运行的机器，否则交给
资料库中第一台接受它的机器，并为此将其启动。用“插入磁盘”或“插入磁带”选取的映像
会放入该驱动器或卡带机，拖放到机器窗口上的映像则以写保护方式放入驱动器 0 或卡带
机。只要磁盘的文件可写，机器写到磁盘上的内容就会写回该文件；文件不可写的磁盘处
于写保护状态。“弹出”取出磁盘，“磁盘另存为”把副本保存到任意位置。录过音的磁带在
取出时保存。“保存快照”把整台机器存入文件，“恢复快照”连同其磁盘和磁带一并取回。

在画面上右击打开的菜单提供 Model B 的各驱动器和磁带；BREAK、“复位”“暂停”和速
度；全屏、锐利或平滑缩放以及扫描线；键盘的映射方式；输入剪贴板文本的“粘贴”；快
照；“设置”；“机器资料库”；以及“关机”。按字符映射时，按键输入其上所示的字符，字
母大小写由机器的 CAPS LOCK 决定。按位置映射时，每个键都是其位置上的机器按键。在
Model B 上，F1 至 F9 为 f1 至 f9，F10 为 f0，Home 为 SHIFT LOCK，Insert 为反斜
杠键。在 Electron 上，F1 至 F10 为 FUNC 加 1 至 9 和 0，Alt 为 FUNC，Caps Lock
为 CAPS LK。在两种机器上，F12 均为 BREAK，End 为 COPY，方向键为光标键。

机器窗口底部的指示灯显示 CAPS LOCK 和卡带电机，在 Model B 上还显示 SHIFT LOCK
和各驱动器。每台机器运行在不持有任何权限的独立工作进程中，因此其软件和介质都不
被信任；失败的工作进程会被替换，机器像通电时一样重新启动，并显示原因。

关闭资料库窗口后，正在运行的机器会继续运行；关闭所有窗口后，模拟器仍留在图标栏
上：点击它的图标，或其菜单中的“机器资料库”，可以把资料库找回来，而该菜单中的
“退出”会挂起所有正在运行的机器并结束模拟器。

## OPTIONS

`-h`, `-?`, `--help`
: 将本帮助写到标准输出并退出。

## EXIT STATUS

在图标栏图标的菜单中选择“退出”后为零。窗口通道、事件信箱或桌面会话被拒绝时为非
零；原因写到标准错误流。
