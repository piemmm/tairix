## NAME

music — デスクトップの音楽プレーヤー

## SYNOPSIS

`music`

## DESCRIPTION

一つのウィンドウでトラックのリストを再生します。デスクトップのファイル選択でフ
ァイルやフォルダー全体を開くか、ファイルマネージャーからトラックを開いてくださ
い。すでに動いているプレーヤーのリストに加わります。レート、サンプル形式、チャ
ンネル配置が同じトラックは途切れなく続けて再生されます。

プレーヤーはファイルシステムの権限を一切持ちません。デスクトップのセッションが
代わりに閲覧し、ユーザーが選んだファイルだけを一度限り、読み取り専用で委ねます。
フォルダーの場合は、その中でこのプレーヤーが開くファイルです。プレーヤーの中で
デコードされるファイルはありません。音声とアルバムアートはそれぞれ、何にも届か
ない別のプロセスがデコードするため、不正な、あるいは悪意あるファイルがプレーヤ
ーの届くものに届くことはありません。

ウィンドウの上部には再生中のものが表示されます。アルバムアート、タイトル、アー
ティストとアルバム、形式、再生位置、各チャンネルのレベルメーターです。その下に
再生操作、シャッフルとリピートの操作、音量があり、さらにその下にリストがありま
す。位置のスライダーをドラッグしてシークし、音量のスライダーでレベルを設定しま
す。どちらも離したところで働きます。トラックをダブルクリックすると再生します。
リスト上で副ボタンを押すとプレーヤーのメニューが開き、出力先や、各トラック自身
のタグが示すラウドネスで揃えるかどうかも選べます。

プレーヤーが読めないファイルは除外され、その理由がステータス行に表示されます。

* `Space` — 再生または一時停止
* `Enter` — 選択したトラックを再生
* `Left` / `Right` — 10 秒戻るまたは進む
* `Ctrl` + `Left` / `Right` — 前のトラックまたは次のトラック
* `Up` / `Down` — 上または下のトラックを選択
* `Alt` + `Up` / `Down` — 選択したトラックを移動
* `Delete` — 選択したトラックをリストから外す
* `+` / `-` — 3 デシベル大きくまたは小さく
* `S` — シャッフルまたは順番に再生
* `R` — リピートしない、リストをリピート、トラックをリピート
* `Ctrl` + `O` — ファイルを開く
* `Ctrl` + `Shift` + `O` — フォルダーを開く

## OPTIONS

`-h`, `-?`, `--help`
: このヘルプを標準出力に書き出して終了する。

## EXIT STATUS

ウィンドウを閉じるか「終了」を選ぶとゼロです。ウィンドウチャンネル、共有フレー
ム領域、デスクトップセッションのいずれかが拒否されたときはゼロ以外となり、理由が
標準エラーに示されます。
