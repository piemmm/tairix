## NAME

music — 桌面音乐播放器

## SYNOPSIS

`music`

## DESCRIPTION

在一个窗口中播放曲目列表。通过桌面的文件选择器打开文件或整个文件夹，或从文件
管理器中打开曲目：它会加入已在运行的播放器的列表。采样率、采样格式和声道布局
相同的曲目之间无缝衔接。

播放器不持有任何文件系统能力。桌面会话代它浏览，并一次性、只读地把用户所选的
文件委托给它——对文件夹而言，是其中本播放器会打开的文件。播放器内部不解码任何
文件：声音和专辑封面各由一个毫无访问权限的独立进程解码，因此格式错误或恶意的
文件无法触及播放器所能触及的任何东西。

窗口顶部显示正在播放的内容：专辑封面、标题、艺术家和专辑、格式、播放位置，以及
每个声道的电平表。其下是播放控制、随机和重复控制以及音量，再往下是列表。拖动
位置滑块可以跳转，拖动音量滑块可以设置音量；两者都在松开处生效。双击曲目即可
播放。在列表上按副键会打开播放器菜单，菜单中还可以选择输出，以及是否按曲目自身
标签所标明的响度对曲目进行均衡。

播放器无法读取的文件会被略过，原因显示在状态行上。

* `Space` — 播放或暂停
* `Enter` — 播放所选曲目
* `Left` / `Right` — 后退或前进十秒
* `Ctrl` + `Left` / `Right` — 上一首或下一首
* `Up` / `Down` — 选择上方或下方的曲目
* `Alt` + `Up` / `Down` — 移动所选曲目
* `Delete` — 将所选曲目移出列表
* `+` / `-` — 调高或调低三分贝
* `S` — 随机播放或按顺序播放
* `R` — 不重复、重复列表或重复曲目
* `Ctrl` + `O` — 打开文件
* `Ctrl` + `Shift` + `O` — 打开文件夹

## OPTIONS

`-h`, `-?`, `--help`
: 把本帮助写到标准输出并退出。

## EXIT STATUS

关闭窗口或选择“退出”后为零。窗口通道、共享帧区域或桌面会话被拒绝时为非零，
原因会写在标准错误流上。
