## NAME

chown — ファイルの所有者とグループを変更する

## SYNOPSIS

`chown [OPTION]... [OWNER][:[GROUP]] file...`

`chown [OPTION]... --reference=RFILE file...`

## DESCRIPTION

各ファイルオペランドの所有ユーザーとグループを順に変更します。`OWNER` は
ユーザーを変更してグループを保ち、`OWNER:GROUP` は両方を、`:GROUP` はグ
ループだけを変更します。`OWNER:` はさらに、所有者の主グループをファイル
に与えます。空のオペランドや `:` だけではどちらも変わりません。古い
`OWNER.GROUP` の綴りも警告付きで使えますが、オペランド全体がアカウント名
である場合は別です。`--reference` を付けると、各ファイルは `RFILE` が指
すものの所有者とグループを受け取ります。

`OWNER` と `GROUP` はアカウント名とグループ名、または数値です。まず名前
として試し、その名前を持つものがないときだけ数値として受け取ります。先頭
の `+`（`+1000`）は常に数値を意味します。

ファイルを別のアカウントや、自分が属していないグループに与えるには
`CAP_FS_CHOWN` capability が必要です。これがなくても、自分が所有するファ
イルのグループを自分のグループのいずれかに変えることはできます。変更する
と、ファイルの set-user-ID ビットが消去され、グループがそのファイルを実
行できる場合は set-group-ID ビットも消去されます。ディレクトリでは両方と
も保たれます。

オペランドとしてシンボリックリンクを指定すると、それが指すファイルが変更
され、`-h` を付けるとリンク自体が変更されます。`-R` を付けるとディレクト
リオペランドとその中のすべてが変更され、各ディレクトリはその中身の後に変
更されます。ツリーの中で出会ったシンボリックリンクはそれ自体が変更され、
それが指すものに手が付けられることはありません。`--dereference` を付ける
と、リンクにも手を付けません。`-R` のとき、オペランドとして指定したシン
ボリックリンクはそれ自体が変更され、たどられません。`--dereference` を付
けると代わりにそれが指すものが変更され、`-H` を付けるとそれが指すディレ
クトリが巡回されます。到達または変更できないファイルは報告され、それでも
残りは変更されます。報告では、各所有者とグループを名前で示し、その番号を
持つアカウントやグループがない場合は番号で示します。`--` はオプション解
析を終了し、以降の引数はすべてオペランドです。

## OPTIONS

- `-c, --changes` — 所有権が実際に変わったファイルだけを報告する。
- `-f, --silent, --quiet` — ほとんどのエラーメッセージを抑止する。実行は
  失敗のままで、終了コードがそれを報告する。
- `-v, --verbose` — 処理したすべてのファイルを、変更が拒否されたものや到
  達できなかったものも含めて報告する。
- `--dereference` — リンク自体ではなく、シンボリックリンクが指すものを変
  更する。`-R` がなければこれが既定。
- `-h, --no-dereference` — シンボリックリンクが指すものではなく、リンク
  自体を変更する。
- `--preserve-root` — `-R` のとき、どのようにたどり着いても `/` の変更を
  拒む。
- `--no-preserve-root` — `/` をほかのディレクトリと同じように扱う（既
  定）。
- `--from=CURRENT_OWNER:CURRENT_GROUP` — 現在の所有者とグループがこれと
  一致するファイルだけを変更する。どちらかを省くと、その方は何でも受け付
  ける。
- `--reference=RFILE` — 名前を指定する代わりに、各ファイルに `RFILE` の
  所有者とグループを与える。
- `-R, --recursive` — ファイルとディレクトリを再帰的に変更する。
- `-H` — `-R` のとき、オペランドとして指定したシンボリックリンクの先にあ
  るディレクトリを巡回する。
- `-L` — `-R` のとき、ディレクトリへのシンボリックリンクをすべてたどる。
  再帰的な変更はツリーの中のリンクを決してたどらないので、拒否される。
- `-P` — `-R` のとき、シンボリックリンクを一切たどらない（既
  定）。`-H`、`-L`、`-P` は最後に指定したものが勝つ。
- `-?, --help` — このコマンド自身の短いヘルプを表示する。
- `--version` — ツール名とバージョンを出力する。

## EXAMPLES

- `chown alice notes.txt` — グループを保ったまま `notes.txt` を `alice`
  に与える。
- `chown alice:staff notes.txt` — それを `alice` とグループ `staff` に与
  える。
- `chown :staff shared.txt` — グループだけを変更する。
- `chown -R alice Projects` — `Projects` ツリーを `alice` に与える。
- `chown -R --from=bob alice Shared` — `Shared` の中で `bob` が所有する
  ものだけを `alice` に与える。
- `chown --reference=template.txt notes.txt` — `notes.txt` に
  `template.txt` の所有者とグループを与える。

## EXIT STATUS

- `0` — すべての変更が成功した。
- `1` — 到達または変更できないファイルがあった、あるいは出力が失敗した。
  それぞれの理由は標準エラーに出力される（`-f` では抑止）。解釈できな
  かったコマンド行や、読み取れなかった所有者、グループ、参照ファイルの場
  合も `1` で終了し、何も変更しない。
